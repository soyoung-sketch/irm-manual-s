# 포인트 사용 현황

매출처별로 **포인트 적립·사용 내역**을 한 줄로 집계해 **잔여 포인트**를 조회하는 화면입니다.

### 1. 🔍 조회

- 검색어를 입력해 **통합검색**하거나, [🔍 상세검색]으로 조건을 지정해 조회합니다.

### 2. ✅ 포인트 집계 확인

매출처별로 한 줄씩 집계된 포인트를 확인합니다.

**📌 기본정보**

- **매출처코드 · 매출처명 · 사업장명**으로 매출처를 확인하고, **이전 포인트**에서 이전까지 보유하던 포인트를 확인합니다.
**📌 추가 포인트(+)**

- **매출적립 · 결제취소 · 수금취소 · 관리자** 사유별로 늘어난 포인트를 확인합니다.
  - 관리자 포인트는 포인트 지급/차감 화면에서 지급합니다.
**📌 차감 포인트(-)**

- **결제 · 매출반품 · 수금 · 관리자** 사유별로 줄어든 포인트를 확인합니다.
  - 차감 포인트의 값은 빨간색으로 표시되어 추가 포인트와 구분됩니다.
**📌 보유 포인트**

- **잔여 포인트(=)**에서 매출처가 지금 사용할 수 있는 포인트를 확인합니다.
  - 이전 포인트 + 추가 포인트 − 차감 포인트 = 잔여 포인트

### 3. 🧮 합계 확인

- 화면 하단에서 조회된 전체 매출처의 **항목별 합계**를 확인합니다.
  - 이전 포인트는 합계가 표시되지 않습니다.

### ⚙️ 옵션

[⚙ 옵션] 버튼을 클릭하면 메뉴가 표시됩니다.

- **문서저장** : 조회된 내역을 **엑셀 · 워드 · PDF** 형식으로 저장합니다.
- **레이아웃** : 목록에 표시할 **사용자 컬럼**을 설정하거나 초기화합니다.

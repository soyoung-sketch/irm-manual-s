# 카테고리

매출처를 분류하는 카테고리를 **대분류·중분류** 2단계로 등록하고 관리하는 화면입니다.

### 1. 🌳 카테고리 분류 확인

등록된 카테고리를 트리 구조로 확인합니다.

- 사업장명 아래의 **대분류**를 펼치면 그에 속한 **중분류**까지 확인할 수 있습니다.
- **카테고리 미지정**을 클릭하면 아직 분류하지 않은 매출처를 확인할 수 있습니다.

### 2. 📁 대분류 등록·관리

- [+] 버튼을 클릭해 새 대분류를 추가하고 카테고리명을 입력합니다.
- 삭제할 대분류를 체크한 후 [✕] 버튼을 클릭하면 삭제됩니다.
- 관리할 대분류를 **클릭**해 선택하면 하위 중분류가 표시됩니다.

**📌 순서 변경**

- 대분류를 선택한 후 [▲] [▼] 버튼을 클릭하면 **순서**가 한 칸씩 이동합니다.
  - 순서는 매출처 등록 화면에서 카테고리를 고를 때 표시되는 차례입니다.

### 3. 📂 중분류 등록·관리

- [+] 버튼을 클릭해 선택한 대분류 아래에 새 중분류를 추가합니다.
- 삭제할 중분류를 체크한 후 [✕] 버튼을 클릭하면 삭제됩니다.

**📌 순서 변경**

- 중분류를 선택한 후 [▲] [▼] 버튼을 클릭하면 **순서**가 한 칸씩 이동합니다.

### 🔍 카테고리 검색

- 검색어를 입력한 후 [찾기] 버튼을 클릭하면 해당 카테고리를 찾아줍니다.

### 🔗 대분류–중분류 연동

- 대분류를 **클릭**하면 그 대분류에 속한 중분류만 표시됩니다.
- 중분류를 추가하려면 **대분류를 먼저 선택**해야 합니다.

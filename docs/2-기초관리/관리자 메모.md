# 관리자 메모

매출처에 등록된 **관리자 메모**를 한자리에 모아 조회하는 화면입니다.

### 1. 🔍 매출처 검색

조회할 매출처를 지정해 메모를 불러옵니다.

- […] 버튼을 클릭해 **매출처 목록**에서 조회할 매출처를 선택합니다.
- [✕] 버튼을 클릭하면 지정한 매출처가 해제되어 **전체 메모**를 조회합니다.

- [🔍 검색] 버튼을 클릭하면 지정한 조건으로 메모가 조회됩니다.

### 2. ✅ 메모 목록 확인

- **구분**과 메모를 남긴 **작성자**를 확인합니다.
- 메모가 등록된 **거래처코드·거래처명**으로 어느 매출처의 메모인지 확인합니다.
- **관리자 메모**에서 작성된 메모 내용을, **작성일**에서 등록 시각을 확인합니다.
  - 화면 위아래의 총 건수에서 조회된 메모 수를 확인할 수 있습니다.

### 📝 긴 메모 표시

- 메모가 길면 **자동으로 줄바꿈**되고 행 높이가 늘어나 전체 내용이 잘리지 않고 표시됩니다.

### 👥 매출처 목록

[…] 버튼으로 열리는 창입니다.

- **통합검색·상세검색**으로 매출처를 조회합니다.
- 매출처를 선택한 후 [✓ 선택] 버튼을 클릭하면 조회 조건에 지정됩니다.

💡 등록된 메모를 모아 보는 **조회 전용** 화면입니다.

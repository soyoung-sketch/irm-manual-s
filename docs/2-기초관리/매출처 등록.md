# 매출처 등록

새 **매출처**의 기본정보·결제정보·거래정보를 입력해 등록하는 화면입니다.

💡 「매출처 목록」 화면에서 [매출처 등록] 버튼을 클릭해도 같은 화면이 탭으로 열립니다.

### 1. 📝 기본정보 입력

매출처의 구분·인적사항·연락처·분류를 차례대로 입력합니다.

**📌 구분**

- **매출처구분**을 개인·사업자·센터 중에서 선택하고, 사업자라면 **업종별구분**(일반·면세·간이)을 함께 지정합니다.
- **매출처형태**를 일반매출·직거래(도매)·오픈마켓 중에서 선택합니다.
**📌 인적사항**

- **가입자명**을 입력하고, 필요하면 대표자명·지점명·주민번호를 함께 입력합니다.
- **사원 매칭**의 🔍 버튼을 클릭해 이 매출처를 담당할 사원을 지정합니다.
- 온라인 채널을 연동한다면 **Shop ID·Shop Pwd**를 입력합니다.
- **성별·생년월일**을 선택하고, 사업자라면 업태·종목을 입력합니다.
**📌 연락처·주소**

- 전화번호·팩스번호·**핸드폰번호**를 입력하고, 문자를 받지 않을 번호는 **수신** 체크를 해제합니다.
- **우편번호**의 🔍 버튼으로 주소를 검색한 후 상세주소를 이어서 입력합니다.
- 세금계산서를 받을 주소는 **계산서 발행 이메일**에 따로 입력합니다.
**📌 분류·상태**

- **대분류·중분류**를 선택해 매출처를 분류하면 나중에 조건 조회에 활용할 수 있습니다.
- **영업담당자**를 지정하고 등록일을 확인합니다.
- **행사적용** 여부를 정하고, **거래상태**를 거래·중단·휴면·통합·폐업 중에서 선택합니다.
  - 위에서 선택한 매출처구분에서 **사용하지 않는 항목**은 선택할 수 없습니다.

### 2. 💳 결제·거래 정보 설정

이 매출처에 적용할 단가·포인트 적립과 외상 거래 조건을 정합니다.

**📌 결제정보(포인트적립)**

- **단가그룹**과 **등급선택**을 지정하고, 필요하면 회원카드번호를 입력합니다.
- **포인트 적립**을 적립·안함 중에서 선택합니다.
- **지급기준**을 사업장 기준·등급 적용·개별 적용 중에서 선택합니다.
- 개별 적용을 선택하면 **포인트·카드·현/영·외상 적립률(%)**을 직접 입력합니다.

**📌 거래정보**

- **여신거래**를 사용·안함·모두허용 중에서 선택하고, **세금계산서** 발행 여부를 지정합니다.
- 여신거래를 사용하면 **담보종류·담보금액**과 **담보시작일·담보종료일**, **여신금액**을 입력합니다.
- **양정 회전일**과 물류수수료·결제장려금·판매수수료(%)를 입력합니다.

### 3. 🗂️ 추가 정보 입력

탭을 클릭해 매출처의 부가 항목을 이어서 입력합니다.

**📌 탭 선택**

- 「담당자 연락처 및 설정」 : 담당자 연락처와 현금영수증 발급 방식을 등록합니다.
- 「배송주소 정보」 : 배송지 주소를 여러 개 등록합니다.
- 「서류 이미지」 : 사업자등록증 등 관련 서류 이미지를 첨부합니다.
- 「부가정보」 : 그 밖의 참고 항목을 입력합니다.

**📌 담당자 연락처 추가**

- [+ 추가] 버튼을 클릭해 담당자명·핸드폰번호·비고를 입력합니다.
- 여러 담당자를 등록하면 목록에 행이 계속 쌓이고, 등록 건수는 **총 : n건**에서 확인합니다.
- 잘못 넣은 담당자는 행을 선택한 후 [✕ 삭제] 버튼을 클릭해 제거합니다.

**📌 현금영수증발급설정(자동)**

- 결제 시 현금영수증을 자동 발급할 방식을 **안함·개인·사업자** 중에서 선택합니다.
- 개인 또는 사업자를 선택했다면 **발급번호**에 휴대폰번호나 사업자등록번호를 입력합니다.

### 4. 💾 신규등록

- 입력을 마친 후 [신규등록] 버튼을 클릭하면 매출처가 등록됩니다.
- 등록이 끝나면 매출처코드가 자동으로 부여되고 「매출처 목록」에서 조회할 수 있습니다.

### 🏷️ 자동으로 채워지는 항목

- **매출처코드·매출처명**은 직접 입력하지 않아도 등록을 완료하면 자동으로 채워집니다.
- **미수금**에서 해당 매출처의 남은 미수 금액을 확인합니다.

### 🔀 선택에 따라 달라지는 항목

- **매출처구분·업종별구분**을 무엇으로 고르느냐에 따라 아래쪽에서 입력할 수 있는 항목이 달라집니다.
- 개인을 선택하면 대표자명·지점명·종사업장번호·업태·종목이 회색으로 잠기고, 사업자를 선택하면 입력할 수 있게 열립니다.

### ❗ 필수 입력 항목

- **필수** 배지가 붙은 **가입자명**을 입력하지 않으면 등록되지 않습니다.

### 📋 기타 버튼

- [닫기(Esc)] : 화면을 닫습니다. 키보드 **Esc** 키로도 닫을 수 있습니다.

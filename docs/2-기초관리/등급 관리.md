# 등급 관리

회원 **등급별 적립 혜택**과 **적립 제외 상품**을 관리하는 화면입니다.

### 1. ✔️ 등급 선택

관리할 회원 등급을 선택합니다.

- 등록된 회원 등급(**BASIC · SILVER · GOLD · PLATINUM**) 중 하나를 클릭합니다.
- 선택한 등급의 적립 설정이 오른쪽 혜택설정에 표시됩니다.
  - 적용구분·적립률·적립제외상품수·비고를 목록에서 한눈에 비교할 수 있습니다.

### 2. 💰 혜택 설정

등급별 적립 기준과 적립률을 설정합니다.

- **적용구분**에서 결제금액 또는 판매금액을 선택해 적립 기준을 정합니다.
- **포인트 · 카드 · 현/영 · 외상** 적립률(%)을 각각 입력합니다.
  - **비고** 칸에 등급 설명이나 관리 메모를 남길 수 있습니다.

### 3. 💾 저장

- 적립률이나 제외 상품을 변경한 후 [수정] 버튼을 클릭해 저장합니다.

### 🧮 결제금액 기준 적립

- 적용구분을 **결제금액**으로 지정하면 판매금액에서 **상품 할인금액과 쿠폰 할인금액을 뺀 실제 결제금액**을 기준으로 적립됩니다.

### 📦 적립 제외상품 관리

- [+ 상품추가] 버튼을 클릭해 적립에서 제외할 상품을 검색·등록하면 해당 등급에서는 포인트가 적립되지 않습니다.
- 필요 없어진 상품은 체크한 후 [✕ 선택삭제] 버튼으로 제거합니다.
  - 등급마다 따로 지정하며, 지정하지 않아도 등급 설정은 저장됩니다.

### 📋 기타 버튼

- [🔍 새로고침] : 등급 목록을 최신 상태로 다시 불러옵니다.
- [⚙ 옵션] : 문서저장·도움말 메뉴를 표시합니다.
- [초기화] : 수정한 내용을 취소하고 이전 상태로 되돌립니다.

### 🔍 상품 통합검색

[+ 상품추가] 버튼으로 열리는 창입니다.

- 분류·매입처·상품 상태 등 상세 조건을 지정하거나, 통합검색·상품선택으로 상품을 직접 지정합니다.
- [검색] 버튼으로 조회한 후 등록할 상품을 체크합니다.
- [✓ 선택] 버튼을 클릭하면 적립 제외 상품으로 등록됩니다.

# 적립금 사용 현황

---

## 적립금 사용 현황

매출처별 **적립금 입금·사용 내역**과 **잔여 적립금**을 조회하는 화면입니다.

### 1. 🔍 적립금 검색

- 검색어를 입력하면 전체 항목에서 통합검색으로 조회됩니다.

- [🔍 상세검색] 버튼을 클릭하면 거래상태·등급·적립일·분류 등 상세 조건을 지정할 수 있습니다.
- → 「상세검색」 페이지 참고

### 2. ✅ 적립금 현황 확인

- 매출처별 **이전 적립금 · 입금금액 · 사용금액 · 잔여 적립금**을 확인합니다.
- 화면 하단에서 전체 **합계**를 확인할 수 있습니다.
- 매출처를 **더블클릭**하면 해당 매출처의 상세정보 화면이 열립니다. → 「적립금 상세정보」 페이지 참고

### ⚙️ 옵션

[⚙ 옵션] 버튼을 클릭하면 메뉴가 표시됩니다.

- **문서저장** : 조회된 내역을 **엑셀 · 워드 · PDF** 형식으로 저장합니다.
- **도움말** : 화면 사용 안내를 확인합니다.

---

## 상세검색

**상세 조건**을 지정해 적립금 사용 현황을 조회하는 화면입니다.

### 1. 🔍 상세 조건 지정

조회할 매출처의 조건을 지정한 후 검색합니다.

**📌 매출처 조건**

- 거래상태·단가그룹·등급을 선택하고 **적립일** 기간을 지정합니다.
  - 거래상태는 전체·거래·중단·휴면·폐업·통합 중에서 선택합니다.
**📌 분류·담당자 조건**

- 대분류·중분류를 선택하고 업태·종목·**영업담당자**로 조회 대상을 좁힙니다.
**📌 구분 조건**

- 구분(개인·사업자)·업종(면세·일반·간이)·형태·**지급수단**을 선택합니다.
**📌 통합검색**

- 검색어를 입력해 대상을 추가로 좁힌 후 [🔍 검색] 버튼을 클릭합니다.

### 2. ✅ 조회 결과 확인

- 지정한 조건에 해당하는 매출처의 적립금 현황이 조회됩니다.

💡 [닫기] 버튼을 클릭하면 상세검색 영역이 접힙니다.

## 적립금 상세정보

목록에서 매출처를 더블클릭하면 열리는 화면으로, 해당 매출처의 **적립금 적립·사용 내역**을 확인하고 **새 적립금을 지급**할 수 있습니다.

### 1. 🔍 매출처 선택

조회할 매출처와 기간을 지정합니다.

- 더블클릭한 **매출처**가 자동으로 지정됩니다.
- **시작일·종료일**을 지정한 후 [🔍 검색] 버튼을 클릭합니다.

### 2. ✅ 적립/차감 내역 확인

- **이전 적립금**부터 적립일·문서번호·사업장·구분·사유·결제구분을 확인합니다.
- **충전금액·추가적립·합계금액·사용금액**과 화면 하단의 합계를 확인할 수 있습니다.

### 3. 💾 적립금 지급관리

새로 적립할 내용을 입력한 후 적립합니다.

- **보유 적립금**에서 해당 매출처의 잔여 적립금을 확인할 수 있습니다.
- 적립일·작성일을 지정하고 **사유·구분·결제구분·은행정보**를 선택합니다.
- **충전금액**을 입력하면 추가적립과 함께 합계금액이 계산됩니다.
  - 필수 표시가 있는 항목은 모두 입력해야 적립할 수 있습니다.

- [+ 적립금 적립] 버튼을 클릭하면 입력한 내용으로 적립됩니다.
- 입력한 내용을 지우고 다시 작성하려면 [초기화] 버튼을 클릭합니다.

### 📋 내역 처리 버튼

순서와 상관없이 조회된 내역을 대상으로 사용합니다.

- [엑셀저장] : 조회된 내역을 엑셀 파일로 저장합니다.
- [✓ 적립금 지급취소] : 선택한 내역을 취소 처리합니다.
- [✕ 적립금 지급삭제] : 선택한 내역을 삭제합니다.

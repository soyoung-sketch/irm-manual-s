# FAX 전송

받는사람과 전송할 문서를 지정해 **FAX를 전송**하는 화면입니다.

### 1. 👤 받는사람 지정

팩스를 받을 대상을 추가합니다.

- **팩스번호**를 직접 입력하고 이름·회사명을 지정한 후 [✏ 입력추가] 버튼을 클릭합니다.
- [+ 매출처회원추가] [+ 매입처회원추가] 버튼으로 등록된 회원 목록에서 선택할 수도 있습니다.

### 2. ✅ 받는사람 목록 확인

- 추가된 대상의 **회사명·이름·팩스번호**를 확인합니다.
- 전송하지 않을 대상은 선택 후 [✕ 삭제] 버튼으로 제거합니다.

### 3. 📎 전송문서 첨부

팩스로 보낼 문서를 첨부합니다.

- [📁 폴더선택] [📄 파일선택] 버튼으로 전송할 문서를 불러옵니다.
- 첨부한 문서의 **파일명·파일경로·파일크기**를 확인할 수 있습니다.
- **스캔** 장비를 선택해 문서를 바로 스캔해서 첨부할 수도 있습니다.
- [✕ 전체삭제] [✓ 선택삭제] 버튼으로 첨부한 문서를 제거합니다.

### 4. 📤 추가 입력 후 전송

발신 정보를 입력하고 팩스를 보냅니다.

- **발신번호**와 **전송제목**을 입력합니다.
- **전송시간** : 실시간 또는 예약전송을 선택합니다.
- **전송용도** : 일반 안내는 업무용, 광고성은 광고용을 선택합니다.

- [⬇ 메세지 전송] 버튼을 클릭하면 지정한 대상에게 팩스가 전송됩니다.

### 📄 업로드 가능 확장자

- **pdf · tif · jpg · bmp · hwp · xlsx · xls · doc · docx · txt** 형식의 문서를 첨부할 수 있습니다.

### 👥 매출처·매입처 회원 목록

[+ 매출처회원추가] [+ 매입처회원추가] 버튼으로 열리는 창입니다.

- **통합검색·상세검색**으로 회원을 조회합니다.
- **멀티선택모드**를 체크하면 여러 회원을 한 번에 선택할 수 있습니다.
- 회원을 선택한 후 [✓ 선택] 버튼을 클릭하면 받는사람 목록에 추가됩니다.

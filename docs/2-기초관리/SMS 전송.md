# SMS 전송

검색 조건에 맞는 회원을 발송 대상에 추가한 후 **SMS·MMS** 메시지를 작성하여 **즉시 또는 예약 발송**하는 화면입니다.

### 1. 🔍 검색회원 추가

문자를 보낼 회원의 검색 조건을 설정한 후 [검색회원추가] 버튼을 클릭합니다.

- 매출처·매입처, 회원구분, 가입기간, 방문 여부, 구매금액 등의 조건을 설정할 수 있습니다.
- **수신거부 제외**를 선택하면 문자 수신을 거부한 회원을 제외하고 추가합니다.
- 조건에 해당하는 회원은 아래 **발송 대상 목록**에 추가됩니다.
  - 검색 결과를 확인하는 기능이 아니라, 조건에 맞는 회원을 바로 발송 대상 목록에 추가하는 기능입니다.

### 2. 👤 발송 대상 확인

추가된 회원의 회원코드, 가입자명, 전화번호를 확인합니다.

- 목록에 등록된 회원이 **문자 발송 대상**입니다.
- 발송하지 않을 회원은 선택을 해제하거나 상단 [삭제] 버튼으로 목록에서 제거합니다.
- 특정 회원만 추가하려면 상단 [회원추가] 버튼을 이용할 수 있습니다.

### 3. 📤 메시지 작성 및 전송

발송 형식과 용도를 선택해 문자 내용을 작성한 후 [문자 메시지 전송] 버튼을 클릭합니다.

- **SMS / MMS** 중 발송 형식을 선택합니다.
- 일반 안내는 **업무용**, 광고성 문자는 **광고용**을 선택합니다.
- MMS 발송 시 제목을 입력하고, 메시지 내용을 작성합니다.
- 작성 중인 메시지의 **글자 수·사용 용량**은 입력창 상단에서 확인할 수 있습니다.
  - 광고용 문자 발송 시에는 광고 문구와 수신거부 안내가 포함되어 있는지 확인합니다.

- **실시간**을 선택하면 메시지를 바로 발송합니다.
- **예약전송**을 선택하면 예약일과 전송시각을 지정해 그 시간에 발송합니다.
- 화면 하단에서 **보내는 번호**를 확인한 후 전송합니다.
- 입력한 내용을 모두 지우고 새로 작성하려면 [다시작성] 버튼을 클릭합니다.

### 🔤 회원 정보 치환 문구

회원마다 다른 내용이 자동으로 채워지도록 변수를 넣을 수 있습니다.

- [회원명 추가] 버튼을 클릭하면 **제목**에 회원명 변수가 삽입됩니다.
- [미수금 추가] 버튼을 클릭하면 **메시지 내용**에 미수금 변수가 삽입됩니다.
- 발송할 때 변수 자리에 회원별 **이름·미수금액**이 자동으로 표시됩니다.

### 🗂️ 메시지 템플릿

자주 사용하는 문자 내용을 미리 등록하고 불러와 사용할 수 있습니다.

- [➕ 추가] 버튼을 클릭하면 새로운 템플릿 카드가 등록됩니다.
- 템플릿 카드의 [선택]을 클릭하면 제목·내용이 **메시지 작성란에 적용**됩니다.
- [사진첨부] 버튼으로 템플릿창의 **레이아웃**을 설정합니다.
- [❌ 삭제] : 선택한 템플릿을 삭제합니다.
- [⬆ 위로] [⬇ 아래] : 위·아래로 넘겨가며 템플릿을 봅니다.

💡 **링크 메시지 작성** 탭은 준비중입니다.
    💡 발송 전에는 **대상 회원 수·전화번호·메시지 내용·발송 시점**을 다시 확인해주세요.

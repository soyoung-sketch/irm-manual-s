# 사원 관리

---

## 사원정보

사원의 **기본정보와 접근권한**을 등록하고 수정하는 화면입니다.

### 1. 🔍 조회 조건

- **사원구분**(일반사원·관리자·매입처 담당자·기타)과 **상태**(근무중·퇴사자)를 선택해 사원을 조회합니다.

### 2. ✔️ 사원 선택

- 조회된 목록에서 **사원**을 선택하면 우측에 상세정보가 표시됩니다.
- [찾기] 버튼으로 조회된 목록 안에서 다시 검색할 수 있습니다.

### 3. 💾 사원 정보 입력·저장

우측 패널에 정보를 입력한 뒤 저장합니다.

**📌 기본정보**

- **사원번호·사원ID·사원명**을 입력하고 근무지·부서·직위/직책·직무를 지정합니다.
- **비빌번호변경**을 변경으로 선택해 로그인 비밀번호를 재설정합니다.
- [✏ 등록] 버튼으로 사원 사진을 등록하고, [✕ 삭제] 버튼으로 제거합니다.

**📌 상세 정보**

- **핸드폰번호·전화번호·이메일·주소** 등 연락처를 입력합니다.
- 생일·결혼기념일·장애여부·보훈여부·입사일·추천자를 지정합니다.
- 퇴사한 사원은 **퇴사일·퇴사사유**를 입력합니다.

**📌 접근권한·사원구분**

- **IRM(SHOP·WMS·AMS)·POS·GW·PDM·PDA·SCM** 등 사용할 시스템을 선택하고 **기본메뉴**에서 로그인 시 열릴 메뉴를 지정합니다.
- **사원구분**과 **근무 상태**(근무중·퇴사)를 지정합니다.

**📌 저장**

- [+ 수정] 버튼을 클릭하면 입력한 내용이 저장됩니다.

### 🆕 신규작성

- [신규작성] 버튼을 클릭하면 입력값이 초기화되어 새 사원을 등록할 수 있습니다.

### 🖨️ 사원증 인쇄

- [🖨 사원증 인쇄] 버튼을 클릭해 인쇄할 사원증 크기를 선택합니다.
- **6.8Cm × 2.2Cm · 7Cm × 3Cm · 7.5Cm × 5Cm · 9Cm × 6Cm** 중에서 선택할 수 있습니다.

# 상품등록

---

## 규격관리

판매할 상품의 **기본정보**와 **규격·단위·판매가·바코드**를 등록하는 화면입니다.

### 1. 📝 상품 기본정보 입력

상품을 식별할 정보와 판매 상태를 입력합니다.

- **매입처**를 지정하면 해당 매입처의 상품으로 등록됩니다.
- **상품코드**는 등록할 때 자동으로 부여되고, 규격과 재고수는 등록한 단위 기준으로 표시됩니다.

**📌 상품 기본정보**

- **상품명 · 대분류 · 관리부서**는 반드시 입력해야 하는 필수 항목입니다.
- 서브명·POP상품명을 입력하면 출력물에 해당 이름으로 표시됩니다.
- 상품구분(상품/반제품/품목)과 단위구분(수량/중량), **과세구분**을 선택합니다.
- 중분류·소분류·세분류와 제조사·브랜드·원산지를 지정해 상품을 분류합니다.
- 공병금액을 **사용**으로 지정하면 금액을 입력할 수 있습니다.

**📌 상품 상태정보**

- 포인트적립·추가적립의 적립 여부와 적립할 금액을 지정합니다.
- **매입상태 · 판매상태**를 매입중·판매중으로 두어야 매입·판매에 사용할 수 있습니다.
- 판매구분에서 **매장 · 도매몰 · 쇼핑몰** 중 판매할 채널을 선택하고 매장상태를 지정합니다.
  - 「상품 추가정보」 「부가정보」 탭으로 넘기면 나머지 항목을 입력할 수 있습니다.

### 2. 📐 규격·단위 등록

입·출고 규격과 상품을 담는 단위를 등록합니다.

- 입고와 출고에 사용할 **최소 규격**을 선택하고, 단량과 **내품수**를 입력하면 규격이 계산되어 표시됩니다.

**📌 단위(내품수)관리**

- [+ 단위추가] 버튼을 클릭해 내품수와 단위를 입력하면 단위가 추가됩니다.
- 추가한 단위의 **규격 · 가로 · 세로 · 높이 · 중량(G)**을 입력합니다.
- 매입/매출에 사용할 **기준단위**를 선택합니다.
- 삭제할 단위를 선택한 후 [✕ 단위삭제] 버튼을 클릭합니다.

### 3. 💰 판매가 관리

- 단위별로 **매입가 · 판매단가**를 입력하면 마진율(%)이 함께 계산됩니다.
- 거래처에 따라 다르게 적용할 **PriceB · PriceC**를 추가로 등록할 수 있습니다.
- 매입·매출에 사용할 **기준 단위**를 체크합니다.
  - 가로 스크롤을 이동하면 사업장 등 나머지 항목을 확인할 수 있습니다.

### 4. 🔖 바코드관리

- [바코드추가] 버튼을 클릭해 내품수와 바코드를 입력하면 바코드가 추가됩니다.
- 바코드를 직접 입력하거나 [생성] 버튼으로 **새 바코드를 만들어** 등록합니다.
- 여러 개를 등록한 경우 **기준** 열에서 대표로 사용할 바코드를 지정합니다.
- 삭제할 바코드를 선택한 후 [✕ 바코드삭제] 버튼을 클릭합니다.

### 5. 💾 상품 등록

- 입력을 마친 후 [신규등록(F5)] 버튼을 클릭하면 상품이 등록됩니다.
  - 필수 표시가 있는 항목을 모두 입력해야 등록할 수 있습니다.

### ✅ 바코드 체크

- 바코드가 등록된 상품이면 **체크 표시**가 나타나므로 바코드 등록 여부를 한눈에 확인할 수 있습니다.

### 📤 엑셀 업로드

- [엑셀 업로드] 버튼을 클릭하면 엑셀 양식으로 여러 상품을 **한 번에 등록**할 수 있습니다.

### ➕ 단위정보 추가

[+ 단위추가] 버튼으로 열리는 창입니다.

- **내품수**를 입력하고 **단위**를 선택한 후 [+ 추가] 버튼을 클릭하면 단위가 등록됩니다.

### 🔖 바코드 정보 추가

[바코드추가] 버튼으로 열리는 창입니다.

- **내품수**를 선택하고 바코드를 입력한 후 [+ 추가] 버튼을 클릭하면 바코드가 등록됩니다.
- 사용할 바코드가 없으면 [생성] 버튼을 클릭해 바코드 생성 창을 엽니다.

**📌 바코드 생성**

- **기준코드**를 선택하면 그 코드로 시작하는 바코드정보가 만들어집니다.
- [바코드생성] 버튼을 클릭하면 생성한 바코드가 **바코드 정보 추가** 창에 채워집니다.
  - [선택] 버튼으로 이미 만들어 둔 바코드 중에서 지정할 수도 있습니다.

### 🗂️ 우측 패널 탭

- 「규격관리」 : 입·출고 규격과 단위·판매가·바코드를 등록합니다.
- 「이미지」 : 상품 이미지를 등록합니다. → 「이미지」 페이지 참고
- 「고시정보」 : 상품군별 고시항목을 입력합니다. → 「고시정보」 페이지 참고

## 이미지

상품에 사용할 **이미지 파일**을 등록하고 대표 이미지를 지정하는 화면입니다.

### 1. 🖼️ 이미지 추가

- [+ 추가] 버튼을 클릭한 후 등록할 **이미지 파일**을 선택합니다.

### 2. ✅ 등록 이미지 확인

- 등록한 **이미지와 파일명**을 확인합니다.
- 여러 장을 등록한 경우 **기준** 열에서 대표로 사용할 이미지를 지정합니다.
- 삭제할 이미지를 선택한 후 [✕ 삭제] 버튼을 클릭합니다.

💡 상품명·분류·상태정보 등 **상품 기본정보**는 모든 탭에서 공통으로 입력합니다. → 「규격관리」 페이지 참고

## 고시정보

상품군별로 정해진 **상품 고시정보** 항목을 입력하는 화면입니다.

### 1. 🗂️ 상품군 선택

- 등록할 상품에 해당하는 **상품군**을 선택하면 입력할 고시 항목이 표시됩니다.

### 2. 📝 고시정보 입력

- 표시된 **항목**별로 내용을 입력합니다.
- 상품군을 바꾸면 항목이 다시 구성되므로 **상품군을 먼저 확정**한 후 입력합니다.

💡 상품명·분류·상태정보 등 **상품 기본정보**는 모든 탭에서 공통으로 입력합니다. → 「규격관리」 페이지 참고

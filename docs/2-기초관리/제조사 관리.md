# 제조사 관리

상품에 사용할 **제조사를 등록·삭제**하고 조회하는 화면입니다.

### 1. 📝 제조사 등록

- 등록할 **제조사명**을 입력한 후 [+ 저장] 버튼을 클릭하면 목록에 추가됩니다.
  - 코드는 저장할 때 자동으로 부여됩니다.

### 2. ✅ 제조사 목록 확인

- 등록된 제조사의 **코드 · 제조사명 · 비고**를 확인합니다.

### 3. 🗑️ 제조사 삭제

- 목록 왼쪽의 **체크박스**를 클릭해 삭제할 제조사를 선택합니다.
- 머리글의 체크박스를 클릭하면 조회된 제조사가 **전체 선택**됩니다.

- [✕ 삭제] 버튼을 클릭하면 체크한 제조사가 목록에서 삭제됩니다.
  - 상품에 이미 사용 중인 제조사는 삭제되지 않을 수 있습니다.

### 🔍 결과내 재검색

- 검색어를 입력한 후 [찾기] 버튼을 클릭하면 조회된 목록 안에서 다시 검색됩니다.

### 🕒 등록·수정 이력 확인

- 제조사를 등록한 **등록ID · 등록자 · 등록일**을 확인합니다.
- 이후 내용이 변경된 경우 **수정ID · 수정자 · 수정일**이 함께 표시됩니다.

### 📋 기타 버튼

- [닫기] : 제조사 관리 화면을 닫습니다.

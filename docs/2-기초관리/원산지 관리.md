# 원산지 관리

상품의 원산지를 **대분류·중분류·소분류** 3단계로 등록하고 관리하는 화면입니다.

### 1. 🌳 원산지 분류 조회

- 검색어를 입력한 후 [찾기] 버튼을 클릭하면 해당 원산지를 바로 찾아줍니다.

- 사업장명 아래의 **국산·수입산·기타**를 펼치면 그에 속한 중분류·소분류까지 확인할 수 있습니다.

### 2. 📁 대분류 선택·등록

- 관리할 대분류를 **클릭**해 선택하면 하위 중분류가 표시됩니다.
- 등록된 대분류의 **원산지명**과 **세분류출력** 여부, 표시 **순서**를 확인합니다.
  - 가로 스크롤을 이동하면 순서 열을 확인할 수 있습니다.

- 입력칸에 원산지명을 입력하고 [+] 버튼을 클릭하면 새 대분류가 추가됩니다.
- 삭제할 대분류를 체크한 후 [✕] 버튼을 클릭하면 삭제됩니다.
- 대분류를 선택한 후 [▲] [▼] 버튼을 클릭하면 **순서**가 한 칸씩 이동합니다.
  - 순서는 상품등록 화면에서 원산지를 고를 때 표시되는 차례입니다.

### 3. 📂 중분류 선택·등록

- 관리할 중분류를 **클릭**해 선택하면 하위 소분류가 표시됩니다.
- 선택한 대분류에 속한 중분류의 **원산지명**과 표시 **순서**를 확인합니다.
  - 국산은 강원·경기·경남 등 17개 시·도로 나뉩니다.

- **대분류를 먼저 선택**한 후 입력칸에 원산지명을 입력하고 [+] 버튼을 클릭합니다.
- 삭제할 중분류를 체크한 후 [✕] 버튼을 클릭하면 삭제됩니다.
- 중분류를 선택한 후 [▲] [▼] 버튼을 클릭하면 **순서**가 한 칸씩 이동합니다.

### 4. 📄 소분류 선택·등록

- 선택한 중분류에 속한 소분류의 **원산지명**과 표시 **순서**를 확인합니다.
  - 강원을 선택하면 전체·강릉시·고성군 등 시·군이 표시됩니다.

- **중분류를 먼저 선택**한 후 입력칸에 원산지명을 입력하고 [+] 버튼을 클릭합니다.
- 삭제할 소분류를 체크한 후 [✕] 버튼을 클릭하면 삭제됩니다.
- 소분류를 선택한 후 [▲] [▼] 버튼을 클릭하면 **순서**가 한 칸씩 이동합니다.

### 🖨️ 세분류출력

- **세분류출력**은 대분류에만 있는 항목으로, 체크하면 원산지를 표시할 때 중분류·소분류까지 함께 출력됩니다.
- 체크를 해제하면 해당 대분류는 **대분류명만** 출력됩니다.

### 🔗 대분류–중분류–소분류 연동

- 대분류를 **클릭**하면 그에 속한 중분류만, 중분류를 **클릭**하면 그에 속한 소분류만 표시됩니다.
- 하위 분류를 추가하려면 **상위 분류를 먼저 선택**해야 합니다.

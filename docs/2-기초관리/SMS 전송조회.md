# SMS 전송조회

발송한 **SMS 전송 내역**과 **수신 대상**을 조회하는 화면입니다.

### 1. 📅 등록일 기간 지정 후 검색

- **등록일**의 시작일과 종료일을 지정합니다.
  - 날짜 입력창을 클릭하면 기간을 빠르게 지정하는 버튼이 표시됩니다.

- [🔍 검색] 버튼을 클릭하면 기간 내 전송 내역이 조회됩니다.

### 2. ✅ 전송 내역 확인

조회된 목록에서 발송 결과를 확인하고, 상세를 볼 전송 건을 클릭합니다.

**📌 확인할 수 있는 항목**

  - 전송구분 · 수신거부 · 전송모드 · 사업장명 · 발신번호 · 전송담당자
  - 제목 · 전송내역 · 예약일 · 등록일

### 3. 👤 수신 대상·전송 내용 확인

- 선택한 전송 건의 **회원코드·회원명·수신번호**로 누구에게 보냈는지 확인합니다.

- 발송된 **메시지 내용**으로 어떤 문구가 전송됐는지 확인합니다.

### 📅 기간 빠른 선택

날짜 입력창을 클릭하면 표시되는 버튼입니다.

- [+ 오늘] [1 전일] [7 7일] [31 30일] 버튼으로 조회 기간을 빠르게 지정합니다.
- [↻ 초기화] 버튼으로 지정한 기간을 초기화합니다.

# 통합 목록 조회

---

## 통합회원

여러 매출처를 **하나의 통합회원**으로 묶은 이력을 조회하고, 필요하면 **통합을 취소**하는 화면입니다.

### 1. 🔍 통합 목록 검색

- 검색어를 입력하면 전체 항목에서 조회됩니다.

- [🔍 상세검색] 버튼을 클릭하면 거래상태·등급·등록일·분류 등 상세 조건을 지정할 수 있습니다.
- → 「상세검색」 페이지 참고

### 2. ✅ 통합 목록 확인

- **통합일자**와 사업장코드·사업장명·매출처코드·매출처명을 확인합니다.
- 통합을 처리한 **담당자ID·담당자명**과 통합된 **적립금·포인트**를 확인합니다.

### 3. 👥 통합된 매출처 확인

- 목록에서 통합 건을 선택하면 **합쳐진 매출처**의 사업장·매출처 정보와 적립금·포인트가 표시됩니다.

### 4. 🚫 통합 취소

- 통합 건을 선택한 후 [취소] 버튼을 클릭하면 통합이 취소됩니다.
- 취소한 건은 「취소」 탭에서 확인할 수 있습니다.

### 🔢 조회 건수 확인

- 목록 위·아래의 **총: N건**에서 현재 탭에 조회된 통합 건수를 확인합니다.
- 탭을 바꾸면 해당 탭의 건수로 다시 표시됩니다.

### 🗂️ 탭 구성

- 「통합회원」 : 통합 처리된 건을 조회합니다.
- 「취소」 : 통합을 취소한 이력을 조회합니다.
- 「전체」 : 전체 통합 이력을 조회합니다.

### ⚙️ 옵션

[⚙ 옵션] 버튼을 클릭하면 메뉴가 표시됩니다.

- **문서저장** : 조회된 내역을 **엑셀 · 워드 · PDF** 형식으로 저장합니다.
- **도움말** : 화면 사용 안내를 확인합니다.

## 취소

통합을 **취소한 이력**을 조회하는 탭입니다.

### 1. ✅ 취소 이력 확인

- 취소된 통합 건의 **통합일자**·사업장·매출처·담당자를 확인합니다.
- 통합 당시 합산되었던 **적립금·포인트**를 함께 확인할 수 있습니다.

### 2. 👥 통합됐던 매출처 확인

- 목록에서 취소 건을 선택하면 **합쳐졌던 매출처**의 정보와 적립금·포인트가 표시됩니다.

### 🔢 조회 건수 확인

- 목록 위·아래의 **총: N건**에서 취소된 통합 건수를 확인합니다.

💡 **조회 전용** 탭으로, 이미 취소된 건이므로 [취소] 버튼이 표시되지 않습니다.

---

## 전체

**전체 통합 이력**을 조회하는 탭입니다.

### 1. ✅ 전체 이력 확인

- 통합일자·사업장·매출처·담당자와 **적립금·포인트**를 확인합니다.
- 조회된 내역이 없으면 목록이 비어 있는 상태로 표시됩니다.

### 2. 👥 통합된 매출처 확인

- 목록에서 통합 건을 선택하면 **합쳐진 매출처**의 정보와 적립금·포인트가 표시됩니다.

### 🔢 조회 건수 확인

- 목록 위·아래의 **총: N건**에서 조회된 통합 건수를 확인합니다.
- 조회 결과가 없으면 **총: 0건**으로 표시됩니다.

💡 **조회 전용** 탭으로 [취소] 버튼이 표시되지 않습니다. 통합을 취소하려면 「통합회원」 탭을 이용합니다.

## 상세검색

**상세 조건**을 지정해 통합 목록을 조회하는 화면입니다.

### 1. ✔️ 조회 조건 지정

**📌 매출처 조건**

- **거래상태**를 전체·거래·중단·휴면·폐업·통합 중에서 선택합니다.
- **단가그룹·등급**을 선택하고 **등록일** 기간을 지정해 대상을 좁힙니다.

**📌 분류·담당자 조건**

- **대분류·중분류**를 선택해 조회할 분류를 지정합니다.
- 업태·종목·**영업담당자**로 조건을 추가할 수 있습니다.

**📌 구분 조건**

- **구분**(개인·사업자)과 **업종**(면세·일반·간이)을 선택합니다.
- **형태**(직거래(도매)·일반매출·오픈마켓)와 **지급수단** 사용 여부를 선택합니다.

### 2. 🔍 통합검색

- 검색 항목을 선택하고 검색어를 입력해 조회 대상을 추가로 좁힙니다.
- [🔍 검색] 버튼을 클릭하면 지정한 조건으로 조회됩니다.

### 3. ✅ 조회 결과 확인

- 지정한 조건에 해당하는 **통합 목록**이 조회됩니다.
- 통합 건을 선택하면 우측에 **합쳐진 매출처**가 함께 표시됩니다.

💡 [닫기] 버튼을 클릭하면 상세검색 영역이 접힙니다.

# 매입처 등록

[+ 매입처 등록] 버튼으로 열리는 화면으로, 새 **매입처를 등록**합니다.

### 1. 📝 기본정보 입력

매입처의 기본 정보를 차례로 입력합니다.

  - 매입처코드는 등록할 때 자동으로 부여됩니다.
**📌 구분 지정**

- **매입처구분**(사업자·개인·본사(센터))과 **업종별구분**(일반·면세·간이)을 선택합니다.
- **매입처형태**를 일반매입·임대업장(입점사업자)·매장(직영)·판매분수수료·x-dock·창고·일반(매입처배송)·쇼핑몰입점 중에서 선택합니다.

**📌 사업자·연락처**

- **사업자등록번호**와 **매입처명(상호)**을 입력하고 종사업장번호·지점명·대표자명·업태·종목을 채웁니다.
- 전화번호·팩스번호·핸드폰번호를 입력합니다.
- 우편번호를 검색해 기본주소를 채운 뒤 상세주소와 이메일을 입력합니다.

**📌 분류·담당**

- **대분류 · 중분류 · 소분류**를 차례로 선택합니다.
- 주류업 구분·SCM·매입가 변경 유무를 지정합니다.
- **영업담당자**와 등록일을 지정하고 **거래상태**(거래·중단·폐업)를 선택합니다.

### 2. 💳 거래·결제정보 입력

- **여신거래**를 여(사용)로 선택하면 담보종류·담보금액·담보시작일·담보종료일을 입력할 수 있습니다.
  - 부(안함)를 선택하면 담보 항목이 비활성화됩니다.

- **결제수단**(현금·어음·카드(주류))과 **결제주기**(즉시결제·당월결제·익월결제·익익월결제)를 선택합니다.
- **결제일**을 지정합니다.

### 3. 🏦 은행정보·부가 탭 입력

- [+ 추가] 버튼으로 은행명·예금주·계좌번호·비고를 등록하고, [✕ 삭제] 버튼으로 제거합니다.
- 「서류 이미지」 · 「발주관리」 · 「매입처 입점정보」 · 「부가정보」 탭에서 나머지 정보를 등록합니다.

### 4. 💾 신규등록

- [💾 신규등록(F5)] 버튼을 클릭하면 입력한 내용으로 매입처가 등록됩니다.
- [닫기(Esc)] 버튼을 클릭하면 매입처 등록 화면이 닫힙니다.

### ❗ 필수 입력 항목

- **필수** 배지가 붙은 **사업자등록번호 · 매입처명(상호) · 등록일**은 모두 채워야 등록할 수 있습니다.

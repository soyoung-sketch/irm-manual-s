# 사업장 상품관리

---

## 사업장 상품관리

사업장에 등록된 **상품 목록**을 조회하고, 상품 정보를 수정하거나 여러 상품을 **한 번에 처리**하는 화면입니다.

### 1. 🔍 상품 조회

- 특정 상품을 조회하고자 할 때는 조회할 **상품정보(상품명, 상품코드)**를 입력하고 **엔터**를 눌러 조회하세요.
- [🔍 상세검색] 버튼을 클릭하면 카테고리·매입처·재고 등 상세 조건을 지정해서 검색하실 수 있습니다.

### 2. ✅ 상품 목록 확인

- 상품정보를 확인합니다. (타입, 재고, 분류, 행사여부, 판매가정보 등등)
  - 가로 스크롤을 이동하면 나머지 항목을 확인할 수 있습니다.

### 3. ✏️ 상품수정

- 수정할 상품을 선택한 후 [상품수정] 버튼을 클릭하면
  상품수정 화면이 열립니다.
- 행 오른쪽 끝의 [보기] 버튼을 클릭해도 해당 상품의
  상품수정 화면이 바로 열립니다.
- 🔗 **상품수정 화면 바로가기**

### 🔤 열별 필터 검색

- 열 머리글 아래 **필터 칸**에 값을 입력하면
  해당 열 기준으로 목록이 걸러집니다.

### 🗂️ 선택한 상품으로 실행하는 기능

- [매입처 지정] 버튼을 클릭하면 **매입처 목록** 창이 열립니다.
  매입처를 선택한 후 [선택] 버튼을 클릭하면 선택한 상품에 매입처가 지정됩니다.
- [바코드인쇄] [POP 인쇄] 버튼을 클릭하면 선택한 상품으로 **매장관리**의 해당 인쇄 화면이 열립니다.
- [재고수불내역] 버튼을 클릭하면 **재고관리 > 상품 수불 내역** 화면이 열립니다.

### 📋 목록 표시 옵션

- **개별선택모드** : 처리할 상품만 하나씩 골라 체크할 수 있습니다.
- **상세화면 새창으로 보기** : 별도의 창에서 상세 정보를 확인할 수 있습니다.

### 🔄 상품정보 일괄변경

변경할 상품을 선택한 후 [상품정보 일괄변경] 버튼을 클릭하고 바꿀 항목을 고릅니다.

**📌 분류·담당 항목**

- **카테고리 · 관리부서 · 담당자(정) · 담당자(부)**를 선택한 상품에 한 번에 지정합니다.
- **원산지 · 제조사 · 브랜드 · 보관방법**을 한 번에 지정합니다.
**📌 신고·그룹 항목**

- **유니패스이력신고 · 상품 그룹관리**를 한 번에 지정합니다.
**📌 판매 상태 항목**

- **사업장 판매상태**와 **매장 판매(사용)구분 · 쇼핑몰 판매구분 · POP 출력구분**을 한 번에 변경합니다.

### 🗂️ 행사·상태·변경 이력

목록에서 상품을 클릭한 후 탭을 바꿔가며 해당 **상품 이력**을 확인합니다.

**📌 행사정보**

- 진행 중인 행사의 **행사구분·제목·기간·행사 판매가**를 확인합니다.
  [행사추가] 버튼으로 상품을 행사에 넣고, [POP 인쇄] 버튼으로
  행사 POP를 출력합니다. 탭 아래에 상품이 진열된 **로케이션**이
  대 > 중 > 소 > 세 순으로 표시됩니다.
**📌 상품상태 관리**

- 관리부서·담당자와 **매입상태·판매상태**를 확인하고
  [상품정보 수정] 버튼으로 고칩니다.
**📌 매입가 변경내역**

- 매입가가 바뀐 **확정일·매입가·매입처**를 확인합니다.
**📌 판매가 변경내역**

- 판매가가 바뀐 **수정일·수정자·판매단가**를 확인합니다.

### 💰 상품 판매가 정보

선택한 상품의 가격을 확인합니다.

- 내품수·단위·규격과 **매입가 · 판매단가**, 마진율(%)을 확인합니다.
- **PriceB · PriceC**에서 단가그룹별 판매가와 적용 모드·값을 확인합니다.
  - **B · C** 체크로 단가그룹의 표시 여부를 선택합니다.
- [판매정보 수정] 버튼을 클릭하면 판매가를 바로 고칠 수 있습니다.

### ⚙️ 옵션

[⚙ 옵션] 버튼을 클릭하면 메뉴가 표시됩니다.

- **문서저장** : 조회된 목록을 **엑셀 · 워드 · PDF** 형식으로 저장합니다.
- **도움말** : 화면 사용 안내를 확인합니다.

## 상품수정 - 상품상세

[상품수정] 또는 [보기] 버튼으로 열리는 창으로, 상품의 **상세정보를 확인하고 수정**하는 화면입니다.

### 1. 🔍 상품 선택

수정할 상품을 찾아 선택합니다.

- **매입처 · 카테고리**를 지정하거나 **통합검색**에 검색어를 입력한 후 [검색] 버튼을 클릭합니다.
- 조회된 목록에서 상품을 클릭하면 오른쪽에 해당 상품의 정보가 표시됩니다.
  - 창을 닫지 않고 상품을 바꿔가며 연속으로 수정할 수 있습니다.

### 2. 📝 상품 정보 수정

상품상세 탭에서 이 상품의 정보를 확인하고 고칩니다.

**📌 입·출고 규격**

- **입/출고 최소 규격**과 **단량 · X내품수**를 입력합니다.
**📌 상품명**

- **상품명**(필수)과 **서브명 · POP상품명**을 입력합니다.
**📌 구분·분류**

- **상품구분**(상품·반제품·품목)과 **과세구분**(과세·면세·영세)을 선택합니다.
- **대분류 · 중분류 · 소분류 · 세분류**를 지정합니다.
- **관리부서 · 제조사 · 브랜드 · 원산지**를 지정하고
  **공병금액** 사용 여부를 선택합니다.
**📌 상태정보**

- **포인트적립 · 추가적립** 여부와 **매입상태**(매입중·안함) · **판매상태**(판매중·안함)를 선택합니다.
- **매장상태**를 지정합니다.
- 「상품 추가정보」 「부가정보」 탭에서 나머지 항목을 입력합니다.
**📌 행사정보**

- 이 상품이 포함된 행사의 **행사구분·행사제목·기간·행사 판매가**를 확인합니다.
- [행사추가] 버튼으로 상품을 행사에 넣고, [POP 인쇄]
  버튼으로 행사 POP를 출력합니다.
**📌 단위(내품수)관리**

- **기준단위**를 선택하고 내품수·단위·규격과 가로·세로·높이·중량을 확인합니다.
- [+ 단위추가] 버튼으로 단위를 추가하고,
  [✕ 단위삭제] 버튼으로 삭제합니다.
**📌 판매가 관리**

- 내품수·단위별 **매입가 · 판매단가**를 확인하고 수정합니다.
- **PriceB · PriceC**에 단가그룹별 판매가와 적용 모드·값을 지정합니다.
  - 가로 스크롤을 이동하면 나머지 항목을 확인할 수 있습니다.
**📌 바코드관리**

- 상품에 등록된 **단위별 바코드**를 확인하고 **기준** 바코드를 지정합니다.
- [바코드추가] 버튼으로 바코드를 추가합니다.
- 수정한 내용은 화면 오른쪽 위 [💾 저장(F5)] 버튼을 클릭해야 반영됩니다.

💡 위쪽 탭에서 「매입매출」 「매입관리」 「매출집계」 「POS 매출」 「재고정보」 「판매가격변경내역」을 클릭하면 선택한 상품의 거래 내역을 확인할 수 있습니다.

## 상품수정 - 매입매출

선택한 상품의 **기간별 매입·매출 실적**을 날짜별로 확인하는 탭입니다.

💡 왼쪽 검색 목록에서 상품을 클릭하면 해당 상품의 내역으로 바뀝니다. → 「상품수정 - 상품상세」 페이지 참고

### 1. 📅 기간 지정 조회

- **시작일 · 종료일**을 지정한 후 [🔍 검색] 버튼을 클릭합니다.

### 2. ✅ 매입·매출 내역 확인

- **매입** 항목에서 날짜별 매입수량·매입총계·공급가액·부가세·면세금액을 확인합니다.
- **매출** 항목에서 매출수량·총매출액·순매출액과 **이익금액·이익률**을 확인합니다.
- 화면 아래쪽에서 기간 전체의 **합계**를 확인할 수 있습니다.

### 🗂️ 항목별 그룹 조회

- 열 머리글을 **클릭 앤 드래그**로 끌어다 놓으면 해당 항목 기준으로 묶어서 조회됩니다.

### 🔎 결과내 재검색

- 검색어를 입력한 후 [찾기] 버튼을 클릭하면 조회된 내역 안에서 다시 찾습니다.

## 상품수정 - POS 매출

선택한 상품이 **POS에서 판매된 건별 내역**을 확인하는 탭입니다.

💡 왼쪽 검색 목록에서 상품을 클릭하면 해당 상품의 내역으로 바뀝니다. → 「상품수정 - 상품상세」 페이지 참고

### 1. 📅 기간 지정 조회

- **시작일 · 종료일**을 지정한 후 [🔍 검색] 버튼을 클릭합니다.

### 2. ✅ POS 판매 내역 확인

- 매출일자·**포스번호**·전표번호·**시간**으로 어느 포스에서 언제 팔렸는지 확인합니다.
- **판매구분 · 할인구분 · 행사구분**으로 어떤 조건으로 팔렸는지 확인합니다.
- **수량 · 매출단가 · 할인액 · 매출금액**과 이익률을 확인합니다.
  - 수량이 **음수(-1)**로 표시된 행은 **취소된 판매** 건입니다.
- **사업자번호**로 구매한 고객을 확인합니다.
  - 가로 스크롤을 이동하면 나머지 항목을 확인할 수 있습니다.

### 🗂️ 항목별 그룹 조회

## 상품수정 - 재고정보

선택한 상품의 **입고·출고 수불 내역**과 재고가 어떻게 변해왔는지 확인하는 탭입니다.

### 1. 📅 기간 지정 조회

- **시작일 · 종료일**을 지정한 후 [🔍 검색] 버튼을 클릭합니다.

### 2. ✅ 수불 내역 확인

- **거래정보**에서 거래일·전표번호·구분으로 어떤 거래인지 확인합니다.
- **사업장정보 · 업체정보**에서 입고·출고 사업장과 매입처명·매출처명을 확인합니다.
- **이전재고**와 **현재고**를 비교하면 거래 한 건으로 재고가 얼마나 바뀌었는지 알 수 있습니다.
**📌 입고정보(+) — 파란색 영역**

- 재고를 **늘린** 수량을 **매입 · 판매반품 · 소분입고** 등 항목으로 나누어 확인합니다.
**📌 출고정보(-) — 가로 스크롤 오른쪽**

- 가로 스크롤을 오른쪽으로 옮기면 재고를 **줄인** **판매 · 매입반품** 등의 항목이 나타납니다.

## 상품수정 - 판매가격변경내역

선택한 상품의 **판매가격이 언제, 누구에 의해 바뀌었는지** 이력을 확인하는 탭입니다.

### 1. 🔍 상품 선택

이력을 확인할 상품을 찾아 선택합니다.

- **매입처 · 카테고리**를 지정하거나 **통합검색**에 검색어를 입력한 후 [검색] 버튼을 클릭합니다.
- 조회된 목록에서 상품을 클릭하면 오른쪽에 해당 상품의 변경 이력이 표시됩니다.
  - 창을 닫지 않고 상품을 바꿔가며 연속으로 확인할 수 있습니다.

### 2. ✅ 변경 이력 확인

판매가격이 바뀐 기록을 한 줄씩 확인합니다.

- **수정일**과 **수정자ID · 수정자명**으로 언제 누가 바꿨는지 확인합니다.
- 규격·단위·내품수와 바뀐 **판매단가 · PriceB · PriceC**를 확인합니다.
- 이어서 **매입단위 · 판매단위**와 **사업장 · 쇼핑몰 · 도매몰** 항목이 표시됩니다.
  - 가로 스크롤을 이동하면 오른쪽 끝 **비고**까지 확인할 수 있습니다.

💡 **조회 전용** 탭으로, 이력을 고치거나 지울 수는 없습니다.

# 포인트 지급/차감

매출처의 **포인트 적립·차감 내역**을 확인하고 **관리자 포인트를 지급**하는 화면입니다.

### 1. 🔍 매출처 선택

조회할 매출처와 기간을 지정합니다.

- **매출처명**을 선택하고 **시작일·종료일**을 지정한 후 [🔍 검색] 버튼을 클릭합니다.

### 2. ✅ 포인트 내역 확인

- **이전 포인트**부터 적립일·문서번호·구분·사업장명을 확인합니다.
- **추가 포인트(+)** : 매출적립·결제취소·수금취소·관리자·결제·매출반품 항목별로 적립된 포인트를 확인합니다.
- **차감 포인트(-)**와 화면 하단의 합계를 확인할 수 있습니다.

### 3. 📝 포인트 지급

관리자가 직접 지급할 포인트를 입력하고 지급합니다.

- **보유 포인트**에서 해당 매출처의 현재 포인트를 확인할 수 있습니다.
- 적립일·작성일을 지정하고 **적립사유**를 선택합니다.
- 지급할 **포인트**를 입력합니다.
  - 필수 표시가 있는 항목은 모두 입력해야 지급할 수 있습니다.

- [+ 포인트지급] 버튼을 클릭하면 입력한 포인트가 지급됩니다.
- 입력한 내용을 지우고 다시 작성하려면 [초기화] 버튼을 클릭합니다.

### 📋 기타 버튼

- [✓ 포인트 지급취소] : 선택한 내역을 취소 처리합니다.
- [✕ 포인트 지급삭제] : 선택한 내역을 삭제합니다.

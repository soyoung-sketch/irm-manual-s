# 사업장 관리

---

## 기본정보

사업장의 **기본정보**를 등록하고 도장·영수증 메시지를 설정하는 화면입니다.

### 1. 🏢 사업장 정보 입력

- **사업장코드·사업장명**을 입력하고 **사업장구분**(본사·물류센터·공장·매장·창고 등)을 선택합니다.
- **사업자번호·대표자명·업태·종목**과 주소·전화번호를 입력합니다.

- 문자·팩스 발송에 사용할 **핸드폰·팩스번호·이메일**을 입력합니다.
- **사용상태**를 사용중 또는 사용안함으로 지정합니다.

### 2. 🧾 도장·영수증 메시지 설정

- [✏ 등록] 버튼으로 영수증·문서에 찍힐 **사업장 도장(사인)** 이미지를 등록합니다.
  - [✕ 삭제] 버튼을 클릭하면 등록한 도장이 제거됩니다.

- 영수증 하단에 인쇄할 **안내 문구**를 입력합니다.
- 반품·교환 안내, 포인트 유효기간, 송금 계좌, 문의 번호 등을 작성할 수 있습니다.

### 3. 💾 저장

- [💾 저장] 버튼을 클릭해 입력한 내용을 저장합니다.
  - [닫기] 버튼을 클릭하면 화면이 닫힙니다.

### 🗂️ 기타 사업장 정보

- [✓ 기타 사업장 정보] 버튼을 클릭하면 창이 열립니다.
- 등록된 **사업장 정보**와 사업장에 속한 **사원 정보**를 한 화면에서 확인합니다.

## 실시간 계좌연동

은행 계좌의 **실시간 거래내역 연동**을 설정하는 화면입니다.

### 1. 🏢 사업장 정보 입력

- **사업장코드·사업장명**을 입력하고 **사업장구분**(본사·물류센터·공장·매장·창고 등)을 선택합니다.
- **사업자번호·대표자명·업태·종목**과 주소·전화번호를 입력합니다.

- 문자·팩스 발송에 사용할 **핸드폰·팩스번호·이메일**을 입력합니다.
- **사용상태**를 사용중 또는 사용안함으로 지정합니다.

### 2. 🔐 연동 인증 진행

화면의 번호 순서대로 진행합니다.

- **사업자번호·고객사 코드·연동키·연동 계좌정보**를 먼저 확인합니다.
- **① 회원가입** → **② 인증등록(브라우저)** → **③ 인증키 수신** 순으로 연동을 설정합니다.
  - **⓪ 토큰 발급/확인**으로 연동 토큰을 확인하고, **⑤ 서비스 해지**로 연동을 해지합니다.

### 3. ✅ 연동 결과 확인

- 연동된 **서비스·기관·계좌번호·별칭·인증서만료일**을 확인합니다.
- 연동 처리 결과와 **오류 메시지**가 함께 표시됩니다.

### 4. 💾 저장

- [💾 저장] 버튼을 클릭해 입력한 내용을 저장합니다.
  - [닫기] 버튼을 클릭하면 화면이 닫힙니다.

### 🗂️ 기타 사업장 정보

- [✓ 기타 사업장 정보] 버튼을 클릭하면 창이 열립니다.
- 등록된 **사업장 정보**와 사업장에 속한 **사원 정보**를 한 화면에서 확인합니다.

## 세금계산서 발행연동

**전자세금계산서 발행**을 위한 연동을 설정하는 화면입니다.

### 1. 🏢 사업장 정보 입력

- **사업장코드·사업장명**을 입력하고 **사업장구분**(본사·물류센터·공장·매장·창고 등)을 선택합니다.
- **사업자번호·대표자명·업태·종목**과 주소·전화번호를 입력합니다.

- 문자·팩스 발송에 사용할 **핸드폰·팩스번호·이메일**을 입력합니다.
- **사용상태**를 사용중 또는 사용안함으로 지정합니다.

### 2. 🔐 연동 인증 진행

화면의 번호 순서대로 진행합니다.

- **사업자번호·회원ID·담당자 이메일·연동 ID**와 **인증서 만료일·포인트**를 먼저 확인합니다.
- **① 회원가입** → **② 인증서 등록** → **③ 인증서/포인트** 순으로 연동을 설정합니다.
- **④ 포인트 충전**으로 세금계산서 발행에 사용할 포인트를 충전합니다.
  - **⓪ 토큰 발급/확인**으로 연동 토큰을 확인합니다.

### 3. 📄 처리 결과 확인

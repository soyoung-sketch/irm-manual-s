# 매출처 목록

---

## 매출처 목록

등록된 **매출처를 조회**하고, 여러 매출처의 **정보 통합·일괄변경**을 처리하는 화면입니다.

### 1. 🔍 매출처 검색

조회할 매출처를 찾습니다.

- 검색어를 입력하면 매출처명·연락처 등 전체 항목에서 조회됩니다.
- [🔍 상세검색] 버튼을 클릭하면 거래상태·분류·구분 등 조건을 지정할 수 있습니다.
- → 「상세검색」 페이지 참고

### 2. ✅ 매출처 목록 확인

- 매출처코드·대분류·매출처구분·업종별구분·거래형태와 **매출처명**을 확인합니다.
- 대표자명·생년월일·주민/사업자번호·업태·종목과 **전화번호·팩스번호·핸드폰**을 확인합니다.
  - 가로 스크롤을 이동하면 나머지 항목을 확인할 수 있습니다.

### 🔤 열별 필터 조회

- 열 머리글 아래 **필터 칸**에 값을 입력하면 해당 열 기준으로 목록이 걸러집니다.

### ➕ 매출처 등록

- [+ 매출처 등록] 버튼을 클릭하면 매출처 등록 화면이 열립니다.

### 🔄 여러 매출처 한 번에 처리

중복된 매출처를 합치거나 공통 항목을 한꺼번에 바꿉니다.

- **멀티선택모드**를 체크한 후 처리할 매출처를 선택합니다.
- → 「멀티선택모드」 페이지 참고

- [고객정보 통합] 버튼을 클릭해 같은 고객이 중복 등록된 건을 하나로 합칩니다.
  - 통합될 매출처의 미수금·보유 적립금을 확인한 후 진행합니다.

- [매출처정보 일괄변경] 버튼을 클릭해 선택한 매출처의 공통 항목을 한 번에 바꿉니다.

### 🔗 매출처 정보 통합 창

[고객정보 통합] 버튼으로 열리는 창입니다.

- **통합될 정보**에는 합쳐져 사라질 매출처를, **통합 기준 정보**에는 정보가 남을 매출처를 놓습니다.
- [▶ 추가] [◀ 삭제] 버튼으로 통합 대상을 옮깁니다.
- **비고**에 통합 사유를 입력한 후 [+ 통합] 버튼을 클릭하면 하나로 합쳐집니다.

### 🔄 매출처정보 일괄변경 메뉴

[매출처정보 일괄변경] 버튼으로 열리는 메뉴입니다.

- **카테고리 · 영업담당자 · 행사적용 · 거래상태 · 단가그룹 · 등급선택**을 선택한 매출처에 한 번에 적용합니다.
- **포인트 적립 · 문자 수신 여부 · 이메일 수신 여부**를 한 번에 켜거나 끕니다.

### ⚙️ 옵션

[⚙ 옵션] 버튼을 클릭하면 메뉴가 표시됩니다.

- **문서저장** : 조회된 목록을 **엑셀 · 워드 · PDF** 형식으로 저장합니다.
- **도움말** : 화면 사용 안내를 확인합니다.

## 상세검색

**상세 조건**을 지정해 매출처를 조회하는 화면입니다.

### 1. ✔️ 조회 조건 지정

필요한 조건을 골라 조회할 매출처를 좁힙니다.

**📌 거래상태·단가그룹·등급**

- **거래상태**를 전체·거래·중단·휴면·폐업·통합 중에서 고르고, 단가그룹·등급과 **등록일** 기간을 지정합니다.
**📌 분류·담당자**

- **대분류·중분류**를 선택하고 업태·종목·**영업담당자**로 조건을 좁힙니다.
**📌 구분**

- **구분**(개인·사업자)·**업종**(면세·일반·간이)·**형태**(직거래(도매)·일반매출·오픈마켓)·**지급수단**을 선택합니다.
**📌 통합검색**

- 검색어를 입력해 조회 대상을 추가로 좁힐 수 있습니다.

### 2. ✅ 조회 결과 확인

- 지정한 조건에 해당하는 매출처가 조회됩니다.

💡 상세검색이 펼쳐진 동안에는 상단 **통합검색** 입력칸을 사용할 수 없습니다.

💡 [닫기] 버튼을 클릭하면 상세검색 영역이 접힙니다.

## 멀티선택모드

**멀티선택모드**를 체크하면 나타나는 화면으로, 여러 매출처를 한 번에 선택해 처리할 수 있습니다.

### 1. ☑️ 대상 선택

- 목록 왼쪽에 생긴 **체크박스**를 클릭해 처리할 매출처를 선택합니다.
- 머리글의 체크박스를 클릭하면 조회된 매출처가 **전체 선택**됩니다.
  - 선택한 매출처의 매출처코드·매출처명·대표자명·연락처를 확인합니다.

### 2. 🔄 선택 후 처리

- [고객정보 통합] 버튼을 클릭해 중복 등록된 매출처를 하나로 합칩니다.

- [매출처정보 일괄변경] 버튼을 클릭해 선택한 매출처의 공통 항목을 한 번에 변경합니다.
- → 「매출처 목록」 페이지 참고

💡 체크를 해제하면 체크박스 열이 사라지고 원래 목록으로 돌아갑니다.

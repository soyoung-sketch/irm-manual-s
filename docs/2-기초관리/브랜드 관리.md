# 브랜드 관리

상품에 사용할 **브랜드를 등록·수정·삭제**하고 등록된 브랜드를 조회하는 화면입니다.

### 1. 🔍 브랜드 검색

- 검색어를 입력하고 [찾기] 버튼을 클릭하면 입력한 검색어로 브랜드가 걸러집니다.
  - 검색어를 비우고 [찾기]를 클릭하면 전체 브랜드가 다시 표시됩니다.

### 2. ✅ 브랜드 목록 확인

- 등록된 브랜드의 **코드 · 브랜드명 · 비고**를 확인합니다.
  - 세로 스크롤을 이동하면 나머지 브랜드를 확인할 수 있습니다.

### 3. 💾 브랜드 등록·수정

- 등록할 **브랜드명**을 입력합니다.
- 목록에서 브랜드를 클릭하면 입력칸에 이름이 채워져 **수정**할 수 있습니다.

- [+ 저장] 버튼을 클릭하면 입력한 브랜드가 목록에 등록됩니다.
  - 등록하면 **코드**가 자동으로 부여됩니다.

### 🗑️ 브랜드 삭제

- 목록 왼쪽의 **체크박스**로 삭제할 브랜드를 선택한 후 [✕ 삭제] 버튼을 클릭합니다.
- 머리글의 체크박스를 클릭하면 조회된 브랜드가 **전체 선택**되어 한 번에 삭제됩니다.

### 📅 등록·수정 이력 확인

- **등록ID · 등록자 · 등록일**에서 브랜드를 처음 만든 사람과 시점을 확인합니다.
- **수정ID · 수정자 · 수정일**은 등록 이후 내용을 바꾼 브랜드에만 표시됩니다.

### 📋 기타 버튼

- [닫기] : 브랜드 관리 화면을 닫습니다.

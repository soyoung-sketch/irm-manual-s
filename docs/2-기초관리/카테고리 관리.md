# 카테고리 관리

상품을 분류할 카테고리를 **대분류 → 중분류 → 소분류 → 세분류** 4단계로 등록·관리하는 화면입니다.

### 1. 🔍 카테고리 검색

- 검색어를 입력한 후 [찾기] 버튼을 클릭하면 해당 카테고리를 찾아줍니다.

### 2. 🌳 카테고리 분류 확인

등록된 분류가 트리 구조로 표시됩니다.

- 분류명 앞의 **▸**를 클릭해 펼치면 하위 분류를 단계별로 확인합니다.
- 분류를 클릭하면 우측 대분류~세분류 목록이 해당 분류 기준으로 바뀝니다.
  - 카테고리 미지정 : 아직 분류를 지정하지 않은 상품이 모이는 항목입니다.

### 3. 📁 카테고리 4단계 등록

왼쪽부터 대분류 → 중분류 → 소분류 → 세분류 순으로 등록합니다.

- 각 단계의 입력칸에 카테고리명을 입력하고 [+]를 클릭하면 그 단계에 추가됩니다.
- **순서** 열의 숫자로 목록에 표시되는 차례를 지정합니다.
**📌 대분류**

- 상품 분류의 첫 단계로, 상위 분류를 고르지 않고 바로 등록합니다.

**📌 중분류·소분류·세분류**

- 바로 위 단계를 먼저 선택한 후 카테고리명을 입력해 등록합니다.
- 세분류까지 등록하면 상품을 **4단계**로 가장 세밀하게 분류할 수 있습니다.
  - 세분류가 필요 없는 상품은 소분류까지만 등록해도 됩니다.

### 🔗 단계별 선택 연동

상위 분류를 먼저 선택해야 그 아래 단계를 등록할 수 있습니다.

- 대분류를 선택하면 그에 속한 **중분류만** 표시됩니다.
- 중분류를 선택하면 그에 속한 **소분류만** 표시됩니다.
- 소분류를 선택하면 그에 속한 **세분류만** 표시됩니다.
  - 하위 목록이 비어 있으면 아직 그 단계에 등록된 분류가 없다는 뜻입니다.

### ➕ 분류 편집 도구

대분류·중분류·소분류·세분류 목록 위쪽에 같은 도구가 각각 있습니다.

**📌 버튼별 기능**

- [+] : 입력한 카테고리명을 해당 단계에 추가합니다.
- [✕] : 선택한 카테고리를 삭제합니다.
- [▲] : 선택한 카테고리의 순서를 위로 올립니다.
- [▼] : 선택한 카테고리의 순서를 아래로 내립니다.

  - 상위 분류를 삭제하면 그 아래 하위 분류도 함께 사라지므로 주의합니다.

# 매입처 목록

---

## 매입처 목록

등록된 **매입처 목록**을 조회하고, 새 매입처를 등록하는 화면입니다.

### 1. 🔍 매입처 검색

조회할 매입처를 찾습니다.

- 검색어를 입력하면 매입처명·대표자명 등 전체 항목에서 조회됩니다.
- [🔍 상세검색] 버튼을 클릭하면 거래상태·매입처구분·분류·결제수단 등 조건을 지정할 수 있습니다.
- → 「상세검색」 페이지 참고

### 2. ✅ 매입처 목록 확인

- 매입처코드·대분류·매입처구분·**매입형태**와 매입처명(상호)·대표자명을 확인합니다.
- 사업자등록번호·종사업장번호·**업종구분**·업태·종목을 확인합니다.
- 핸드폰번호·사무실전화번호·사무실팩스번호와 **우편번호**를 확인합니다.
  - 우편번호 오른쪽 열은 가로 스크롤을 이동해 확인합니다.
  - 화면 위아래에서 조회된 총 건수를 확인할 수 있습니다.

### 🔤 열별 필터 조회

- 열 머리글 아래 **필터 칸**에 값을 입력하면 해당 열 기준으로 목록이 걸러집니다.

### ➕ 매입처 등록

- [+ 매입처 등록] 버튼을 클릭하면 매입처 등록 화면이 열립니다.

### ✏️ 매입처정보 일괄변경

여러 매입처의 정보를 한 번에 수정합니다.

- **멀티선택모드**를 체크한 후 변경할 매입처를 선택합니다.
- [매입처정보 일괄변경] 버튼을 클릭하면 변경할 항목 메뉴가 표시됩니다.
**📌 변경 항목**

- **카테고리** : 선택한 매입처의 카테고리를 한 번에 지정합니다.
- **거래상태** : 선택한 매입처의 거래상태를 한 번에 변경합니다.
- **영업담당자** : 선택한 매입처의 영업담당자를 한 번에 지정합니다.

### ⚙️ 옵션

[⚙ 옵션] 버튼을 클릭하면 메뉴가 표시됩니다.

- **문서저장** : 조회된 목록을 **엑셀 · 워드 · PDF** 형식으로 저장합니다.
- **도움말** : 화면 사용 안내를 확인합니다.

### 📋 기타

- 「전략 보고서」 : 화면 우측 사이드탭을 클릭하면 전략 보고서 화면이 열립니다.

## 상세검색

**상세 조건**을 지정해 매입처를 조회하는 화면입니다.

### 1. ✔️ 조회 조건 지정

찾으려는 매입처의 조건을 지정합니다.

**📌 거래·구분**

- **거래상태**(전체·거래·중단·폐업)와 **매입처구분**(전체·사업자·개인·센터), **업종별구분**(전체·일반·면세·간이)을 선택하고 등록일 기간을 지정합니다.

**📌 분류·담당자**

- **대분류 · 중분류 · 소분류**를 차례로 선택합니다.
- 업태·종목을 입력하고 **영업담당자**를 지정해 조회 대상을 좁힐 수 있습니다.

**📌 형태·결제**

- **매입처형태**를 일반매입·판매분수수료·일반(매입처배송)·임대업장(다중사업자)·x-dock 중에서 선택합니다.
- **지급수단**(여(사용)·부(안함))과 **결제수단**(현금·어음·카드[주류]), **결제주기**(즉시·당월·익월·익익월)를 선택합니다.

### 2. 🔍 통합검색으로 조회

- 검색어를 입력하고 [🔍 검색] 버튼을 클릭하면 지정한 조건으로 매입처가 조회됩니다.

### 3. ✅ 조회 결과 확인

- 지정한 조건에 해당하는 매입처가 조회됩니다.
  - 화면 위아래에서 조회된 총 건수를 확인할 수 있습니다.

💡 [닫기] 버튼을 클릭하면 상세검색 영역이 접힙니다.

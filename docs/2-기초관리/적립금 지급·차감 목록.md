# 적립금 지급/차감 목록

---

## 적립금 지급/차감

매출처별 **적립금 지급·차감 내역**을 조회하고, 지급 취소·삭제를 처리하는 화면입니다.

### 1. 🔍 조회

- 검색어를 입력해 **통합검색**하거나, [🔍 상세검색]으로 조건을 지정해 조회합니다.

### 2. ✅ 내역 확인

- 조회된 내역의 적립일·매출처·적립사유·결제구분과 **충전금액·추가적립·합계금액**을 확인합니다.
- **취소** 열에서 해당 내역의 **정상 / 취소** 상태를 확인합니다.

### 3. 👤 매출처 내역보기

- 내역을 선택한 후 [✓ 매출처 내역보기] 버튼을 클릭합니다.
- 해당 매출처의 적립 내역과 적립금 지급 화면이 열립니다. → 「매출처 내역보기」 페이지 참고

### 🚫 지급취소·지급삭제

- 내역을 선택한 후 [✓ 적립금 지급취소] 버튼을 클릭하면 취소 처리됩니다.
  - 취소하면 금액이 차감(음수) 내역으로 새로 생성되고, 비고에 취소한 문서번호가 기록됩니다.
- 내역을 선택한 후 [✕ 적립금 지급삭제] 버튼을 클릭하면 목록에서 삭제되며, 「지급삭제」 탭에서 확인할 수 있습니다.

### 🗂️ 항목별 그룹 조회

- 열 머리글을 **클릭 앤 드래그**로 끌어다 놓으면 해당 항목 기준으로 묶어서 조회됩니다.

## 매출처 내역보기

선택한 매출처의 **적립금 적립·사용 내역**을 확인하고, **새 적립금을 지급**하는 화면입니다.

### 1. 🔍 매출처 선택

조회할 매출처와 기간을 지정합니다.

- **매출처명**을 선택하고 **시작일·종료일**을 지정한 후 [🔍 검색] 버튼을 클릭합니다.

### 2. ✅ 적립/차감 내역 확인

- **이전 적립금**부터 적립일·문서번호·사업장·구분·사유·결제구분을 확인합니다.
- **충전금액·추가적립·합계금액·사용금액**과 화면 하단의 합계를 확인할 수 있습니다.

### 3. 💾 적립금 적립

새로 적립할 내용을 입력한 후 적립합니다.

- **보유 적립금**에서 해당 매출처의 잔여 적립금을 확인할 수 있습니다.
- 적립일·작성일을 지정하고 **사유·구분·결제구분·은행정보**를 선택합니다.
- **충전금액**을 입력하면 추가적립과 함께 합계금액이 계산됩니다.
  - 필수 표시가 있는 항목은 모두 입력해야 적립할 수 있습니다.

- [+ 적립금 적립] 버튼을 클릭하면 입력한 내용으로 적립됩니다.
- 입력한 내용을 지우고 다시 작성하려면 [초기화] 버튼을 클릭합니다.

### 📋 기타 버튼

- [엑셀저장] : 조회된 내역을 엑셀 파일로 저장합니다.
- [✓ 적립금 지급취소] : 선택한 내역을 취소 처리합니다.
- [✕ 적립금 지급삭제] : 선택한 내역을 삭제합니다.

## 지급삭제

**삭제된 적립금 지급/차감 이력**을 조회하는 탭입니다.

### 1. ✅ 삭제 이력 확인

- 삭제 처리된 내역의 적립일·매출처·금액·비고를 확인합니다.
- **취소** 열이 모두 **삭제**로 표시됩니다.

💡 **조회 전용** 탭으로, 매출처 내역보기·적립금 지급취소·적립금 지급삭제 기능은 사용할 수 없습니다.

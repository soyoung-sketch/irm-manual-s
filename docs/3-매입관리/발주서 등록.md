# 발주서 등록

발주할 상품을 담아 매입처에 보내는 **발주서**를 등록하는 화면입니다.

### 1. 🏢 매입처 선택

발주서를 보낼 매입처를 먼저 지정합니다.

- 매입처명 칸의 [···] 버튼을 클릭하면 **매입처 목록** 창이 열립니다.
- 목록에서 바로 고르거나 **상세검색**으로 조건을 지정해 찾습니다.
- 단일 선택은 **더블클릭**, 여러 개는 **멀티선택모드**를 켠 뒤 선택합니다.

### 2. 🛒 발주할 상품 추가

세 가지 방법으로 상품을 담을 수 있습니다.

**📌 직접 입력**

- [+ 상품추가(F2)]로 행을 만들고 상품코드의 [···] 버튼으로 상품 통합검색창을 열어 선택합니다.
**📌 문서불러오기**

- [문서불러오기]로 다른 주문서·발주서의 상품을 그대로 가져옵니다.
**📌 엑셀업로드**

- [엑셀업로드]로 여러 상품을 한 번에 가져옵니다.

- 담은 상품의 **매입단가·수량**을 입력하면 공급가·부가세·매입합계가 계산됩니다.

### 3. 💾 발주서 등록

- 매입처·상품과 필수 정보를 모두 입력했다면 [신규등록(F5)] 버튼으로 발주서를 등록합니다.

### 📝 관리자 메모

이 발주서에 대한 코멘트를 남길 수 있습니다.

- **노란색**으로 표시한 메모영역의 입력칸에 메모를 입력합니다.
- [＋ 저장]을 누르면 메모가 등록되고, 잘못 남긴 메모는 [✕ 삭제]로 지웁니다.

### 🔗 바코드 인쇄관리

[바코드인쇄] 버튼을 클릭하면 바코드 인쇄관리 화면으로 이동합니다.

- 🔗 **바코드 인쇄관리** 페이지 바로가기

등록된 발주서는 **발주서 조회** 페이지에서 확인할 수 있습니다.

# 매입 반품 등록

매입한 상품을 매입처에 반품 처리하는 화면입니다. **매입 등록**과 사용법이 같고, **반품사유**를 등록해야 한다는 점만 다릅니다.

### 1. 🏢 매입처 선택

반품 처리할 매입처를 먼저 지정합니다.

- 매입처명 칸의 [···] 버튼을 클릭하면 **매입처 목록** 창이 열립니다.
- 단일 선택은 **더블클릭**, 여러 개는 **멀티선택모드**를 켠 뒤 선택합니다.
  - 매입처를 선택하면 해당 매입처의 **미수금** 합계도 화면에서 바로 확인할 수 있습니다.

### 2. 📋 반품 정보·반품사유 선택

반품일·담당자·부서명(필수)과 함께 **반품사유**를 선택합니다.

- **반품사유**(필수)는 유통기한·파손·단순반품·기타 중에서 선택합니다.
  - 사유를 **기타**로 선택했다면 비고에 상세 내용을 적어두면 좋습니다.

### 3. 🛒 반품할 상품 추가

매입 등록과 같은 세 가지 방법으로 상품을 담습니다.

**📌 직접 입력**

- [+ 상품추가(F2)]로 행을 만들고 상품코드의 [···] 버튼으로 상품 통합검색창을 열어 선택합니다.
**📌 문서불러오기**

- [문서불러오기]로 다른 문서의 상품을 그대로 가져옵니다.
**📌 엑셀업로드**

- [엑셀업로드]로 여러 상품을 한 번에 가져옵니다.

- 담은 상품의 **반품수량**을 입력하면 공급가·부가세·매입합계가 계산됩니다.

### 4. 🔢 반품수량 입력

담은 상품의 **반품수량**을 입력하면 공급가·부가세·매입합계가 자동으로 계산됩니다.

### 5. 💾 매입 반품 등록

- 필수 정보와 상품을 모두 입력했다면 [신규등록(F5)] 버튼으로 매입 반품을 등록합니다.

### 💲 판매가변경

[판매가변경] 버튼을 누르면 담긴 상품의 **판매가를 변경**할 수 있으며, **사업장 상품관리** 화면으로 이동합니다.

### 📝 관리자 메모

이 반품 건에 대한 코멘트를 남길 수 있습니다.

- **노란색**으로 표시한 메모영역의 입력칸에 메모를 입력합니다.
- [＋ 저장]을 누르면 메모가 등록되고, 잘못 남긴 메모는 [✕ 삭제]로 지웁니다.

### 🔗 바코드 인쇄관리

[바코드인쇄] 버튼을 클릭하면 바코드 인쇄관리 화면으로 이동합니다.

- 🔗 **바코드 인쇄관리** 페이지 바로가기

등록된 반품 내역은 **매입 반품 조회** 페이지에서 확인할 수 있습니다.

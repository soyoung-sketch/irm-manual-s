# 수수료 매출 마감

입점사(매입처)의 **판매분 수수료**를 정산하고 매출을 마감하는 화면입니다.

### 1. 🔍 매입처 조회하기

- **마감월**을 선택한 후 [🔍 검색] 버튼을 클릭합니다.
  - 매입처가 많으면 검색어를 입력하고 [찾기] 버튼으로 목록에서 찾을 수 있습니다.

### 2. 📄 매출상세 정보보기

- 조회된 매입처를 **더블클릭**하면 매출상세정보가 생성됩니다.
- 매출일·매출전표·상품명·판매단가·판매수 등 **판매 내역**을 확인합니다.

### 3. 📝 수정하기

[⬇ 일괄수정] 버튼을 클릭하면 수정 탭이 열립니다.

**📌 기본 수정**

- 판매분수수료·카드수수료 등 **수수료 항목**을 개별 수정합니다.
**📌 기간 일괄 수정**

- 매출 **시작일·종료일**을 선택하고 조정할 수수료율을 입력합니다.
- [✓ 일괄수정] 버튼을 클릭하면 기간 내 수수료율이 한 번에 조정됩니다.

### 4. ✅ 지급금액 확인 및 매출 확정

- 총 매출금액에서 **판매분 수수료·카드 수수료·회원지급 포인트**를 뺀 마감금액을 확인합니다.
- **담당자·마감일**을 지정하고 필요하면 비고를 입력합니다.

- [＋ 지급입력] 버튼을 클릭하면 매출 마감이 완료됩니다.

### ⚙️ 옵션

[⚙ 옵션] 버튼을 클릭하면 메뉴가 표시됩니다.

- **문서저장** : 조회된 내역을 **엑셀 · 워드 · PDF** 형식으로 저장합니다.
- **레이아웃** : 목록에 표시할 **사용자 컬럼**을 설정하거나 초기화합니다.

완료된 전표는 **수수료 매출 마감 조회** 카테고리에서 확인하실 수 있습니다.

# 발주계획 조회

---

## 작성중

발주계획 입력에서 등록한 계획을 **확인·수정·작성완료** 처리하는 화면입니다. 작성완료하면 발주서가 자동 작성됩니다.

### 1. ✅ 작성중 계획 확인

발주계획 입력에서 등록한 계획이 **작성중** 탭에 올라옵니다.

- 특정 문서만 보려면 우측 상단 **통합검색**으로 찾습니다.
- 목록에서 처리할 문서를 **☑ 체크**해 선택합니다.

### 2. 📝 문서를 확인해주세요

문서를 확인한 뒤 수정하거나 완료합니다.

**📌 수정하기**

- [수정] 버튼을 클릭하면 **발주계획수정** 화면으로 이동합니다.
**📌 완료하기**

- [작성완료(발주서작성)] 버튼을 클릭하면 **작성완료** 처리되고 발주서가 자동 작성됩니다.
- ⬇ 완료된 문서는 **작성완료** 탭으로 이동합니다.

### ✏️ 발주계획수정 화면

수정 버튼으로 열리며 **발주계획 입력과 같은 시스템**입니다.

- 행을 클릭해 **상품·매입단가·수량** 등 내용을 고칩니다.
- 다 고쳤으면 [계획수정(F5)] 버튼으로 수정 내용을 저장합니다.
- 상단 「발주계획 조회」 탭을 클릭하면 조회 화면으로 돌아옵니다.

---

## 작성완료

### 1. 📦 작성완료 문서 확인

**작성완료** 탭에서 완료 처리된 문서를 확인합니다.

- 이 단계에서는 [수정] · [취소]가 불가능합니다.

작성완료된 문서는 **발주서 조회**의 **발주대기** 탭에서 확인하고 발주를 진행할 수 있습니다.

---

## 취소

**취소** 탭에서는 취소한 발주계획 목록을 확인하고 필요하면 다시 되돌릴 수 있습니다.

### 1. ✅ 취소 문서 확인

취소한 발주계획 문서를 목록에서 확인합니다.

### 2. ◀ 작성중으로 복구

- [◀ 작성중] 버튼으로 취소한 발주계획을 다시 **작성중** 단계로 되돌립니다.
- 이 탭에서는 [수정]·[취소]가 불가능합니다.

# 발주계획 입력

발주할 상품과 수량을 계획으로 등록하는 화면입니다 · **발주계획 입력**(신규등록) → **발주계획 조회**(작성완료) → **발주서 조회**(발주대기) 순서로 진행됩니다.

### 1. 📝 정보를 입력해주세요

- **입고예정일·부서명·담당자**를 설정합니다 (모두 필수 항목).

### 2. 🛒 상품을 추가해주세요

[+ 상품추가(F2)] 버튼을 클릭하면 리스트에 새 한 줄이 생성됩니다 (첫 한 줄은 미리 생성돼 있습니다).

### 3. 🔍 상품을 선택해주세요

- 상품코드의 [···] 버튼을 클릭해 **상품 통합검색창**에서 발주할 상품을 선택합니다.

### 4. ✏️ 수량·매입처를 입력해주세요

- 선택한 상품이 행에 채워지면 발주할 **수량**을 입력합니다 (공급가·부가세·매입합계가 자동 계산).
- 매입처코드 우측 [···] 버튼을 클릭해 **매입처 목록**에서 매입처를 선택합니다.

### 5. 💾 발주계획을 등록해주세요

- 등록할 상품을 체크하고 [신규등록(F5)] 버튼을 클릭합니다.

### 🔗 바코드 인쇄관리

[바코드인쇄] 버튼을 클릭하면 바코드 인쇄관리 화면으로 이동합니다.

- 🔗 **바코드 인쇄관리** 페이지 바로가기

등록된 발주계획은 **발주계획 조회** 탭에서 확인하실 수 있습니다.

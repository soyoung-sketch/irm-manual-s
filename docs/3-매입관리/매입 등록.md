# 매입 등록

매입처에서 매입한 상품과 수량을 담아 **매입 내역**을 등록하는 화면입니다.

### 1. 🏢 매입처 선택

매입한 매입처를 먼저 지정합니다.

- 매입처명 칸의 [···] 버튼을 클릭하면 **매입처 목록** 창이 열립니다.
- 단일 선택은 **더블클릭**, 여러 개는 **멀티선택모드**를 켠 뒤 선택합니다.
  - 매입처를 선택하면 해당 매입처의 **미수금 총액**이 빨간 글씨로 표시됩니다.

### 2. 📝 매입 정보 선택

- **매입일·담당자·부서명**을 선택합니다 (모두 필수 항목).

### 3. 🛒 매입할 상품 추가

세 가지 방법으로 상품을 담을 수 있습니다.

**📌 직접 추가**

- [+ 상품추가(F2)]로 행을 만들고(첫 줄은 미리 생성) 상품코드의 [···] 버튼을 클릭합니다.
- ⬇ **상품 통합검색창**에서 매입할 상품을 선택합니다.
- ⬇ 매입할 **구매수량**을 입력하면 공급가·부가세·매입합계가 자동 계산됩니다.
**📌 문서불러오기**

- [문서불러오기]로 다른 카테고리의 주문서 정보를 불러옵니다.
**📌 엑셀업로드**

- [엑셀업로드]로 지정 탬플릿 엑셀을 이용해 여러 상품을 한꺼번에 등록합니다.

### 4. 💾 매입 등록

- 매입처·상품과 필수 정보를 모두 입력했다면 [신규등록(F5)] 버튼으로 매입을 등록합니다.
  - 판매가를 변경해야 하면 [판매가변경] 버튼으로 **사업장 상품관리**를 열어 판매단가를 수정합니다.

### 📝 관리자 메모

이 매입 건에 대한 코멘트를 남길 수 있습니다.

- **노란색**으로 표시한 메모영역의 입력칸에 메모를 입력합니다.
- [＋ 저장]을 누르면 메모가 등록되고, 잘못 남긴 메모는 [✕ 삭제]로 지웁니다.

### 🔎 편리한 기능: 검색모드

상품을 빠르게 검색해 매입 목록에 바로 담는 기능입니다.

- 매입처명을 입력한 뒤 **검색모드**를 체크하면 우측에 상품검색 창이 열립니다.
- 상품검색 창에 **상품명**을 입력하고 **엔터**를 누르면 상품이 조회됩니다.
- 조회된 상품을 **더블클릭**하면 좌측 매입 목록에 바로 등록됩니다.
- 이미 담긴 **중복 상품**은 상품코드가 빨간색으로 표시됩니다.

### 🔗 바코드 인쇄관리

[바코드인쇄] 버튼을 클릭하면 바코드 인쇄관리 화면으로 이동합니다.

- 🔗 **바코드 인쇄관리** 페이지 바로가기

등록된 매입 내역은 **매입 조회** 화면에서 확인할 수 있습니다.

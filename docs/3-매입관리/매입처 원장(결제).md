# 매입처 원장(결제)

매입처 한 곳의 **결제 원장**을 기간별로 조회하여 매입·지급·장려금과 잔고를 확인하는 화면입니다.

### 1. 🏢 매입처 입력하기

- 조회할 매입처를 입력하거나 **···** 버튼으로 검색해 지정합니다.

### 2. 📅 날짜 설정하기

- **시작일~종료일**을 선택해 조회할 기간을 지정합니다.

### 3. 🔍 검색하기

- [🔍 검색] 버튼을 클릭해 원장을 조회합니다.

### 4. 📋 목록 확인하기

- **기초잔고+매입-결제-장려금=잔고** 구조로 내역을 확인합니다.
- ⬇ 하단 합계 줄에서 기간 전체의 **잔고합계**를 확인할 수 있습니다.

### 📌 매입처 원장(상품)

🔗 **매입처 원장(상품)** 버튼으로 같은 매입처의 **상품 단위 원장**으로 이동합니다.

### 📌 채무지급입력

[채무지급입력] 버튼으로 🔗 **채무 지급 관리**로 이동합니다.

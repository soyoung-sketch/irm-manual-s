# 매입처별 거래내역

매입처별 **매입·결제·장려금 내역과 잔고**를 기간 단위로 확인하는 화면입니다.

### 1. 🔍 조회하기

**시작일~종료일**을 지정한 후 [🔍 검색] 버튼을 클릭합니다.

- ⬇ [매입처선택] 버튼으로 특정 매입처만 골라 조회할 수 있습니다.
- 매입처·결제내역·장려금내역 **상세보기**를 체크하면 목록에서 해당 내역의 상세내역을 확인할 수 있습니다.

### 2. 📋 매입처 확인

조회된 목록에서 매입처별 금액을 확인하고 행을 선택합니다.

- **이전금액+매입금액-지급합계-장려금=잔고합계** 구조로 표시됩니다.

### 3. 🗂️ 상세 화면 열기

매입처를 선택한 후 상단 버튼으로 상세 화면을 엽니다.

**📌 보고서 작성**

- [🖨 보고서 작성] 메뉴에서 **보고서 인쇄**를 클릭하면 매입 보고서 미리 보기가 열립니다.
**📌 매입처 원장(결제) · 원장(상품)**

- 🔗 **매입처 원장(결제)** · 🔗 **매입처 원장(상품)** 버튼으로 원장 화면을 엽니다.
**📌 채무지급입력**

- 🔗 **채무지급입력** 버튼으로 매입처가 미리 입력된 **채무지급 관리** 화면으로 이동합니다.

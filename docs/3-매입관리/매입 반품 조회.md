# 매입 반품 조회

---

## 반품입력

반품 등록한 전표를 **반품입력 → 반품대기 → 반품완료** 단계로 처리하는 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. 📋 반품 전표 선택

**반품입력** 목록에서 처리할 반품 전표를 선택합니다.

- 우측 상단 **통합검색·상세검색**으로 특정 전표를 찾을 수 있습니다.

### 2. ➡️ 반품대기로 넘김

[반품대기 / 회수요청]으로 넘기면 **반품대기** 상태가 되어 「반품대기」 탭으로 이동합니다.

### 📌 가능한 작업

- **인쇄** : [인쇄]로 선택한 반품전표의 **매입전표**를 출력합니다.
- **수정** : [수정]으로 **반품수정** 화면에서 내용을 고칩니다.
- **취소** : [취소]로 필요 없는 전표를 취소합니다(반품취소 탭으로 이동).

---

## 반품취소

반품이 **취소**된 전표를 모아 보는 탭입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. 📋 반품취소 전표 선택

반품이 취소된 전표 목록에서 처리할 전표를 선택합니다.

### 2. ◀ 반품입력으로 되돌리기

[◀반품입력]으로 취소한 전표를 다시 **반품입력** 상태로 되돌립니다(반품입력 탭으로 이동).

### 📌 가능한 작업

- **인쇄** : [인쇄]로 반품취소 **매입전표** 미리 보기를 열어 출력합니다.
- **수정** : [수정]으로 취소 상태에서도 **반품수정** 화면으로 이동합니다.

---

## 반품대기

등록한 반품전표를 확인하고 **반품완료** 처리하는 **반품대기** 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 반품 확인

매입 반품 등록에서 등록한 반품전표가 **반품대기** 탭에 올라옵니다. 처리할 전표를 선택합니다.

- 우측 상단 **통합검색**으로 특정 전표를 찾을 수 있습니다.

### 2. 📦 반품완료 처리

내용 확인이 끝나면 [반품완료]로 전표를 다음 단계로 보냅니다(반품완료 탭으로 이동).

### 📌 가능한 작업

- **인쇄** : [인쇄]로 선택한 반품전표의 **매입전표**를 출력합니다.
- **수정** : [수정]으로 **반품수정** 화면에서 내용을 고칩니다.
- **취소** : [취소]로 필요 없는 전표를 취소합니다(반품취소 탭으로 이동).

---

## 반품완료

반품이 **완료**된 전표를 모아 보는 탭입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 📌 가능한 작업

- **인쇄** : [인쇄]로 반품 **매입전표** 미리 보기를 열어 출력합니다.
- **취소** : [취소]로 반품을 되돌립니다(반품취소 탭으로 이동).
- **수정** : 반품완료 단계에서는 사용할 수 없습니다.

---

## 반품수정

반품 전표의 내용을 **고치는 수정 화면**입니다. 반품 조회의 [수정] 버튼으로 들어와 **번호 순서**대로 고칩니다.

### 1. ✏️ 수정 가능한 항목

**노란색 칠**이 된 부분이 수정할 수 있는 항목입니다. 필요한 값을 고칩니다.

### 2. 🛒 새 반품 상품 추가

아래 영역에서 **새로 반품할 상품**을 추가할 수 있습니다.

### 3. 💾 반품수정 완료

[반품수정] 버튼을 누르면 변경 내용을 반영하고 **이전 화면**으로 돌아갑니다.

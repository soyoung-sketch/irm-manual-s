# 채무 지급 관리

---

## 채무지급입력

채무 지급 건을 등록하고 상태별로 처리하는 화면입니다. 상단 5개 탭이 지급 건의 **처리 상태**를 나눕니다.

### 1. ✍️ 지급 정보 입력

우측 **채무지급등록** 패널에서 지급 정보를 입력합니다.

- **매입처명·담당자·지급일·결제구분·결제금액**은 반드시 입력해야 하는 필수 항목입니다.
- ⬇ [검색] 버튼으로 매입처를 조회해 선택합니다.
- 결제구분을 선택하면 그에 맞는 **계좌 정보** 입력란이 표시됩니다.

### 2. ➕ 지급 등록

작성을 마치면 [지급입력] 버튼을 클릭해 지급 건을 등록합니다.

- 입력 내용을 처음부터 다시 쓰려면 [다시작성] 버튼을 클릭합니다.

### 3. 📋 등록 내역 확인

등록한 지급 건이 왼쪽 **목록**에 표시됩니다.

### 4. 📤 지급대기로 넘기기

목록에서 건을 선택하고 [지급대기] 버튼을 클릭하면 **지급대기** 탭으로 이동합니다.

- [지급완료] 버튼으로 지급을 확정하면 **지급완료** 탭에서 확인합니다.
- 지급하지 않을 건은 [취소] 버튼으로 **취소** 탭에 모읍니다.
  - 「발행어음목록」 탭에서는 발행어음 내역을 모아 봅니다.

---

## 취소

**취소** 처리된 지급 건을 모아 보는 탭입니다. 이 단계에서는 **취소** 버튼을 사용할 수 없습니다.

### 1. 📋 취소 건 확인

**취소**된 지급 건이 목록에 표시됩니다.

---

## 지급대기

**지급대기** 상태의 지급 건을 확인하는 탭입니다. 선택한 건을 **◀채무지급입력**으로 되돌리거나 상태를 처리할 수 있습니다.

### 1. 📋 지급대기 건 확인

**지급대기** 상태의 지급 건이 목록에 표시됩니다.

### 2. ✅ 지급완료 처리

건을 선택하고 [지급완료] 버튼을 클릭하면 **지급완료** 탭으로 이동합니다.

---

## 지급완료

**지급완료**된 지급 건을 확인하는 탭입니다. 지급하지 않을 건은 **취소** 버튼으로 취소 처리할 수 있습니다.

### 1. 📋 지급완료 건 확인

**지급완료**된 지급 건이 목록에 표시됩니다.

---

## 발행어음목록

**발행어음** 내역을 확인하고 어음 지급을 등록하는 탭입니다.

### 1. ✍️ 발행어음 정보 입력

우측 **채무지급등록** 패널에서 발행어음 지급 정보를 입력합니다.

- 노란색으로 표시된 항목이 **입력·수정** 대상입니다.

### 2. ➕ 지급 등록

작성을 마치면 [지급입력] 버튼으로 발행어음 지급을 등록합니다.

### 3. 📋 발행어음 내역 확인

등록된 **발행어음 지급**은 **채무지급등록 > 채무지급이력 > ****지급완료** 시 **발행어음목록**에 표시됩니다.

# 월 매입 마감

매입처별 **월 매입 내역**을 확인하고 계산서 발행금액을 입력하여 월 매입 마감을 진행하는 화면입니다.

### 1. 🔍 매입처 조회하기

- 마감할 **매입월**을 선택한 후 [🔍 검색] 버튼을 클릭합니다.
- ⬇ 조회된 매입처를 **더블클릭**하면 오른쪽 매입정보창에서 상세정보를 확인할 수 있습니다.

### 2. ➕ 계산서추가

매입정보를 확인했으면 [계산서추가] 버튼을 클릭해 계산서 입력 화면을 엽니다.

### 3. 📝 계산서 발행금액 입력하기

계산서 정보등록의 [＋ 추가] 버튼을 클릭합니다.

- ⬇ 발행구분을 선택하고 **공급가액·부가세·면세금액**을 입력합니다.
- 계산서 발행금액과 매입금액을 비교하여 **차액**을 확인할 수 있습니다.

### ✅ 차액 확인

- 차액이 **0원**인지 확인한 후 저장하는 것을 권장합니다.

### 4. 💾 저장하기

- [💾 저장] 버튼을 클릭하면 월 매입 마감이 저장됩니다.

저장된 문서는 **월 매입 마감 조회** 카테고리에서 확인하실 수 있습니다.

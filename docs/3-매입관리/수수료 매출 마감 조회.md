# 수수료 매출 마감 조회

---

## 작성중

수수료 매출 마감에서 완료한 전표를 **확인부터 마감완료까지** 단계별로 처리하는 화면입니다. 상단 5개 탭이 전표의 **처리 상태**를 나눕니다.

### 1. ✅ 전표 확인

완료한 전표가 **작성중** 탭에 올라옵니다 · 목록에서 처리할 전표를 확인합니다.

- 우측 상단 **통합검색·상세검색**으로 특정 전표를 찾을 수 있습니다.

### 2. 📤 마감 진행

확인이 끝난 전표는 [마감대기] 버튼으로 넘깁니다.

- 처리된 전표는 **마감대기** 페이지로 이동합니다.
- 마감하지 않을 전표면 [취소]합니다(취소 페이지로 이동).

### 📋 매출마감 상품정보 패널

상세정보 버튼으로 열리며 전표의 상품 내역을 보여줍니다.

- 위쪽 표에서 **매출구분별 공급가·부가세·면세·합계금액**과 총합계를 확인합니다.
- 아래쪽은 「일자별 상품정보」 · 「상품 합계정보」 탭으로 나눠 봅니다.
- [엑셀저장] 버튼으로 상품 내역을 엑셀 파일로 저장합니다.
- [닫기] 버튼을 클릭하면 패널이 닫히고 목록으로 돌아옵니다.

---

## 취소

**취소**한 전표를 모아 보는 탭입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 취소 전표 확인

취소한 전표 목록에서 내용을 확인합니다.

### 📌 가능한 작업

- **상세정보** : 전표를 선택하고 [상세정보] 버튼으로 상품 내역을 확인합니다.
- **취소** : 이 단계에서는 사용할 수 없습니다.

---

## 마감대기

**마감대기**로 넘긴 전표를 확인하고 마감완료 처리하는 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 전표 확인

마감대기로 넘긴 전표 목록에서 내용을 확인합니다.

### 2. 📦 마감완료

전표 확인이 끝나면 [마감완료]로 마감을 확정합니다(「마감완료」 탭으로 이동).

### 📌 가능한 작업

- **지급안함** : 지급하지 않을 전표는 [지급안함]으로 처리합니다(「지급안함」 탭으로 이동).
- **취소** : 되돌릴 전표는 [취소]합니다(「취소」 탭으로 이동).
- **상세정보** : [상세정보] 버튼으로 전표의 상품 내역을 확인합니다.

---

## 마감완료

마감이 끝난 **마감완료** 전표를 모아 보는 탭입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 마감완료 전표 확인

마감이 끝난 전표 목록에서 내용을 확인합니다.

### 📌 가능한 작업

- **상세정보** : 전표를 선택하고 [상세정보] 버튼으로 상품 내역을 확인합니다.
- **취소** : 이 단계에서는 사용할 수 없습니다.

마감완료까지 끝나면 수수료 매출 마감의 **모든 과정이 끝납니다**.

---

## 지급안함

**지급안함**으로 처리한 전표를 모아 보는 탭입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 지급안함 전표 확인

지급하지 않기로 처리한 전표 목록에서 내용을 확인합니다.

### 📌 가능한 작업

- **상세정보** : [상세정보] 버튼으로 전표의 상품 내역을 확인합니다.

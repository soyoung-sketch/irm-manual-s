# 발주계획v2

**재고 부족 품목**을 찾아 발주하는 화면입니다 · 재고차를 보고 필요한 만큼 발주서를 만듭니다.

### 1. 🔍 검색하기

[검색] 버튼을 누르면 전체 리스트가 나옵니다.

- **매입처**를 선택해 특정 매입처로 검색할 수 있습니다.
- **시작일·종료일** 또는 **대·중·소·세분류**를 지정해 검색합니다.

### 2. 발주가 필요한 품목 확인하기

재고차가 **1 이상**이고 아직 발주하지 않은 품목은 **핑크색**입니다.

- 재고차 = **출고수량 − 현재고**.
- 추천 발주수량 = **부족한 재고차**만큼입니다.

### 3. 이미 발주된 품목 확인하기

이미 **발주수량이 존재**하면 **빨간색**으로 표시됩니다.

### 4. 📝 발주하기

핑크색 라인의 상품을 선택하고 [＋ 발주서 만들기] 버튼을 클릭합니다.

- ⬇ 🔗 **발주서 등록** 화면으로 이동합니다.
- 발주한 것은 **빨간색**으로 바뀝니다 (🔗 **발주서 조회 › 발주대기**에서 확인).

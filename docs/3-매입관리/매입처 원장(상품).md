# 매입처 원장(상품)

매입처 한 곳의 **매입 내역**을 상품 단위로 조회하여 품목별 금액과 잔고를 확인하는 화면입니다.

### 1. 🏢 매입처 확인

조회할 매입처를 확인합니다.

- [···] 버튼을 클릭해 매입처를 설정해주세요.

### 2. 📅 조회 기간 지정

- **시작일·종료일**을 지정해 조회할 기간을 정합니다.

### 3. 🔍 검색

[🔍 검색] 버튼을 클릭하면 기간 내 원장 내역이 조회됩니다.

### 4. 📋 상품 단위 내역 확인

조회된 내역을 상품 단위로 훑으며 잔고 변동을 확인합니다.

**📌 상품정보 · 매입금액(+)**

- 마감일별로 **상품명·수량·단가·공급가**와 매입금액을 확인합니다.
**📌 결제내역(-) · 장려금(-) · 잔고합계(=)**

- 매입금액에서 **지급합계·장려금**을 뺀 **잔고합계**가 행마다 계산되어 표시됩니다.
  - 반품은 수량·금액이 마이너스로 표시되어 잔고에서 차감됩니다.
- 화면 하단 **합계 및 잔고** 줄에서 기간 전체 합계와 최종 잔고를 확인합니다.

### 📌 채무지급입력

[채무지급입력] 버튼으로 🔗 **채무 지급 관리** 화면으로 이동할 수 있습니다.

### 📌 합계 행 보기

- **일 합계 · 월 합계 · 월 총합계**를 체크하면 아래 목록에 주황색 **합계 행**이 함께 표시됩니다.

📌 결제 단위로 정리된 원장은 🔗 **매입처 원장(결제)**에서 확인할 수 있습니다.

# 미 입고 현황

발주했지만 아직 **입고되지 않은 내역**을 확인하는 조회 전용 화면입니다.

### 1. 🔎 미입고 현황 조회

- 검색창의 [···] 버튼을 누르면 **전체 현황**을 확인할 수 있습니다.
- [상세검색] 버튼을 누르면 조건을 지정해 **특정 현황**을 검색할 수 있습니다.

### 2. 📋 미입고 내역 확인

- 문서번호·입고예정일·**매입처·상품**과 규격·과세구분·단위·단가를 확인합니다.
- **발주수량·입고수량**과 아직 들어오지 않은 **미입고 수량·미입고 합계**를 확인합니다.

### 🗂️ 목록 다루기

- 열 머리글을 **클릭 앤 드래그**로 위 영역에 끌어오면 항목별로 묶어서 조회됩니다.
- **결과내 재검색**에 검색어를 입력하고 [찾기]를 누르면 조회된 목록 안에서 다시 찾습니다.

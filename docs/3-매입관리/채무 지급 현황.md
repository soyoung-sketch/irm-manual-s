# 채무 지급 현황

매입처에 지급한 **채무 지급 내역**을 피벗 표로 조회하는 **조회 전용** 화면입니다. 검색으로 원하는 내역을 찾고, 표를 원하는 대로 커스텀해 봅니다.

### 1. 🔎 채무 지급 현황 조회

두 가지 방법으로 원하는 지급 내역을 찾습니다.

**📌 통합검색**

- 통합검색 입력창의 [···] 버튼을 누르면 모든 정보를 한 번에 검색합니다.
**📌 조건 검색**

- 우측 패널에서 **매입처·담당자·지급일·결제구분·출금은행**을 지정하고 [검색]하면 내역이 출력됩니다.

### 2. 📋 지급 내역 확인

조회된 채무 지급 내역을 표에서 확인합니다.

- 행마다 **지급상태·지급일·매입처명**을 보여주고, 데이터 영역에 **지불금액** 필드가 지정되어 금액이 집계됩니다.
- 맨 아래 **Grand Total** 행에서 전체 합계를 확인합니다.

### 🧩 표 커스텀 (드래그)

보고 싶은 정보만 골라 표를 구성합니다.

- 상단의 **등록일·담당자명·결제구분·입금은행** 등 칩을 **클릭 앤 드래그**로 행·열 영역에 가져오면 표가 세분화되고, 표 밖으로 빼면 사라집니다.
- ⬇ 노란 칩 바를 클릭하면 **담당자명·결제구분·입금은행**을 행에 추가한 예시 화면으로 전환됩니다. 다시 클릭하면 돌아옵니다.

채무 지급 현황은 **조회 전용** 화면으로, 데이터를 수정하지 않고 확인만 합니다.

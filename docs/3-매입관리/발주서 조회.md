# 발주서 조회

---

## 발주서입력

등록한 발주서를 **발주대기 → 발주완료 → 입고** 단계로 처리하는 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 발주서 선택

발주서입력 목록에서 처리할 발주서를 선택합니다.

- 우측 상단 **통합검색·상세검색**으로 특정 문서를 찾을 수 있습니다.

### 2. 📤 발주대기로 넘김

내용 확인이 끝나면 [발주대기]로 넘겨 다음 단계로 보냅니다(발주대기 탭으로 이동).

### 📌 가능한 작업

- **인쇄** : [인쇄]로 선택한 발주서를 출력합니다.
- **수정** : [수정]으로 내용을 고칩니다(발주서 등록창과 시스템 동일).
- **취소** : [취소]로 발주서를 취소합니다 · 취소한 내역은 **취소** 탭에서 확인합니다.

---

## 발주대기

등록한 발주서를 **발주대기 → 발주완료 → 입고** 단계로 처리하는 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 발주서 선택

1차 컨펌이 끝난 **발주대기** 목록에서 처리할 발주서를 선택합니다.

### 2. 📦 발주완료로 전송

2차 컨펌이 끝나면 [발주완료]로 보내 매입처에 발주서를 전송합니다(발주완료 탭으로 이동).

### 📌 가능한 작업

- **인쇄** : [인쇄]로 선택한 발주서를 출력합니다.
- **되돌리기** : [발주서입력]으로 이전 단계로 되돌립니다.
- **수정** : [수정]으로 틀린 곳을 고칩니다.
- **취소** : [취소]로 쓰지 않을 발주서를 취소합니다.

---

## 발주완료

등록한 발주서를 **발주대기 → 발주완료 → 입고** 단계로 처리하는 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 발주서 선택

2차 컨펌이 끝난 **발주완료** 목록에서 처리할 발주서를 선택합니다.

### 2. 🚚 입고대기로 넘김

최종 컨펌이 끝나면 [입고대기]로 넘겨 입고 단계로 보냅니다(입고대기 탭으로 이동).

### 📌 가능한 작업

- **인쇄** : [인쇄]로 선택한 발주서를 출력합니다.
- **재전송** : [발주서 재전송]으로 매입처에 발주서를 다시 보냅니다.
- **취소** : [취소]로 쓰지 않을 발주서를 취소합니다.
- **수정** : 이 단계에서는 수정할 수 없습니다.

---

## 입고대기

등록한 발주서를 **발주대기 → 발주완료 → 입고** 단계로 처리하는 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 발주서 선택

최종 컨펌한 **입고대기** 목록에서 처리할 발주서를 선택합니다.

### 2. 📥 입고완료로 넘김

컨펌이 끝났으면 [입고완료]로 넘겨 입고를 마칩니다(입고완료 탭으로 이동).

### 📌 가능한 작업

- **매입 검수시작** : [매입 검수시작]으로 🔗 **매입 조회**의 금액 확인 화면으로 이동해 매입완료하면 입고완료됩니다.
- **인쇄** : [인쇄]로 선택한 발주서를 출력합니다.
- **취소** : [취소]로 쓰지 않을 발주서를 취소합니다.
- **수정** : 이 단계에서는 수정할 수 없습니다.

---

## 입고완료

발주부터 입고까지 **모든 처리가 끝난** 최종 목록 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 발주서 선택

입고가 완료된 **입고완료** 목록에서 확인할 발주서를 선택합니다.

### 2. 🖨️ 입고완료 인쇄

[인쇄] 버튼을 누르면 세 가지 인쇄 방식이 나옵니다.

**📌 **기본 발주서** · **매장별 인쇄** · **XDock 인쇄** 중 골라 인쇄합니다.**

### 📌 가능한 작업

- **수정** : 이 단계에서는 수정할 수 없습니다.
- **취소** : 이 단계에서는 취소할 수 없습니다.

---

## 입고반려

**입고반려**는 **SCM 매입처**에서 요청할 수 있으며, 반려된 발주서가 이 탭에 모입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 반려 발주서 확인

입고가 반려된 **입고반려** 목록에서 확인할 발주서를 선택합니다.

### 2. 🔄 발주서 재전송

반려된 발주서를 [발주서 재전송]으로 매입처에 다시 보냅니다.

### 📌 가능한 작업

- **수정** : [수정]으로 발주서를 고쳐 다시 처리합니다.
- **취소** : [취소]로 쓰지 않을 발주서를 취소합니다.

---

## 취소

**취소** 탭에서는 취소한 발주서를 확인하고 필요하면 다시 되돌립니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. ✅ 취소 발주서 확인

취소한 **발주서 목록**에서 되돌릴 발주서를 선택합니다.

### 2. ◀ 발주서입력으로 복구

취소한 발주서를 [발주서입력]으로 다시 발주서입력 단계로 복구합니다.

### 📌 가능한 작업

- **인쇄** : [인쇄]로 선택한 발주서를 출력합니다.
- **수정** : 복구할 때 [수정]도 함께 할 수 있습니다.
- **취소** : 이 단계에서는 취소할 수 없습니다.

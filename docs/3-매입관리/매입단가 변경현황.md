# 매입단가 변경현황

상품별 **매입단가가 변경된 이력**을 날짜별로 조회하는 **조회 전용** 화면입니다. 검색으로 원하는 내역을 찾고, 표를 원하는 대로 커스텀해 봅니다.

### 1. 🔎 매입단가 변경현황 조회

두 가지 방법으로 원하는 변경 내역을 찾습니다.

**📌 통합검색**

- 통합검색 입력창의 [···] 버튼을 누르면 모든 정보를 한 번에 검색합니다.
- **매입처**를 입력해 검색할 수 있습니다.
**📌 상세검색**

- [상세검색]을 누르면 조건 입력 패널이 열립니다. 원하는 조건을 지정하고 [검색]하면 목록이 출력됩니다.

### 2. 📋 변경 내역 확인

조회된 매입단가 변경 내역을 표에서 확인합니다.

- 행마다 **매입처코드·매입처명·상품코드·상품명**을 보여주고, 열은 변경이 발생한 **날짜**별로 나뉩니다.
- 각 칸에는 해당 날짜에 변경된 **매입단가**가 표시되어 단가 변동 흐름을 한눈에 볼 수 있습니다.

매입단가 변경현황은 **조회 전용** 화면으로, 데이터를 수정하지 않고 확인만 합니다.

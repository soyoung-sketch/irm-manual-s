# 매입 현황

매입한 내역을 조회하는 **조회 전용** 화면입니다. 검색으로 원하는 내역을 찾고, 표를 원하는 대로 커스텀해 봅니다.

### 1. 🔎 매입현황 조회

두 가지 방법으로 원하는 매입 내역을 찾습니다.

**📌 통합검색**

- 통합검색 입력창의 [···] 버튼을 누르면 모든 정보를 한 번에 검색합니다.
**📌 상세검색**

- [상세검색]을 누르면 조건 패널이 열립니다. **매입처·부서명·담당자·매입일·작성일·분류** 등을 지정하고 [검색]하면 목록이 출력됩니다.

### 2. 📋 매입현황 확인

조회된 매입 내역을 피벗 표에서 확인합니다.

- **매입일(재고)·매입처명·상품코드·상품명**별로 **총 수량·합계금액**을 볼 수 있습니다.
- **매입상태**가 열로 표시되며 맨 아래 **Grand Total** 합계행이 표시됩니다.

### 🧩 표 커스텀 (드래그)

보고 싶은 정보만 골라 표를 구성합니다.

- 상단의 **문서번호·매입년/월·대분류·매입처코드·작성일** 등 칩을 **클릭 앤 드래그**로 표에 가져오면 열이 추가됩니다.
- 반대로 표 밖으로 빼면 해당 열이 사라집니다. 원하는 항목만 남겨 봅니다.

### ⚙ 레이아웃관리 사용법 재생

[⚙ 레이아웃관리] 버튼을 클릭하면 **레이아웃 관리 창**이 열립니다.

- **레이아웃 신규저장** · 현재 구성을 새 이름으로 저장합니다.
- **레이아웃 불러오기** · 저장된 레이아웃을 적용하며 **삭제**도 가능합니다.

매입현황은 **조회 전용** 화면으로, 데이터를 수정하지 않고 확인만 합니다.

# 장려금 입금 현황

매입처에서 받은 **장려금 입금 내역**을 조회하는 **조회 전용** 화면입니다. 검색으로 원하는 내역을 찾고, 표를 원하는 대로 커스텀해 봅니다.

### 1. 🔎 장려금 입금 현황 조회

두 가지 방법으로 원하는 입금 내역을 찾습니다.

**📌 통합검색**

- 통합검색 입력창의 [···] 버튼을 누르면 모든 정보를 한 번에 검색합니다.
**📌 상세검색**

- [상세검색]을 누르면 조건 입력 패널이 열립니다. 원하는 조건을 지정하고 [검색]하면 목록이 출력됩니다.

### 2. 📋 입금 내역 확인

조회된 장려금 입금 내역을 표에서 확인합니다.

- 행마다 **입금일·매입처코드·매입처명**을 보여주고, 열은 **입금구분**별로 나뉩니다.
- 데이터 영역에는 **금액** 필드가 지정되어 각 칸에 **장려금** 금액이 집계됩니다.

### 🧩 표 커스텀 (드래그)

보고 싶은 정보만 골라 표를 구성합니다.

- 상단의 **사업자등록번호·등록일·담당자명·상태** 등 칩을 **클릭 앤 드래그**로 표에 가져오면 열이 추가됩니다.
- 반대로 표 밖으로 빼면 해당 열이 사라집니다. 원하는 항목만 남겨 봅니다.

장려금 입금 현황은 **조회 전용** 화면으로, 데이터를 수정하지 않고 확인만 합니다.

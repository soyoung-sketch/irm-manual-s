# 월 매입 마감 조회

---

## 작성중

월 매입 마감정보를 **확인부터 마감완료까지** 처리하는 화면입니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 1. 🔍 조회하기

조회 조건을 지정하고 [검색]합니다.

- **담당자**로 검색하기
- **시작·종료일** 설정해서 검색하기
- **매입처 선택**해서 검색하기

### 2. ✅ 마감정보 선택

**작성중** 목록에서 마감할 매입처 마감정보 행을 확인하고 선택합니다.

### 3. 📤 마감완료

확인이 끝났으면 [마감완료]로 마감을 확정합니다(「마감완료」 탭으로 이동).

### 📌 가능한 작업

- **마감안함** : [마감안함]으로 마감하지 않음 처리합니다(「마감안함」 탭으로 이동).
- **취소** : [취소]로 마감을 취소합니다 · 취소한 내역은 「취소」 탭으로 이동합니다.

---

## 취소

**취소** 탭에서는 마감을 **취소**한 매입 마감정보 목록을 확인합니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 📌 가능한 작업

- **마감안함** : [마감안함]으로 마감하지 않음 처리합니다(「마감안함」 탭으로 이동).
- **마감완료·취소** : 이 단계에서는 사용할 수 없습니다.

---

## 마감안함

**마감안함** 탭에서는 마감하지 않음 처리한 매입 마감정보 목록을 확인합니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 📌 가능한 작업

- **마감완료** : [마감완료]로 마감을 완료합니다(「마감완료」 탭으로 이동).
- **취소** : [취소]로 마감을 취소합니다(「취소」 탭으로 이동).
- **마감안함** : 이 단계에서는 사용할 수 없습니다.

---

## 마감완료

**마감완료** 탭에서는 마감이 완료된 매입 마감정보 목록을 확인합니다. 상단 **탭**으로 상태별 목록을 봅니다.

### 📌 가능한 작업

- **마감안함** : 마감을 원치 않으면 [마감안함]으로 되돌립니다(「마감안함」 탭으로 이동).
- **취소** : [취소]로 마감을 취소합니다(「취소」 탭으로 이동).
- **마감완료** : 이 단계에서는 사용할 수 없습니다.

# 가격표 관리

---

## 작성중

위치별로 상품을 담아 만든 **가격표**를 관리하는 화면입니다 · 작성 중 가격표를 **작업완료** 또는 **취소**로 정리합니다.

### 1. 📋 가격표 선택

**작성일·담당자·위치명·상품수**를 확인하고 가격표를 선택합니다.

### 2. 🛒 담긴 상품 확인

선택한 가격표에 담긴 **상품·판매단가**를 확인합니다.

### 3. 🎨 POP생성

[POP생성]으로 담긴 상품의 POP를 만듭니다.

- 🔗 **POP 인쇄 관리** 페이지 바로가기

### 4. 🏷️ 바코드인쇄

[바코드인쇄]로 담긴 상품의 바코드를 인쇄합니다.

- 🔗 **바코드 인쇄관리** 페이지 바로가기

### 5. 📥 작업완료

작업을 마친 가격표는 [작업완료]로 정리합니다.

- 필요 없는 가격표는 [취소]로 취소 탭에 보관합니다.

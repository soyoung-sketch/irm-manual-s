# 마감코드 체크목록

마감코드와 매출자료의 연결 상태를 확인하는 화면입니다. **마감이 완료되지 않았거나 마감코드와 매출자료가 일치하지 않는** 내역을 조회할 수 있습니다.

### 1. ✔️ 마감코드 미지정 목록

- 마감코드가 지정되지 않은 매출자료를 조회하는 탭입니다.
- 조회할 매출일을 선택한 후 [🔍 검색] 버튼을 클릭해주세요.
&nbsp;&nbsp;⬇

- 마감코드가 등록되지 않은 매출 내역이 조회됩니다.

### 2. ✅ 매출기준 : 마감코드 마감일 확인

- 매출일 기준으로 마감코드의 마감일 정보를 확인하는 탭입니다.
- 조회할 매출일을 선택한 후 [🔍 검색] 버튼을 클릭해주세요.
&nbsp;&nbsp;⬇

- 매출자료와 연결된 마감코드의 마감일을 확인할 수 있습니다.

### 3. ✅ 마감기준 : 마감코드 매출일 확인

- 마감일 기준으로 연결된 매출자료를 확인하는 탭입니다.
- 조회할 매출일을 선택한 후 [🔍 검색] 버튼을 클릭해주세요.
&nbsp;&nbsp;⬇

- 선택한 마감코드에 연결된 매출일 정보를 확인할 수 있습니다.

### 추가 기능

- [📝 마감코드 수정] : 선택한 내역의 마감코드를 수정할 수 있습니다.
- [📄 매출내역보기] : 선택한 매출자료의 상세 내역을 확인할 수 있습니다.

### 조회 결과 확인

- 마감일 / 마감코드 / 판매일 / 포스번호 / 담당자ID / 담당자명 / 문서번호 / 사업장코드 / 판매구분 / 부서명 / 매출처코드 / 매출처명 / 현장명 / 판매단가그룹 / 결제방법 / 배송구분

💡 마감코드와 매출자료가 정상적으로 연결되었는지 확인할 수 있습니다.
    💡 마감 누락 또는 연결 오류가 발생한 자료를 점검할 수 있습니다.
    💡 조회 화면에서는 데이터 확인 및 **마감코드 수정만 가능**하며 매출자료 수정은 불가능합니다.

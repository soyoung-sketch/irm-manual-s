# 로케이션 관리

**로케이션 관리**는 매장·창고의 **로케이션(위치) 분류**를 단계별로 등록·관리하는 화면입니다.

> 진행 순서 : **① 로케이션 검색 → ② 분류 단계 선택 → ③ 분류 추가**

### 1. 🔍 로케이션 검색·선택

- 검색어를 입력하고 [찾기] 를 눌러 편집할 **로케이션**을 찾습니다.
&nbsp;&nbsp;⬇

- 분류 트리에서 로케이션을 **선택**하면 오른쪽 분류 열에 해당 정보가 표시됩니다.

### 2. 📋 분류 단계 선택

- **대분류 ▸ 중분류 ▸ 소분류 ▸ 세분류** 순으로 선택하면 다음 단계 목록이 걸러져 표시됩니다.
**📌 열별 내용**

- **대분류**에서 **창고 / 매장** 여부를 지정합니다.
- **중분류 · 소분류 · 세분류** : 윗단계를 고르면 그 안에 속한 하위 위치만 표시됩니다.

### 3. ➕ 분류 추가·편집

- 입력칸에 분류명을 입력하고 [＋] 를 누르면 해당 단계에 분류가 추가됩니다.

**📌 함께 쓰는 버튼**

- 항목을 체크하고 [✕] 를 누르면 분류가 삭제됩니다.
- [▲] [▼] 로 분류가 표시되는 순서를 위아래로 옮깁니다.
- [🖨] 를 누르면 🔗 **바코드인쇄관리** 페이지로 이동합니다.

### 📊 엑셀등록

[엑셀등록]으로 로케이션을 **엑셀 양식**으로 한 번에 등록합니다.

- 1 **샘플저장** : 샘플 엑셀파일을 저장한 후 작성해주세요.
&nbsp;&nbsp;⬇

- 2 **엑셀선택** : 저장한 엑셀파일을 선택해 불러오기해주세요.
&nbsp;&nbsp;⬇

- 3 **목록확인** : 불러온 파일의 정보를 확인해주세요.
&nbsp;&nbsp;⬇

- 4 **신규등록** : [신규등록] 버튼을 눌러 저장해주세요.
&nbsp;&nbsp;⬇

- 5 **닫기** : [닫기] 버튼을 눌러 창을 닫고 목록으로 돌아갑니다.

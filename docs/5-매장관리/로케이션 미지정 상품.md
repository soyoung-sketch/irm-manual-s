# 로케이션 미지정 상품

**미지정 상품목록**은 **로케이션(위치)이 지정되지 않은** 상품 목록을 조회·검색하고 엑셀로 저장하는 화면입니다.

### 1. ✔️ 미지정 상품목록

- 로케이션이 지정되지 않은 상품이 목록으로 표시됩니다.
- **대분류·중분류·소분류·세분류·매입처·상품코드·상품명·단위·재고수** 등을 확인할 수 있습니다.

### 2. 🔍 상품 검색

- 검색어를 입력하고 [🔍 찾기] 를 누릅니다.
&nbsp;&nbsp;⬇

- 검색어와 일치하는 상품만 목록에 표시됩니다.

### 3. 💾 엑셀저장

- [📗 엑셀저장] 버튼을 누르면 현재 목록이 **엑셀 파일**로 저장되어 열립니다.

💡 미지정 상품목록은 위치가 지정되지 않은 상품을 확인하는 화면입니다. (위치 지정은 **로케이션 상품 등록**에서 해주세요)

# 계산원 마감 관리

---

## 업무중

계산원의 하루 근무를 **업무중 → 마감점검 → 마감중 → 마감확정** 단계로 관리하는 화면입니다 · 상단 탭으로 단계별 목록을 오갑니다.

### 1. 👤 사원 지정

조회할 **사원명**을 입력합니다.

- 돋보기를 클릭하면 **사원 검색** 창에서 골라 지정할 수 있습니다.

### 2. 📅 업무일 지정

조회할 **업무일** 범위를 지정합니다.

- **시작일**과 **종료일**을 설정해주세요.
- [···] 버튼으로 오늘·이번 주 등 **날짜 그룹**을 빠르게 선택할 수 있습니다.

### 3. 🔍 검색

조건을 정하고 [검색] 버튼으로 조회합니다.

### 4. 📋 계산원 목록 확인

업무 중인 계산원의 **시재금액·마감정보**를 확인하고 처리할 행을 선택합니다.

### 5. ✏️ 마감중 처리

선택한 계산원을 [마감중] 버튼으로 🔗 **마감중** 단계로 넘깁니다.

- [마감점검] 버튼으로 넘기면 🔗 **마감점검** 탭에서, [취소] 버튼을 누르면 🔗 **취소** 탭에서 확인합니다.

### ➕ 계산원추가

[+ 계산원추가] 버튼을 누르면 추가 패널이 열립니다.

- **시작일**과 **포스번호**를 설정하고 배치할 **담당자**를 선택해주세요.
- [+추가] 버튼을 누르면 좌측 리스트에 계산원이 추가됩니다.

---

## 마감점검

**마감점검** 단계의 계산원을 점검하고 마감금액을 수정하는 탭입니다.

### 1. 🔍 검색

**사원명·업무일**을 지정하고 [검색]으로 조회합니다.

### 2. 📋 점검 내역 확인

계산원의 **시재금액·마감정보**를 확인하고 처리할 행을 선택합니다.

### 3. ✅ 마감확정

점검을 마친 계산원을 [마감확정] 버튼으로 확정합니다.

- 확정된 계산원은 🔗 **마감확정** 탭에서 확인합니다.
- [마감중] 버튼으로 넘기면 🔗 **마감중** 탭에서 확인합니다.
- [업무중으로] 버튼으로 🔗 **업무중** 상태까지 되돌릴 수도 있습니다.

### 💰 마감금액수정

[마감금액수정] 버튼으로 수정 패널을 엽니다.

- **시재금액·권종 수량**을 고치고 [저장]으로 반영합니다 · [닫기]로 취소합니다.

### 🔄 마감금액일괄수정

현재 매장에서 일어나고 있는 **변경정보를 반영**해 주는 새로고침 버튼입니다.

---

## 마감중

**마감중** 단계의 계산원을 최종 확인하고 **마감확정**까지 처리하는 탭입니다.

### 1. 🔍 검색

**사원명·업무일**을 지정하고 [검색]으로 조회합니다.

### 2. 📋 마감 내역 확인

계산원의 **마감금액·과부족·권종 입금액**을 확인하고 처리할 행을 선택합니다.

### 3. 🔄 마감점검으로 되돌리기

수정이 필요하면 [**마감점검**] 버튼으로 되돌립니다.

- [업무중으로] 버튼으로 🔗 **업무중** 상태까지 되돌릴 수도 있습니다.

### 4. ✅ 마감확정

확인을 마친 계산원을 [마감확정] 버튼으로 확정합니다.

- 확정된 계산원은 🔗 **마감확정** 탭에서 확인합니다.

### 📄 시재문서 열기

[시재문서 열기] 버튼으로 선택한 계산원의 **시재문서**(카드·외상·할인·현금 내역, 매출합계)를 함께 확인합니다.

### 💰 마감금액수정

[마감금액수정] 버튼으로 수정 패널을 엽니다.

- **시재금액·권종 수량**을 고치고 [저장]으로 반영합니다 · [닫기]로 취소합니다.

### 🔄 마감금액일괄수정

현재 매장에서 일어나고 있는 **변경정보를 반영**해 주는 새로고침 버튼입니다.

---

## 마감확정

**마감확정**된 계산원을 조회하는 탭입니다 · 확정 후에는 상태를 변경할 수 없습니다.

### 1. 🔍 검색

**사원명·업무일**을 지정하고 [검색]으로 조회합니다.

### 2. 📋 확정 내역 확인

확정된 계산원의 **마감금액·과부족·권종 입금액**을 확인합니다.

### 📄 시재문서 열기

[시재문서 열기] 버튼으로 선택한 계산원의 **시재문서**를 확인합니다.

### 💰 마감금액수정

[마감금액수정] 버튼으로 수정 패널을 엽니다.

- **시재금액·권종 수량**을 고치고 [저장]으로 반영합니다 · [닫기]로 취소합니다.

### 🔄 마감금액일괄수정

현재 매장에서 일어나고 있는 **변경정보를 반영**해 주는 새로고침 버튼입니다.

---

## 취소

**취소**한 계산원 마감을 모아 보는 탭입니다.

### 1. 🔍 검색

**사원명·업무일**을 지정하고 [검색]으로 조회합니다.

### 2. 📋 취소 내역 확인

취소한 계산원 마감의 **시재금액·마감정보**를 확인합니다.

---

## 임시마감(휴식중)

휴식 등으로 **임시마감**한 계산원을 모아 보는 탭입니다.

### 1. 🔍 검색

**사원명·업무일**을 지정하고 [검색]으로 조회합니다.

### 2. 📋 임시마감 내역 확인

임시마감(휴식) 중인 계산원의 **시재금액·마감정보**를 확인합니다.

### 🖥️ 포스에서 임시마감 처리

포스에서 **매출마감 → 계산원마감금액 → 임시 마감(휴식)** 순서로 처리하면 이 탭에 표시됩니다.

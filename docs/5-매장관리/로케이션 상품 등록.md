# 로케이션 상품 등록

**로케이션 상품 등록**은 분류(로케이션)별로 상품을 등록하고, 상품의 **보관 위치**를 지정하는 화면입니다.

> 진행 순서 : **① 분류 선택 → ② 상품추가**

### 1. ✔️ 분류 선택

- **카테고리 분류** 트리에서 상품을 등록할 분류를 선택합니다.
  - 여기서 선택한 분류가 그대로 상품의 위치정보로 지정됩니다.

### 2. ➕ 상품추가

- [＋ 상품추가] 버튼을 누르면 **상품 통합검색** 창이 열립니다.
&nbsp;&nbsp;⬇

- 상품을 선택하고 [✔ 선택] 을 누르면 목록에 추가됩니다.

- 추가된 상품의 **위치정보·상품코드·상품명·단위·재고수** 를 목록에서 확인합니다.
- 💡 상품 행이나 **체크박스**를 클릭하면 체크 표시(✓)가 생깁니다.

### 🗑️ 상품삭제

- 삭제할 상품을 체크한 뒤 [✕ 상품삭제] 를 누르면 목록에서 제거됩니다.

### 📍 위치이동

- 위치를 바꿀 상품을 체크하고 [↻ 위치이동] 을 누르면 **위치정보 검색** 창이 열립니다.
&nbsp;&nbsp;⬇

- 대분류 ▸ 중분류 ▸ 소분류 ▸ 세분류를 선택하고 [선택] 을 누르면 **위치정보**가 변경됩니다.

# 바코드 인쇄관리

---

## 상품정보 바코드 인쇄

상품에 붙일 **바코드 라벨**을 골라 미리보고 프린터로 출력하는 화면입니다.

### 1. ➕ 상품 담기

- [+ 상품추가] 버튼을 클릭하면 상품 통합검색창이 열립니다.
- 검색한 상품을 선택하면 인쇄 목록에 담깁니다.

### 2. ☑️ 인쇄할 상품 선택

- 담긴 상품의 **상품코드 · 바코드 · 상품명 · 단위 · 내품수/G · 판매가격**을 확인합니다.
- 인쇄할 행의 **체크박스**를 클릭해 대상을 고릅니다.

### 3. 🏷️ 인쇄 템플릿 선택

라벨의 모양과 크기를 정합니다.

- **바코드 인쇄 템플릿** 목록에서 사용할 템플릿을 클릭하면 미리보기에 바로 반영됩니다.
- 템플릿은 🔗 **바코드 템플릿**에서 만들고 수정합니다.
- 선택한 상품과 템플릿이 적용된 **인쇄 모양**을 미리보기에서 확인합니다.
- 미리보기 상단에 인쇄할 상품명·상품코드와 라벨 크기(70×30mm)가 표시됩니다.

### 4. 🖨️ 바코드 인쇄

- **프린터명**에서 라벨을 출력할 프린터를 선택합니다.

- [바코드 인쇄] 버튼을 클릭하면 지정한 매수만큼 출력됩니다.

### 🔢 인쇄수 지정

- 상품 한 건당 뽑을 **매수**를 입력한 후 [✓] 버튼을 클릭해 적용합니다.
  - 따로 지정하지 않으면 한 건당 1매씩 출력됩니다.

### 🔍 미리보기 배율

- [+] [−] 버튼을 클릭하거나 배율을 직접 입력해 미리보기를 **확대·축소**합니다.
  - 배율은 화면에서 보이는 크기만 바꾸며 실제 인쇄 크기는 템플릿을 따릅니다.

### 📋 기타 버튼

- [✕ 삭제] : 체크한 상품을 인쇄 목록에서 뺍니다.
- [바코드 초기화] : 담긴 목록과 설정을 모두 지우고 처음 상태로 되돌립니다.

## 쿠폰정보 바코드 인쇄

발행한 **할인쿠폰의 바코드**를 골라 미리보고 프린터로 출력하는 화면입니다.

### 1. ☑️ 인쇄할 쿠폰 선택

- 등록된 쿠폰의 **순서 · 바코드 · 제목 · 할인구분 · 할인금액**을 확인합니다.
- 인쇄할 행의 **체크박스**를 클릭해 대상을 고릅니다.
  - 쿠폰은 「할인쿠폰 등록」 메뉴에서 먼저 발행해야 목록에 나타납니다.

### 2. 🏷️ 인쇄 템플릿 선택

- **쿠폰바코드 · 쿠폰QR** 중 사용할 템플릿을 클릭하면 미리보기에 바로 반영됩니다.
  - 템플릿은 「바코드 템플릿」 메뉴에서 만들고 수정합니다.

- 쿠폰과 템플릿을 모두 고르면 미리보기에 **인쇄 모양**이 표시됩니다.
  - 둘 중 하나라도 고르지 않으면 안내 문구만 표시됩니다.

### 3. 🖨️ 바코드 인쇄

- **프린터명**에서 라벨을 출력할 프린터를 선택합니다.

- [바코드 인쇄] 버튼을 클릭하면 지정한 매수만큼 출력됩니다.

### 🔢 인쇄수 지정

- 쿠폰 한 건당 뽑을 **매수**를 입력합니다.
  - 따로 지정하지 않으면 한 건당 1매씩 출력됩니다.

### 🔍 미리보기 배율

- [+] [−] 버튼을 클릭하거나 배율을 직접 입력해 미리보기를 **확대·축소**합니다.

### 📋 기타 버튼

- [✕ 삭제] : 체크한 쿠폰을 인쇄 목록에서 뺍니다.
- [바코드 초기화] : 담긴 목록과 설정을 모두 지우고 처음 상태로 되돌립니다.

## 로케이션 바코드 인쇄

진열 위치에 붙일 **로케이션 QR 라벨**을 골라 미리보고 프린터로 출력하는 화면입니다.

### 1. ➕ 로케이션 담기

- [+ 로케이션] 버튼을 클릭하면 **위치정보 검색** 창이 열립니다.
- 위치를 선택하면 인쇄 목록에 담깁니다.

### 2. ☑️ 인쇄할 로케이션 선택

- 담긴 **순서 · 로케이션코드(바코드) · 로케이션명**을 확인합니다.
- 로케이션명은 **대분류 > 중분류 > 소분류 > 세분류** 순서로 이어져 표시됩니다.
- 인쇄할 행의 **체크박스**를 클릭해 대상을 고릅니다.

### 3. 🏷️ 인쇄 템플릿 선택

- **로케이션바코드 600*600**처럼 QR 크기가 정해진 템플릿을 클릭하면 미리보기에 바로 반영됩니다.
  - 템플릿은 「바코드 템플릿」 메뉴에서 만들고 수정합니다.

- 로케이션명과 **QR코드**가 찍힌 인쇄 모양을 미리보기에서 확인합니다.
  - 미리보기 상단에 로케이션코드와 라벨 크기(60×60mm)가 표시됩니다.

### 4. 🖨️ 바코드 인쇄

- **프린터명**에서 라벨을 출력할 프린터를 선택합니다.

- [바코드 인쇄] 버튼을 클릭하면 담긴 로케이션 QR이 출력됩니다.

### 🔍 미리보기 배율

- [+] [−] 버튼을 클릭하거나 배율을 직접 입력해 미리보기를 **확대·축소**합니다.

### 🔎 위치정보 검색 창

[+ 로케이션] 버튼으로 열리는 창입니다.

- **위치정보 검색**에 이름이나 코드를 입력한 후 [검색] 버튼을 클릭합니다.
- 아래 **대분류 → 중분류 → 소분류 → 세분류** 목록을 차례로 클릭해 위치를 좁혀갈 수도 있습니다.
- [선택] 버튼을 클릭하면 로케이션이 인쇄 목록에 추가됩니다.

### 📋 기타 버튼

- [✕ 삭제] : 체크한 로케이션을 인쇄 목록에서 뺍니다.
- [바코드 초기화] : 담긴 목록과 설정을 모두 지우고 처음 상태로 되돌립니다.

# 계산원별 매출현황

계산원(사원)별 **판매 실적**을 업무일 단위로 조회하는 화면입니다.

### 1. 👤 사원 지정

조회할 **사원명**을 입력합니다.

- 돋보기를 클릭하면 **사원 검색** 창에서 골라 지정할 수 있습니다.

### 2. 📅 업무일 지정

조회할 **업무일** 범위를 지정합니다.

- **시작일**과 **종료일**을 설정해주세요.
- [···] 버튼으로 오늘·이번 주 등 **날짜 그룹**을 빠르게 선택할 수 있습니다.

### 3. 🔍 검색

조건을 정하고 [검색] 버튼으로 조회합니다.

### 4. 📋 매출 실적 확인

매출일·사업장·사원별 **보류·반품·매출건수와 매출금액**을 확인합니다.

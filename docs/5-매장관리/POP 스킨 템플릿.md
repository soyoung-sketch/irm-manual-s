# POP 스킨 템플릿

---

## POP 스킨 템플릿

POP 인쇄에 사용할 **스킨 템플릿**을 등록·관리하는 화면입니다 · 목록은 **카테고리별**로 묶여 표시됩니다.

### 1. 🗂️ 분류관리

템플릿의 카테고리를 정리합니다.

- [분류관리]를 누르면 **카테고리 변경 · 카테고리 관리** 메뉴가 열립니다.
**📌 카테고리 변경**

- 선택한 템플릿이 들어갈 **카테고리**를 고르고 [분류선택]을 누릅니다.
**📌 카테고리 관리**

- 카테고리를 **추가·삭제**하고 ▲▼ 버튼으로 **순서**를 바꿉니다.

### 2. ➕ 스킨추가

[스킨추가]를 누르면 **POP 스킨 디자인** 화면이 열립니다 · 텍스트·바코드·QR코드·이미지로 스킨을 만듭니다.

### 3. ✏️ 수정

목록에서 템플릿을 선택하고 [수정]을 누르면 디자인 화면에서 고칠 수 있습니다.

### 4. 📄 복사

선택한 템플릿을 **복제**해 새 템플릿으로 만듭니다.

### 5. 🗑️ 삭제

선택한 템플릿을 **삭제**합니다.

완성한 스킨은 **POP 인쇄 관리**에서 인쇄에 사용합니다.

---

## 스킨 디자인

**텍스트·바코드·QR코드·이미지** 요소로 POP 스킨을 디자인하는 화면입니다.

### 1. 🧩 요소 추가

좌측 **기본 요소**(텍스트·바코드·QR코드·이미지)를 클릭해 캔버스에 추가합니다.

### 2. ⚙️ 속성 설정

선택한 요소의 **속성**을 설정합니다.

### 3. 🛠️ 편집 도구

**저장(Ctrl+S)**과 실행 취소·정렬·그룹화·복제 등 편집 도구를 사용합니다.

- [저장] 또는 우측 상단 **✕**를 누르면 템플릿 목록으로 돌아갑니다.

### 🏷️ 미리보기

추가한 요소가 배치되는 **미리보기 편집** 화면입니다.

### 📐 페이지 설정

**페이지 크기·각도·프리셋·줌**을 설정합니다.

### 🖨️ 다매 인쇄

**다매 인쇄**를 체크하면 스킨 여러 장을 한 페이지에 배치해 출력합니다.

- **라벨 크기·여백·간격**은 다매 인쇄를 체크했을 때만 수정할 수 있습니다.

# 바코드 템플릿

---

## 바코드탬플릿

바코드 인쇄에 사용할 **바코드 템플릿**을 만들고 관리하는 화면입니다.

### 1. 🗂️ 바코드 타입 선택

인쇄할 **바코드 타입**(상품정보·쿠폰정보·로케이션)을 선택합니다.

### 2. ➕ 바코드 추가

[+ 바코드 추가] 버튼을 누르면 **바코드 템플릿 디자인** 화면이 열립니다.

- **텍스트·바코드·QR코드·이미지** 요소로 라벨을 디자인하고 [저장]합니다.

### 3. 📋 템플릿 목록 확인

사업장·타입별로 묶인 템플릿의 **바코드명·크기**를 확인해주세요.

- 수정을 원하는 경우 **더블클릭**해 편집합니다.

### ➕ 라인 추가

[+ 라인 추가]를 누르면 목록에 **구분용 라인 행**이 추가됩니다.

### 📄 복사

[복사]로 선택한 템플릿을 복제합니다 · **(복사)** 이름으로 목록에 추가됩니다.

---

## 바코드추가

**텍스트·바코드·QR코드·이미지** 요소로 바코드 라벨을 디자인하는 화면입니다.

### 1. 🧩 요소 추가

좌측 **기본 요소**(텍스트·바코드·QR코드·이미지)를 클릭해 라벨에 추가합니다.

### 2. ⚙️ 속성 설정

선택한 요소의 **속성**을 설정합니다.

### 3. 🛠️ 편집 도구

**저장(Ctrl+S)**과 실행 취소·정렬·그룹화·복제 등 편집 도구를 사용합니다.

- [저장], 또는 [닫기]를 누르면 템플릿 목록으로 돌아갑니다.

### 🏷️ 미리보기

추가한 요소가 배치되는 **미리보기 편집** 화면입니다.

### 🖨️ 다매 인쇄

**다매 인쇄**를 체크하면 라벨 여러 장을 한 페이지에 배치해 출력합니다.

- 하단에서 **페이지 크기·라벨 크기·여백·간격**을 함께 설정합니다.

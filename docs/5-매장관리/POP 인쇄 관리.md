# POP 인쇄 관리

상품의 **POP 용지**를 템플릿에 맞춰 미리보고 인쇄하는 화면입니다.

💡 매장관리 리본에서 바로 열거나, 「사업장 상품관리」에서 상품을 선택한 후 [POP 인쇄] 버튼으로 열 수 있습니다.

### 1. ➕ 상품추가

- [+ 상품추가] 버튼을 클릭하면 상품 통합검색창이 열립니다.
- 검색한 상품을 선택하면 인쇄할 상품 목록에 추가됩니다.

### 2. ✅ 상품 목록 확인

- 추가한 상품의 **상품코드 · 바코드 · 상품명**을 확인합니다.
- 상품을 클릭하면 해당 상품의 POP가 미리보기에 표시됩니다.
- 왼쪽 **체크박스**로 인쇄하거나 삭제할 상품을 선택하고, 머리글 체크박스를 클릭하면 **전체 선택**됩니다.

### 3. 🎨 POP 인쇄 템플릿 선택

인쇄에 사용할 스킨을 고릅니다.

- **이미지** 열의 썸네일로 모양을 확인하고 사용할 **템플릿**을 선택합니다.
  - 목록 오른쪽 **스크롤바**로 등록된 템플릿을 더 확인할 수 있습니다.

### 4. 👁️ 미리보기 확인

- 선택한 템플릿이 적용된 **POP 용지**를 인쇄 전에 확인합니다.
- 템플릿 문구와 **판매가 · 바코드**가 210×297mm 용지에 배치된 모습을 확인합니다.

### 5. 🖨️ 프린터 선택 · POP 인쇄

- **프린터명**에서 POP를 출력할 프린터를 선택합니다.

- [POP 인쇄] 버튼을 클릭하면 입력한 인쇄수만큼 출력됩니다.

### 🔢 인쇄수 입력

- 인쇄할 **매수**를 입력한 후 [✓] 버튼을 클릭해 적용합니다.
  - 기본값은 1매이며, 여러 장을 뽑을 때만 바꿔 주면 됩니다.

### 🔎 미리보기 정보·배율

- 미리보기 표시줄에서 지금 보고 있는 **상품명·상품코드**와 용지 크기를 확인합니다.
- [+] [−] 버튼으로 배율을 조절하고 [100%] 버튼으로 원래 크기로 되돌립니다.

### 📋 기타 버튼

- [✕ 삭제] : 선택한 상품을 목록에서 제거합니다.
- [POP초기화] : 입력한 내용과 목록을 모두 지우고 처음 상태로 되돌립니다.

# 폐기처리 등록

매장에서 **폐기 처리**한 상품을 등록하여 재고에서 차감하는 화면입니다. 폐기 증빙 **사진**도 함께 등록할 수 있습니다.

> 진행 순서 : **① 상품 검색** → **② 수량 입력** → **③ 기본 정보 입력** → **④ 신규등록**

### 1. 🔍 상품 검색

- 상품 행의 상품코드 [···] 버튼을 클릭하면 **상품 통합검색** 창이 열립니다.
&nbsp;&nbsp;⬇

- 상품을 검색·체크한 후 [✔ 선택] 버튼을 클릭하면 폐기 목록에 추가됩니다.

### 2. ✔️ 수량 입력

- 폐기할 상품의 **수량**을 입력하면 공급가·부가세·합계금액이 자동 계산됩니다.

### 3. 📝 기본 정보 입력

- **폐기일 · 부서명 · 담당자 · 사용유형**(필수)을 입력합니다.
  - 사진 등록(선택) : [➕ 추가] 버튼으로 폐기 증빙 사진을 등록하고 미리보기로 확인합니다.

### 4. 💾 신규등록

- 입력 내용을 확인한 후 [💾 신규등록(F5)] 버튼을 클릭하면 폐기처리 전표가 저장됩니다.
&nbsp;&nbsp;⬇

- 저장된 전표는 🔗 **폐기처리 조회** 메뉴에서 확인할 수 있습니다.

### 📄 문서불러오기

- 기존 폐기처리 전표를 불러와 **동일한 내용**으로 작업합니다.

### 📊 엑셀업로드

[📊 엑셀업로드] 버튼을 클릭하면 업로드 메뉴가 표시됩니다.

- 엑셀 파일로 **상품·수량 정보**를 일괄 등록합니다.

### 🔘 보조 기능

- [➕ 상품추가(F2)] : 폐기할 상품을 입력할 새 행을 만듭니다.
- [❌ 선택삭제(F4)] : 체크한 상품을 목록에서 지웁니다.
- [🔄 다시작성(F12)] : 입력 중인 내용을 초기화합니다.
- [🔄 매입(지정)단가 기준 판매가변경] : 판매가를 매입(지정)단가 기준으로 일괄 변경합니다.

💡 **사용유형** 선택은 필수입니다.
    💡 상품은 **여러 건을 동시에** 추가할 수 있습니다.
    💡 저장된 전표는 **폐기처리 조회** 메뉴에서 프로세스를 진행하며, **완료** 상태일 때 재고가 차감됩니다.

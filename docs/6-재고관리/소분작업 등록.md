# 소분작업 등록

**소분작업 등록**은 팩·박스 등 묶음 상품을 개봉하여 **별도로 등록된 작은 단위의 상품으로 소분**하고, 소분 후 수량과 원가를 등록하는 화면입니다.
    예) 볼펜 1PACK(12입) 1팩 → 볼펜 1EA **12개**

⚠️ 소분 후 상품은 원상품과 **다른 상품으로 등록**되어 있어야 합니다.
    필요한 경우 먼저 기초관리 > 🔗 **상품등록**에서 **볼펜 1EA** 상품을 등록합니다.

> 진행 순서 : **① 상품추가** → **② 상품수 입력** → **③ 소분상품추가** → **④ 수량 입력** → **⑤ 소분 출고 정보** → **⑥ 저장**

### 1. ➕ 상품추가

- [＋ 상품추가] 버튼을 클릭합니다.
- 상품 통합검색에서 **소분할 원상품**을 선택합니다.
&nbsp;&nbsp;⬇

- 선택한 상품이 상단 **소분할 상품정보**에 추가됩니다.
  - 예시) **볼펜(블랙) 1PACK(12입)** 선택

### 2. 📝 상품수 입력

- 소분에 사용할 원상품의 **상품수**를 입력합니다.
| 항목 | 설명 |
| --- | --- |
| 현재고 | 현재 보유 중인 원상품 재고 |
| 상품수 | 이번 소분에 사용할 원상품 수량 |
| 매입(지정)단가 | 원상품 1개당 매입단가 |
| 합계금액 | 소분에 사용되는 총 매입금액 |
**📌 화면 예시) 볼펜 1PACK(12입) **1팩**, 매입단가 **1,000원** → 1,000원 × 1팩 = **총 매입가 1,000원****

### 3. ➕ 소분상품추가

- [＋ 소분상품추가(F2)] 버튼을 클릭합니다.
- 소분 후 만들어질 **별도 상품**을 선택합니다.
&nbsp;&nbsp;⬇

- 선택한 상품이 하단 **소분된 상품정보**에 추가됩니다.
| 소분 전 | 소분 후 |
| --- | --- |
| 볼펜 1PACK(12입) | 볼펜 1EA |
| 1팩 | 12개 |
  - ⚠️ 실제 작업에서는 볼펜 1PACK(12입)과 볼펜 1EA를 **서로 다른 상품코드로 등록하여 사용합니다.**

### 4. 📝 수량 입력

- 소분 후 만들어지는 상품의 **수량**을 입력합니다.
  - 볼펜 1PACK에 12자루가 들어 있으므로 1PACK × 12자루 = 1EA 12개 → 소분된 상품의 **수량 = 12개**

📌 **소분원가 계산**
    원상품 1팩의 총 매입가 **1,000원**을 소분 후 만들어진 **12개에 나누어 반영**합니다.
    1,000원 ÷ 12개 = 약 83.33원 → **매입(소분반영)가 = 약 83.33원**

| 항목 | 계산 | 결과 |
| --- | --- | --- |
| 원상품 | 볼펜 1PACK(12입) | **1팩** |
| 원상품 총 매입가 | 1,000원 × 1팩 | **1,000원** |
| 소분상품 | 볼펜 1EA | **12개** |
| 매입(소분반영)가 | 1,000원 ÷ 12개 | **약 83.33원** |
| 매입합계 | 83.33원 × 12개 | **약 1,000원** |
**소분 전·후의 총 매입금액은 동일하며, 원상품의 총 원가가 소분된 수량에 맞게 나누어집니다.**

💡 **매입단가와 매입(소분반영)가 차이**

| 항목 | 의미 |
| --- | --- |
| **매입단가** | 소분상품에 기존 등록되어 있는 매입단가 |
| **매입(소분반영)가** | 이번 소분작업에서 원상품의 원가를 나누어 새로 계산한 단가 |
예를 들어 원상품 총 원가가 **1,000원**이고 12개로 소분하면 1,000 ÷ 12 = 약 83.33원 → 실제 소분 원가로 **83.33원**이 반영됩니다.

### 5. ⚙️ 소분 출고 정보

- **소분 매입가 반영기준** : 원상품의 **총 매입가를 소분상품에 어떤 기준으로 반영할지** 선택합니다.
| 반영기준 | 설명 |
| --- | --- |
| **소분수량** | 소분하여 생성되는 수량을 기준으로 반영 |
| **매입단가** | 소분상품의 매입단가를 기준으로 반영 |
| **판매단가** | 소분상품의 판매단가를 기준으로 반영 |
- 선택한 기준에 따라 **매입(소분반영)가**가 계산됩니다.
  - 💡 현재 예시처럼 **소분상품이 한 종류인 경우에는 총 매입가가 해당 상품에 모두 반영되므로 세 기준의 결과가 동일하게 나타날 수 있습니다.**
- **부서명 · 담당명**은 필수로 입력합니다.
  - 제조일 · 유효일 · 비고는 필요 시 입력합니다.

### 6. 💾 저장

- [💾 저장] 버튼을 클릭하면 소분작업 전표가 등록됩니다.
  - 저장 단계에서는 **재고가 바로 변경되지 않습니다.**
- 저장된 전표는 🔗 **소분작업 조회** 메뉴에서 확인합니다.
  - 재고 반영 절차 : **작업중 → 승인대기 → 소분완료** — 소분완료 상태가 되면 재고 수불이 발생합니다.
| 상품 | 재고 반영 |
| --- | --- |
| 볼펜 1PACK(12입) | **−1팩** |
| 볼펜 1EA | **+12개** |
- 즉, **묶음상품의 재고는 감소하고 소분된 상품의 재고는 증가**합니다.

💡 **주요 항목 한눈에 보기**

| 항목 | 의미 |
| --- | --- |
| **상품수** | 소분에 사용할 원상품 수량 |
| **수량** | 소분 후 생성되는 상품 수량 |
| **매입(지정)단가** | 원상품의 매입단가 |
| **매입(소분반영)가** | 소분 후 계산된 1개당 실제 원가 |
| **매입합계** | 소분상품에 반영된 총 원가 |
| **판매단가** | 소분상품에 등록된 판매가격 |
| **판매합계** | 판매단가 × 소분수량 |
| **이익율** | 판매금액 대비 예상 이익 비율 |
📌 **판매단가는 새로 등록한 소분상품의 판매단가가 적용됩니다.**
    현재 테스트 화면의 판매단가는 임시 상품정보를 사용한 값이므로 실제 볼펜 1EA 상품 등록 시 설정한 판매단가와 다를 수 있습니다.

✅ **핵심 예시**
    **소분 전** : 볼펜 1PACK(12입) 1팩 × 1,000원 = 총 원가 1,000원
    ⬇ **12개로 소분** ⬇
    **소분 후** : 볼펜 1EA 12개 × 약 83.33원 = 총 원가 약 1,000원
    
    **핵심** — 볼펜 1PACK(12입)과 볼펜 1EA는 **각각 별도 상품으로 등록**합니다.
    **1PACK 1팩 → 1EA 12개**로 변환되며, **원상품의 총 매입가는 그대로 유지한 채 소분된 수량에 맞춰 1개당 원가가 다시 계산됩니다.**

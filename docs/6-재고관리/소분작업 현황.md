# 소분작업 현황

**소분작업 현황**은 소분작업 내역을 **문서번호별**로 모아 확인하는 **조회 전용** 화면입니다.

### 1. 🔍 전체 목록 조회

- 통합검색 입력창의 [···] 버튼을 누르면 **전체 목록**이 목록에 표시됩니다.
  - [🔍 상세검색] 버튼을 눌러서 특정 조건을 적용해 검색할 수도 있습니다.

### 2. 🔎 목록 내 상세검색

- 검색어를 입력하고 [찾기] 를 누르면 목록에서 **특정 단어가 들어간 상품**을 찾을 수 있습니다.
  - 예) 헛개 — 검색어와 일치하는 부분이 노랗게 표시됩니다.

### 3. 📋 소분작업 현황 확인

- 문서번호별 **소분작업 내역과 처리 상태**를 확인합니다.
- 소분상품의 **수량·단가·총매입가**와 **상태·등록일·완료일**을 확인할 수 있습니다.

### 🔽 문서번호 필터

[문서번호] 버튼을 클릭하면 **디테일한 필터링**으로 원하는 현황만 볼 수 있습니다.

💡 소분작업 현황은 **조회 전용**(읽기 전용)으로, 전표를 처리하지 않습니다.

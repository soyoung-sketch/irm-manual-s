# 자가사용 조회

---

## 1 작성중

**자가사용**이란? — 매장 내에서 판매가 아닌, **매장을 위해 사용된 물품**입니다.

**자가사용 조회**는 자가사용 등록에서 작성한 전표를 조회하고 **승인 절차**를 단계별로 처리하는 화면입니다. 전표가 **완료** 상태가 되어야 **재고가 차감**됩니다.

> 처리 흐름 : **작성중** → **승인대기** → **완료**(재고 차감) &nbsp;·&nbsp; 중간에 취소하거나 반려할 수 있습니다.

### 1. 🔍 전표 찾기

- 자가사용 등록에서 저장한 전표가 **작성중** 탭에 표시됩니다.
- 통합검색에 검색어를 입력하거나 [🔍 상세검색] 버튼으로 조건 입력창을 엽니다.
&nbsp;&nbsp;⬇

- 사업장·부서명·담당자·사용일·상품분류 등 조건을 입력하고 [🔍 검색] 버튼을 누릅니다.
&nbsp;&nbsp;⬇

- 조건에 맞는 전표가 목록에 표시됩니다.

### 2. 📋 전표 확인

- 조회된 전표의 **문서번호·사용일·사업장·담당자·처리사유·금액**을 확인합니다.

### 3. ✅ 승인요청

전표를 확인한 후 [▶ 승인요청] 버튼을 누르면 🔗 **승인대기** 탭으로 이동합니다.

- 승인대기 탭에서 **완료** 처리해야 재고가 차감됩니다.

### 📥 완료

승인 없이 완료할 수 있는 경우 [📥 완료] 버튼을 누르면 바로 완료됩니다.

- 완료된 전표는 🔗 **완료** 탭에서 확인합니다.

### 📊 합계 확인

- 화면 하단에서 조회된 전표의 **건수**와 **금액 합계**를 확인합니다.

### 보조 기능

- [✏️ 수정] : 🔗 **수정** 화면에서 상품·수량을 변경합니다.
- [✖ 취소] : 전표를 취소하면 🔗 **취소** 탭으로 이동합니다.
- [🔄 사유변경] : 전표의 처리사유를 변경합니다.
- [🖨 인쇄] : 선택한 전표를 출력합니다.

---

## 취소

**취소** 탭에는 처리를 **취소한** 전표가 모입니다. 재고에 영향을 주지 않습니다.

### 1. 📋 취소 전표 확인

- 취소된 전표의 **문서번호·사용일·사업장·담당자·처리사유** 등을 확인합니다.

### 문서 처리

- [🖨 인쇄] : 선택한 전표를 출력합니다.
- [🔄 사유변경] : 전표의 처리사유를 변경합니다.

---

## 반려

**반려** 탭에는 승인 과정에서 **반려된** 전표가 모입니다. 보완이 필요한 경우입니다.

### 1. 📋 반려 전표 확인

- 반려된 전표의 **문서번호·사용일·사업장·담당자·처리사유** 등을 확인합니다.

### 문서 처리

- [✏️ 수정] : 문서를 수정합니다.
- [✖ 취소] : 전표를 취소하면 🔗 **취소** 탭으로 이동합니다.
- [🔄 사유변경] : 전표의 처리사유를 변경합니다.
- [🖨 인쇄] : 선택한 전표를 출력합니다.

---

## 2 승인대기

**승인대기** 탭에는 승인요청되어 **완료 처리를 기다리는** 전표가 모입니다.

### 1. 📋 승인대기 전표 확인

- 승인 대기 중인 전표의 **문서번호·사용일·사업장·담당자·처리사유** 등을 확인합니다.

### 2. ✅ 완료 처리

[📥 완료] 버튼을 누르면 자가사용이 확정되고 🔗 **완료** 탭으로 이동합니다.

- 완료 상태가 되면 해당 상품의 **재고가 차감**됩니다.

### ↩ 반려

보완이 필요한 전표는 [↩ 반려] 버튼으로 🔗 **반려** 탭으로 보냅니다.

### 문서 처리

- [◀ 작성중] : 전표를 🔗 **작성중** 단계로 되돌립니다.
- [✏️ 수정] : 🔗 **수정** 화면에서 상품·수량을 변경합니다.
- [✖ 취소] : 전표를 취소하면 🔗 **취소** 탭으로 이동합니다.
- [🔄 사유변경] : 전표의 처리사유를 변경합니다.
- [🖨 인쇄] : 선택한 전표를 출력합니다.

---

## 3 완료

**완료** 탭에는 승인이 완료되어 **재고 차감이 발생**한 전표가 모입니다. (최종 상태)

### 1. 📋 완료 전표 확인

- 완료된 전표의 **문서번호·사용일·사업장·담당자·처리사유** 등을 확인합니다.

### 문서 처리

- [🖨 인쇄] : 선택한 전표를 출력합니다.
- [🔄 사유변경] : 전표의 처리사유를 변경합니다. (완료 상태에서도 가능)

---

## 수정

**자가사용 수정**은 선택한 전표를 **수정**하는 화면입니다. 자가사용 등록과 동일한 화면이며 **수정** 모드로 열립니다.

### 1. 📝 문서 정보 수정

- **사용일·사용사업장·부서명·담당자·사용유형·비고** 등 문서 정보를 수정합니다.

### 2. ✔️ 상품 · 수량 수정

- 목록에서 상품의 **매입(지정)단가·수량**을 수정합니다.
  - [상품추가] 로 상품을 더하거나 [선택삭제] 로 뺄 수 있습니다.

### 3. 💾 문서수정

- 수정이 끝나면 [💾 문서수정] 버튼을 눌러 변경 내용을 저장합니다.
- 저장된 전표는 🔗 **작성중** 탭에서 확인합니다.

# 재고조정 현황

**재고조정 현황**은 상품별 **재고조정(+/-) 내역**을 조회하는 화면입니다.

### 1. 🔍 전체 목록 조회

- 통합검색 입력창의 [···] 버튼을 누르면 **전체 목록**이 목록에 표시됩니다.
  - [🔍 상세검색] 버튼을 눌러서 특정 조건을 적용해 검색할 수도 있습니다.

### 2. 🔎 목록 내 상세검색

- 검색어를 입력하고 [찾기] 를 누르면 목록에서 **특정 단어가 들어간 상품**을 찾을 수 있습니다.

### 3. 📋 재고조정 현황 확인

- 상품별 **재고조정(+) · 재고조정(−) · 재고금액**을 확인합니다.
  - 상품정보(사업장명·상품코드·상품명·분류·매입처·과세구분·단위·매입단가)와 함께 표시됩니다.

💡 재고조정 현황은 **조회 전용**(읽기 전용)으로, 조정 문서를 처리하지 않습니다.

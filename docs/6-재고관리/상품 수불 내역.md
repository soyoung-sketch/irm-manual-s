# 상품 수불 내역

특정 상품의 **입·출고 수불 내역**과 재고 변동을 기간별로 조회하는 화면입니다.

💡 재고관리 리본에서 바로 열거나, **사업장 상품관리**에서 상품을 선택한 후 [재고수불내역] 버튼으로 열 수 있습니다.

### 1. 🔍 조회 조건 지정

조회할 상품과 기간을 지정합니다.

- **시작일·종료일** 을 지정해 조회할 기간을 정합니다.
&nbsp;&nbsp;⬇

- [···] 버튼으로 상품 통합검색창을 열어 조회할 **상품명**을 정할 수 있습니다.
&nbsp;&nbsp;⬇

- [🔍 검색] 버튼을 클릭하면 지정한 조건으로 수불 내역이 조회됩니다.

### 2. 📋 수불 내역 확인

조회된 거래를 위에서부터 훑으며 재고 변동을 추적합니다.

**📌 거래정보 · 사업장정보 · 업체정보**

- 재고가 움직인 **거래일·전표번호**와 **구분**을 보고 어떤 거래였는지 확인합니다.
- 재고가 오간 **입고사업장·출고사업장**과 거래 상대인 **매입처명·매출처명**을 확인합니다.
**📌 기초재고 · 재고정보(+ , -)**

- 거래가 반영되기 전 수량인 **이전재고**에서 시작해 재고 변화를 따라갑니다.
- 파란색 **입고정보(+)**에서 늘어난 수량을, 빨간색 **출고정보(-)**에서 줄어든 수량을 확인합니다.

### 📊 합계 확인

- 화면 하단에서 조회된 **건수**와 입·출고 항목별 **수량 합계**를 확인합니다.

### ⚙️ 옵션

[⚙ 옵션] 버튼을 클릭하면 메뉴가 표시됩니다.

- **문서저장** : 조회된 내역을 **엑셀 · 워드 · PDF** 형식으로 저장합니다.
- **도움말** : 화면 사용 안내를 확인합니다.

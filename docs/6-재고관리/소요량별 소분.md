# 소요량별 소분

**소요량별 소분**은 기준(생산) 상품에 들어가는 **소요 재료(소요량)**를 등록해 두고, 생산 수량에 따라 재료 소요량을 **자동 계산**하여 소분작업을 등록하는 화면입니다.

> 진행 순서 : **① 상품추가** → **② 소요량 등록** → **③ 기준 상품 추가** → **④ 수량 입력** → **⑤ 작업완료**

### 1. ➕ 상품추가

- [＋ 상품추가] 버튼으로 **기준(생산) 상품**을 추가합니다.
  - 구분에서 **일반(소분용) · 세트(판매용)** 를 선택할 수 있습니다.

### 2. 🧾 소요량 등록

- 기준 상품 행을 선택하면 우측 **소요량 정보**에 해당 상품의 소요 재료가 표시됩니다.
- 우측 [＋ 상품추가] 로 재료를 추가하고 **수량**(기준 상품 1개당 소요량)을 입력합니다.

### 3. ⬇️ 기준 상품 추가

- 기준 상품을 선택한 후 [⬇ 기준 상품 추가] 버튼을 클릭합니다.
&nbsp;&nbsp;⬇

- 선택한 상품이 하단 **생산 정보**에 추가됩니다.

### 4. 📝 수량 입력

- 생산 상품 정보에서 **소요량·생산 수량**을 입력합니다.
&nbsp;&nbsp;⬇

- 생산 수량에 따라 우측 **소요량 확인**의 생산 소요량과 남은재고가 자동 계산됩니다.

### 5. ✅ 작업완료

- 수량과 소요량을 확인한 후 [＋ 작업완료] 버튼을 클릭합니다.
- 완료한 작업은 🔗 **소분작업 조회** > **작업중**에서 확인할 수 있으며, 이후 승인 및 소분완료 절차를 진행합니다.
  - 작업중 → 승인대기 → 소분완료

# 재고실사 현황

**재고실사 현황**은 재고실사로 발생한 **재고 조정 내역**을 조회하는 화면입니다.

> 전산 재고수와 실사 재고수를 비교한 **조정 결과**를 확인할 수 있습니다.

### 1. 🔍 상세검색

- [🔍 상세검색] 버튼을 누르면 검색 조건 영역이 열립니다.
&nbsp;&nbsp;⬇

- **부서명·담당자·등록일** 등 원하는 조건을 설정합니다.

### 2. 🔍 검색

- [🔍 검색] 버튼을 누르면 조건에 맞는 실사 현황이 조회됩니다.

### 3. 📋 실사 현황 확인

- **전산 재고수 · 실사 재고수 · 조정수량** 을 확인합니다.

### 🧩 필드 드래그 (집계 기준 구성)

- **규격·단위·등록일·전산재고수·실사재고수·조정수량** 필드 칩을 **Drop Column Fields Here** 영역으로 드래그하면 원하는 기준으로 집계됩니다.
  - 반대로 열을 밖으로 빼면 해당 기준이 사라집니다.

💡 재고실사 현황은 **조회 전용**(읽기 전용)으로, 실사 문서를 처리하지 않습니다.

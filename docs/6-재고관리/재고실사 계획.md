# 재고실사 계획

---

## 전체상품 실사

**재고실사 계획**은 전산 재고와 실제 재고를 맞추기 위한 **재고 실사 문서**를 등록하는 화면입니다.

**전체상품 실사** 탭에서는 전체 상품을 대상으로 실사하기 전에 **업무별 문서 마감 상태**를 확인합니다.

> 진행 순서 : **① 기본 정보 입력** → **② 상태체크(마감 상태 확인)** → **③ 선택상품 실사**

### 1. 📝 기본 정보 입력

- 정보를 입력해주세요.
  - 필수항목 (**제목 · 조정일 · 작성일**) 을 입력하지 않으면 진행이 되지 않습니다.

### 2. ✔️ 상태체크 (마감 상태 확인)

- [✔ 진행중 정보 상태체크(F2)] 버튼을 클릭합니다.
&nbsp;&nbsp;⬇

- 문서의 현재상태가 표시됩니다.
- 진행 중인 문서가 있으면 해당 업무를 **마감(완료) 처리한 후** 실사를 진행합니다.

### 3. 🛍️ 선택상품 실사 탭으로 이동

- 마감 상태 확인이 끝나면 🔗 **선택상품 실사** 탭으로 이동해 실사할 상품을 추가합니다.

---

## 선택상품 실사

**선택상품 실사** 탭에서는 실사할 **상품을 직접 선택**하여 재고실사 문서를 등록합니다.

> 진행 순서 : **① 상품추가** → **② 목록 확인** → **③ 신규등록**

### 1. ➕ 상품추가

- [＋ 상품추가(F2)] 버튼을 클릭하면 **상품 통합검색** 창이 열립니다.
&nbsp;&nbsp;⬇

- 실사할 상품을 검색·체크한 후 [✔ 선택] 버튼을 클릭하면 목록에 추가됩니다.

### 2. 📋 목록 확인

- 실사할 상품의 **상품코드 · 상품명 · 현재고수 · 매입처**를 확인합니다.
  - [선택삭제(F4)] 로 빼거나 [다시작성(F12)] 으로 초기화할 수 있습니다.

### 3. 💾 신규등록

- [💾 신규등록] 버튼을 클릭하면 재고실사 문서가 저장됩니다.
- 저장된 문서는 🔗 **재고실사 조회** 메뉴에서 실사를 진행합니다.

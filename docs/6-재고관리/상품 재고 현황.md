# 상품 재고 현황

**상품 재고 현황**은 **사업장·조건별**로 상품 재고 현황을 조회하는 화면입니다.

### 1. 🔍 검색 조건 설정

- 조회할 **분류 · 원산지 · 확정일 · 상품상태** 등 검색 조건을 설정 후 [🔍 검색] 버튼을 눌러 특정 현황을 조회합니다.
  - 조건을 선택하지 않고 검색 버튼을 누르면 **전체 현황**이 조회됩니다.

### 2. 🔍 검색 항목 선택 · 검색

- 드롭다운에서 **검색 항목**을 선택합니다.
  - 상품코드 · 바코드 · 상품명 · 매입처코드 · 매입처명 · 위치정보 중 선택
- 아래 입력칸에 **검색어**를 입력하고 [🔍 검색] 을 누릅니다.
  - 예) 상품코드 → 10102 · 상품명 → 개미박사
&nbsp;&nbsp;⬇

- 조건에 맞는 **상품 재고 현황**이 조회됩니다.

### 3. ✔️ 매입처 선택

- 검색한 **매입처**가 표시됩니다.
  - 하단 **[매입처코드] 필터** : 매입처가 여러 개일 경우 **더블클릭** 시 해당 매입처코드만 필터링되어 보입니다.
  - ✕ 를 누르면 해제됩니다.

### 4. 📊 재고 현황 확인

- 상품별 **기초재고 · 입고정보(+) · 출고정보(-) · 현재고**를 확인합니다.
  - 매입 · 판매반품 · 소분입고 · 자가취소 · 폐기취소 · 재고조정 · 판매 열이 표시됩니다.

### 🔗 재고조정 등록

[재고조정] 버튼을 누르면 **재고조정 등록** 화면으로 이동합니다.

- 🔗 **재고조정 등록** 페이지 바로가기

### 🔧 필터 편집

[필터 편집] 을 클릭하면 **필터 편집기** 창이 열립니다.

- 1 **값 설정** : 필터링할 값을 설정합니다.
- 2 **확인** : 적용되고 목록으로 돌아갑니다.
- 3 **취소** : 취소되고 창이 닫힙니다.
- 4 **적용** : 팝업창이 열린 채로 적용된 목록을 볼 수 있습니다.

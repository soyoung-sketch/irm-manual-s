# 재고조정 등록

**재고조정 등록**은 전산 재고와 실제 재고의 차이를 **조정**하여 등록하는 화면입니다.

> 진행 순서 : **① 기본 정보 입력** → **② 상품추가** → **③ 상품 선택** → **④ 실사 재고 입력** → **⑤ 신규등록**

### 1. 📝 기본 정보 입력

- 등록에 필요한 **정보**를 입력해주세요.
- **필수항목** 입력해야 진행됩니다.

### 2. ➕ 상품추가

- [＋ 상품추가(F2)] 버튼을 클릭시 **상품입력 행**이 추가됩니다.

### 3. 🔍 상품 선택

- 상품코드의 [···] 버튼을 클릭하면 **상품 통합검색**창이 열립니다.
&nbsp;&nbsp;⬇

- 조정할 상품을 **목록에 추가**해주세요.

### 4. 📝 실사 재고 입력

- **실사 재고**칸에 실제 조사한 재고수를 입력합니다.
&nbsp;&nbsp;⬇

- 현재 재고와의 차이에 따라 **조정재고수와 금액**이 자동입력됩니다.
- **실사재고가 현재고 보다 많을때** : [+] 조정재고칸에 표시
- **실사재고가 현재고 보다 적을때** : [−] 조정재고칸에 표시

💡 **조정재고 계산**
    · 조정재고 재고수 = 현재재고 − 실사재고
    · 조정금액 = 조정재고수 × 단가
    · 재고금액 = 실사재고 × 단가

### 5. 💾 신규등록

- 입력이 끝나면 [💾 신규등록] 버튼을 눌러 문서를 저장합니다.
- 저장된 문서는 🔗 **재고조정 조회** 메뉴에서 프로세스를 진행합니다.

### 🔎 실사정보검색

- [실사정보검색] 버튼으로 실사 문서를 검색해 **실사 정보**를 불러올 수 있습니다.

### 📊 엑셀업로드

[📊 엑셀업로드] 버튼을 클릭하면 업로드 메뉴가 표시됩니다.

- 엑셀 파일로 **상품·재고 정보**를 일괄 등록합니다.

### 보조 기능

- [✕ 선택삭제(F4)] : 체크한 상품 행을 삭제합니다.
- [🔄 다시작성(F12)] : 입력 내용을 초기화합니다.
- [✔ 동일재고 삭제] : 전산 재고와 실사 재고가 같은 행을 삭제합니다.

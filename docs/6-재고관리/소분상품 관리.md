# 소분상품 관리

**소분상품 관리**는 기준 상품과 소분 후 상품을 연결하여 **기준 수량을 설정**하고, 실제 작업 시 **수량·단가를 조정하여 소분작업을 등록**하는 화면입니다.
    예) 기준상품 1개 → 소분상품 **12개**

> 진행 순서 : **① 상품추가** → **② 소분상품·수량 설정** → **③ 소분 상품 추가** → **④ 수량·단가 확인/수정** → **⑤ 작업완료**

### 1. ➕ 상품추가

- [＋ 상품추가] 버튼을 클릭하여 소분할 **기준 상품**을 추가합니다.
| 항목 | 설명 |
| --- | --- |
| 상품코드 / 상품명 | 소분할 기준 상품 |
| 단가 | 기준 상품의 단가 |
| 수량 | 소분에 사용할 기준 수량 |
| 현재고수 | 현재 보유 재고 |

### 2. 🔄 소분상품·수량 설정

- 상품코드의 [···] 버튼을 클릭해 **상품 통합검색** 창에서 소분 후 만들어질 상품을 지정하고, **수량**을 입력합니다.
| 기준 상품 | 수량 | → | 소분상품 | 수량 |
| --- | --- | --- | --- | --- |
| 기준 상품 | 1개 | → | 소분 후 상품 | **12개** |
  - 즉, 기준 상품 1개를 소분하여 **소분상품 12개**로 만드는 기준을 설정합니다.

### 3. ⬇️ 소분 상품 추가

- 상단에서 설정한 상품을 선택한 후 [⬇ 소분 상품 추가] 버튼을 클릭합니다.
&nbsp;&nbsp;⬇

- 설정한 내용이 하단 **상품별 소분** 영역에 추가됩니다.

### 4. 📝 수량·단가 확인 및 수정

- 하단에서는 실제 작업에 사용할 기준 상품의 **수량·단가**와 소분상품의 **생산수량**을 확인하고 필요 시 수정합니다.
- 기준상품 수량을 바꾸면 **소분상품 수량도 비율에 맞게 함께 변경**됩니다.
| 구분 | 확인/설정 내용 |
| --- | --- |
| 기준 상품정보 | 단가 · 수량 · 현재고수 |
| 소분(생산) 상품정보 | 소분상품 · 생산수량 · 현재고수 |
| 추가정보 | 제조일 · 유효일 · 로트번호 · 비고 |
  - 💡 상단에서는 기본적인 상품 연결과 수량 기준을 설정하고, 하단에서는 실제 작업에 맞게 수량과 단가를 조정할 수 있습니다.

### 5. ✅ 작업완료

- 수량과 단가를 확인한 후 [＋ 작업완료] 버튼을 클릭합니다.
- 완료한 작업은 🔗 **소분작업 조회** > **작업중**에서 확인할 수 있으며, 이후 승인 및 소분완료 절차를 진행합니다.
  - 작업중 → 승인대기 → 소분완료

💡 **화면 구조 한눈에 보기**

| 영역 | 역할 |
| --- | --- |
| **상단** | 기준상품 ↔ 소분상품 연결 및 기준 수량 설정 |
| **하단** | 실제 소분작업의 수량·단가 조정 및 작업완료 |
**핵심** — 소분상품 관리 = 상품을 연결해 **수량 기준**을 정한 뒤, 실제 작업 시 **수량과 단가까지 조정**할 수 있는 소분 방식

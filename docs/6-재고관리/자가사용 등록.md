# 자가사용 등록

매장에서 **자가 사용**한 상품을 등록하여 재고에 반영하는 화면입니다.

> 진행 순서 : **기본 정보 입력** → **상품추가** → **상품 선택·단가·수량 입력** → **신규등록**

### 1. 📝 기본 정보 입력

- 사용사업장·사용유형·사용일·부서명·담당자를 입력해 전표의 기본 정보를 채워주세요. (필수)

### 2. ➕ 상품추가

- [➕ 상품추가(F2)] 버튼을 클릭하면 상품 목록에 신규 라인이 생성됩니다.
- 💡 상품은 여러 건을 동시에 추가할 수 있습니다.

### 3. ✔️ 상품 선택 · 단가·수량 입력

- 생성된 행의 상품코드 [···] 버튼을 클릭하면 **상품 통합검색** 창이 열립니다.
- 상품을 고른 뒤 [✔ 선택] 버튼을 클릭하면 자가사용 목록에 추가됩니다.

- 추가된 상품의 **매입(지정)단가**와 **수량**을 입력해주세요.
- 입력한 단가와 수량을 기준으로 공급가·부가세·합계금액이 자동 계산됩니다.

### 4. 💾 신규등록

- 자가사용 상품과 수량을 모두 확인해주세요.
- [💾 신규등록(F5)] 버튼을 클릭하면 자가사용 전표가 저장됩니다.

💡 사용유형 선택은 필수입니다.
    💡 [📄 문서불러오기]로 기존 전표를, [📊 엑셀업로드]로 상품 정보를 일괄 등록할 수 있습니다.
    💡 저장된 전표는 **자가사용 조회** 메뉴에서 프로세스를 진행할 수 있으며, **완료** 상태일 때 재고 수불이 발생합니다.

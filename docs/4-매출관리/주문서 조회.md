# 주문서 조회

---

## 주문서입력

주문 등록에서 등록한 주문서를 **확인부터 주문서완료까지** 단계별로 처리하는 화면입니다. 상단 9개 탭이 주문서의 **처리 상태**를 나눕니다.

📌 처리 흐름 : **주문서입력 → 출고(매입)계획 → 포장중 → 출고대기중 → 출고완료(배송) → 주문서완료**

### 1. 🔍 주문서 확인

주문 등록에서 등록한 주문서가 **주문서입력** 탭에 올라옵니다.

- 우측 상단 **통합검색**으로 문서번호·매출처 등 특정 주문서를 찾습니다.
- 처리할 주문서를 **☑ 체크**해 선택합니다.

### 2. 🚚 계획으로이동

확인이 끝나면 [계획으로이동]으로 다음 단계로 보냅니다.

- 주문서가 **출고(매입)계획** 탭으로 이동합니다.
**📌 수정 · 취소**

- [수정]으로 주문서를 고치고, 쓰지 않을 주문서는 [취소]합니다.
**📌 반려(점검)**

- 점검이 필요하면 [반려(점검)]로 보냅니다.
**📌 인쇄**

- [인쇄 ▾]에서 기본인쇄·동선기준인쇄·거래명세서 등 **양식**을 골라 인쇄합니다.

### 📋 주문내역보기

주문서의 **처리이력·상품내역**을 우측 패널에서 바로 확인합니다.

- [주문내역보기]를 누르면 처리이력·상품내역 패널이 열립니다.
- [주문내역닫기]로 패널을 닫습니다.

---

## 취소

**취소**한 주문서를 모아 보는 탭입니다.

### 1. 📋 취소 주문서 확인

취소한 주문서 목록에서 내용을 확인합니다.

- 이 탭에서는 [수정] · [취소] 버튼을 사용할 수 없습니다.

---

## 반려(점검)

**반려(점검)**한 주문서가 모이는 탭입니다.

### 1. 📋 반려 주문서 확인

반려(점검)한 주문서 목록에서 내용을 확인합니다.

### 2. ↩️ 주문서입력으로 복구

점검이 끝나면 [주문서입력] 버튼으로 되돌립니다.

- 주문서가 **주문서입력** 탭으로 복구됩니다.
- 필요하면 [수정]으로 내용을 고치거나 [취소]합니다.

---

## 출고(매입)계획

출고(매입)계획 단계 주문서입니다 · 작업그룹을 짜고 **포장을 시작**합니다.

### 1. 📋 주문서 확인

출고(매입)계획 단계 주문서 목록에서 내용을 확인합니다.

### 2. 📦 포장시작

준비가 끝나면 [포장시작]으로 다음 단계로 보냅니다.

- 주문서가 **포장중** 탭으로 이동합니다.
- 필요하면 [반려(점검)]로 보내거나 [수정] · [취소]합니다.

### ⚙️ 작업관리

작업그룹·API 주문수집 등 **출고 준비 도구**를 제공합니다.

- [작업관리 ▾]에서 작업그룹 만들기/보기/닫기, API 주문수집, 오픈마켓 주문등록, 인쇄출력체크를 실행합니다.

---

## 포장중

**포장중** 단계 주문서입니다 · 포장이 끝나면 출고대기로 넘깁니다.

### 1. 📋 주문서 확인

포장중 단계 주문서 목록에서 내용을 확인합니다.

### 2. 📮 출고대기중

포장이 끝나면 [출고대기중]으로 넘깁니다.

- 주문서가 **출고대기중** 탭으로 이동합니다.
- 작업관리·인쇄로 포장 작업을 보조합니다.

---

## 출고대기중

**출고대기중** 단계 주문서입니다 · 배송을 시작하면 출고완료로 넘어갑니다.

### 1. 📋 주문서 확인

출고대기중 단계 주문서 목록에서 내용을 확인합니다.

### 2. 🚛 배송시작

출고 준비가 끝나면 [배송시작]으로 넘깁니다.

- 주문서가 **출고완료(배송)** 탭으로 이동합니다.
- 작업관리·인쇄로 출고 작업을 보조합니다.

---

## 출고완료(배송)

**출고완료(배송)** 단계 주문서입니다 · 배송이 끝나면 주문서를 완료합니다.

### 1. 📋 주문서 확인

출고완료(배송) 단계 주문서 목록에서 내용을 확인합니다.

### 2. ✅ 주문서완료

배송이 끝나면 [주문서완료]로 마무리합니다.

- 주문서가 **주문서완료** 탭으로 이동합니다.
- 작업관리·인쇄로 배송 관련 작업을 보조합니다.

---

## 주문서완료

주문서완료 탭으로 오면 **주문 처리가 끝난** 것입니다.

### 1. 📋 완료 주문서 확인

처리가 끝난 주문서를 모아 보며 내용을 확인·인쇄합니다.

- 이 탭에서는 [수정] · [취소] 버튼을 사용할 수 없습니다.

---

## 전체(진행중)

진행 중인 **모든 단계의 주문서**를 한 화면에서 확인하는 탭입니다.

### 1. 📋 진행중 주문서 확인

주문서입력부터 출고완료까지 **진행 중**인 주문서를 모아 봅니다.

- 이 탭에서는 [수정] · [취소] 버튼을 사용할 수 없습니다.

---

## 수정

주문서 내용을 **고치는 수정 화면**입니다. 주문서 조회의 [수정] 버튼으로 들어옵니다.

### 1. ✏️ 전표 수정

전표를 수정하고 **문서수정** 버튼을 눌러주세요.

### 2. 💾 문서수정(F5)

내용을 고친 뒤 [문서수정(F5)] 버튼을 누르면 저장하고 **이전 화면**으로 돌아갑니다.

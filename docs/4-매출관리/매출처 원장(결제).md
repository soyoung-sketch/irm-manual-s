# 매출처 원장(결제)

---

## 매출처 원장(결제)

특정 **매출처의 매출·수금·미수금 원장(결제 기준)**을 조회하는 화면입니다.

### 1. 🏢 매출처 선택

**···** 버튼으로 매출처 목록을 열어 조회할 매출처를 지정합니다.

### 2. 📅 조회 기간 지정

조회할 **시작일~종료일**을 지정합니다.

### 3. 🔍 검색

[검색] 버튼으로 원장 내역을 조회합니다.

### 4. 📋 원장 확인

날짜·문서번호·매출합계·수금합계·**미수금액** 등을 확인합니다.

### 🟨 이어서 처리

- [적립금 사용현황] · 매출처의 **적립금 상세정보** 화면으로 이동합니다.
- [미수금 입금 입력] · **미수금입금** 화면으로 이동해 수금을 등록합니다.

---

## 적립금 사용현황

매출처의 **적립금 적립·차감 상세**를 확인하고 적립금을 등록하는 화면입니다.

### 1. ✍️ 적립금 정보 입력

우측 **적립금 지급관리** 패널에서 사유·구분·결제구분·충전금액을 입력합니다.

### 2. ➕ 적립금 적립

[적립금 적립] 버튼으로 적립 내역을 등록합니다.

### 3. 📋 적립/차감 내역 확인

왼쪽 목록에서 **충전·사용·잔여 적립금** 내역을 확인합니다.

### 🟨 엑셀저장

[엑셀저장] 버튼으로 적립금 내역을 엑셀 파일로 저장합니다.

---

## 미수금입금

매출처 원장에서 **미수금 입금 입력**으로 들어오는 화면입니다. 미수금 건에 수금을 등록합니다.

### 1. 💰 수금 정보 입력·등록

우측에서 **결제구분·수금금액**을 입력한 뒤 [수금입력] 버튼으로 등록합니다.

### 2. 📋 수금 대상 확인

왼쪽 목록에서 수금할 **미수금** 내역을 확인합니다.

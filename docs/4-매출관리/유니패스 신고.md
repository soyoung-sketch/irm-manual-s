# 유니패스 신고

유니패스 **수입신고 자료**를 만들어 신고하는 화면입니다 · **①상품 지정 → ②기간 → ③출고정보검색 → ④신고** 순서로 진행합니다.

### 1. 🛒 신고할 상품정보

신고할 상품을 먼저 지정합니다.

- [＋추가]로 상품을 담고 [✕삭제]로 뺍니다 · [새로고침]으로 목록을 갱신합니다.
- 검색어를 입력하고 [찾기]로 담을 상품을 빠르게 찾습니다.

### 2. 📅 매출검색 기간

**매출 시작일·종료일**로 조회할 기간을 지정합니다.

### 3. 🔍 출고정보검색

[출고정보검색]을 클릭하면 **신고 대상**이 좌측 목록에 출력됩니다.

### 4. ✈️ 유니패스 신고

**부서명·담당자**를 확인한 뒤 [유니패스신고] 버튼으로 수입신고 자료를 전송합니다.

### 🩺 휴/폐업체크

신고 대상의 사업자 상태를 확인합니다.

- [휴/폐업체크] 버튼을 클릭하면 신고 대상의 **휴·폐업 상태**가 목록의 **휴/폐업상태** 란에 표시됩니다.

**옵션**으로 화면 표시·저장 설정을 조정하고, 상품정보의 **검색어**로 담을 상품을 빠르게 찾을 수 있습니다.

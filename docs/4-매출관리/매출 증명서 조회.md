# 매출 증명서 조회

---

## 발행대기

매출 증명서 **발급을 대기** 중인 건을 확인하고 발급완료까지 처리하는 화면입니다. 상단 탭이 증명서의 **발행 상태**를 나눕니다.

### 1. 🔍 검색 조건 지정

**매출처·결제구분·부서명·담당자·발급일**로 조건을 지정합니다.

- 매출처 칸의 [···] 버튼을 클릭하면 **매출처 목록** 창이 열립니다.

### 2. 🔍 검색

조건을 지정하고 [검색] 버튼으로 조회합니다.

### 3. 📋 발급 대기 건 확인

발급 대기 중인 증명서 목록을 확인합니다.

### 4. ✅ 발급완료

확인이 끝나면 [발급완료] 버튼으로 **발급 전송** 창을 엽니다.

- [전송]·[확정]으로 증명서를 발급·전송합니다.
- 발급 **전송·확정된 전표**는 **발행완료** 탭으로 이동합니다.
**📌 발급취소**

- 발급하지 않을 건은 [발급취소]합니다(발행취소 탭으로 이동).

---

## 발행취소

**발급취소**된 매출 증명서를 모아 보는 탭입니다.

### 1. 📋 발행취소 증명서 확인

발급취소한 증명서 목록에서 내용을 확인합니다.

- 이 탭에서는 [발급취소] 버튼을 사용할 수 없습니다.

---

## 발행완료

매출 증명서 **발급이 완료**된 건을 모아 보는 탭입니다.

### 1. 📋 발행완료 증명서 확인

발급 완료된 증명서를 모아 보며 **인쇄** 열로 건별 인쇄합니다.

- 필요하면 [발급취소] 버튼으로 발급을 취소할 수 있습니다.

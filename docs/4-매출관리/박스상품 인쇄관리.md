# 박스상품 인쇄관리

주문서 **박스 인쇄**에 사용할 상품을 관리하는 화면입니다.

### 1. ➕ 상품 추가

박스 인쇄에 쓸 상품을 목록에 추가합니다.

- [＋상품추가] 버튼을 클릭하면 **상품 통합검색창**이 열립니다.
- ⬇ 통합검색창에서 박스 인쇄에 사용할 상품을 선택합니다.

### 2. 📋 목록 확인

등록된 **박스 인쇄 상품**을 목록에서 확인합니다.

- 상품별 **내품수**(박스에 담긴 낱개 수량)와 작성자·작성일을 확인합니다.
**📌 선택삭제**

- 필요 없는 상품은 체크한 뒤 [✕ 선택삭제]로 목록에서 지웁니다.

# 견적서 등록

매출처에 보낼 **견적서**를 작성해 등록하는 화면입니다.

### 1. 🏢 매출처 선택

견적을 보낼 매출처를 먼저 지정합니다.

- 매출처 칸의 [···] 버튼을 클릭하면 **매출처 목록** 창이 열립니다.
- 단일 선택은 **더블클릭**, 여러 개는 **멀티선택모드**를 켠 뒤 선택합니다.
  - 매출처를 선택하면 **우편번호·주소**가 자동으로 입력됩니다.

### 2. 📝 견적 정보 확인

- **주문예정일·부서명·작성일·담당자**를 확인·선택합니다 (모두 필수 항목).
  - 견적유효일은 기본 **견적 후 15일**로 안내됩니다.

### 3. 🛒 견적할 상품 추가

세 가지 방법으로 상품을 담을 수 있습니다.

**📌 직접 추가**

- [+ 상품추가(F2)]로 행을 만들고(첫 줄은 미리 생성) 상품코드의 [···] 버튼을 클릭합니다.
- ⬇ **상품 통합검색창**에서 견적할 상품을 선택합니다.
- ⬇ **판매단가**를 확인하고 **수량**을 입력하면 공급가·부가세·합계금액이 자동 계산됩니다.
**📌 문서불러오기**

- [문서불러오기]로 다른 카테고리의 주문서 정보를 불러옵니다.
**📌 엑셀업로드**

- [엑셀업로드]로 지정 탬플릿 엑셀을 이용해 여러 상품을 한꺼번에 등록합니다.

### 4. 🧮 수량 입력·금액 계산

첫 행은 미리 생성돼 있으며, 상품과 **수량**을 입력하면 공급가·부가세·합계금액이 자동 계산됩니다.

### 5. 💾 견적서 등록

- 매출처·상품과 필수 정보를 모두 입력했다면 [신규등록(F5)] 버튼으로 견적서를 등록합니다.
  - [매입(지정)단가 기준 판매가변경]으로 담긴 상품의 판매가를 일괄 변경할 수 있습니다.

### 📝 관리자 메모

이 견적 건에 대한 코멘트를 남길 수 있습니다.

- **노란색**으로 표시한 메모영역의 입력칸에 메모를 입력합니다.
- [＋ 저장]을 누르면 메모가 등록되고, 잘못 남긴 메모는 [✕ 삭제]로 지웁니다.

등록된 견적서는 **견적서 조회**에서 확인할 수 있습니다.

# 판매 반품 등록

판매한 상품을 회수(반품) 처리하는 **판매 반품**을 등록하는 화면입니다.

### 1. 🏢 매출처 선택

반품 매출처를 먼저 지정합니다 (필수).

- 매출처 칸의 [···] 버튼을 클릭하면 **매출처 목록** 창이 열립니다.
- 단일 선택은 **더블클릭**, 여러 개는 **멀티선택모드**를 켠 뒤 선택합니다.
  - 매출처를 선택하면 주소·수취인명과 **미수금·마지막 판매일**이 함께 표시됩니다.

### 2. 📝 반품 정보 확인

**반품일·부서명·담당자**를 확인·지정합니다 (모두 필수 항목).

- **반품사유**(필수)는 파손·유통기한 등에서 선택합니다.

### 3. 🛒 반품할 상품 추가

상품코드의 [···] 버튼으로 **상품 통합검색창**을 열어 반품할 상품을 선택합니다.

**📌 문서불러오기**

- [문서불러오기]로 다른 카테고리의 주문서 정보를 불러옵니다.
**📌 엑셀업로드**

- [엑셀업로드]로 지정 탬플릿 엑셀을 이용해 여러 상품을 한꺼번에 등록합니다.

### 4. 🔢 수량 입력

반품할 **수량**을 입력하면 공급가·부가세·합계금액이 자동 계산됩니다.

### 5. 💳 결제정보 지정

결제정보 칸의 [···] 버튼을 클릭하면 **결제** 창이 열립니다.

- **결제방법**(현금결제·카드결제 등)을 선택합니다.
- **남은 금액 입력**을 체크하면 **결제금액**이 자동 입력됩니다.
- [＋결제입력] 버튼으로 등록하면 결제 내역이 좌측 목록에 추가됩니다.

### 6. 💾 반품 등록

매출처·상품과 필수 정보를 모두 입력했다면 [신규등록(F5)] 버튼으로 반품을 등록합니다.

### 📝 관리자 메모

이 반품 건에 대한 코멘트를 남길 수 있습니다.

- **노란색 칸**에 메모를 쓰고 [＋저장]을 누르면 등록, [✕삭제]로 지웁니다.

등록된 반품 내역은 **판매 반품 조회** 화면에서 확인·처리할 수 있습니다.

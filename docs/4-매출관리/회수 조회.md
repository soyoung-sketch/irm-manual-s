# 회수 조회

---

## 회수입력

회수 등록에서 등록한 문서를 **확인부터 회수(반품)완료까지** 단계별로 처리하는 화면입니다. 상단 **탭**이 문서의 처리 상태를 나눕니다.

### 1. 📅 회수일 지정

조회할 **회수일**(시작~종료)을 지정합니다.

### 2. 🔍 검색

[검색] 버튼으로 회수 문서를 조회합니다.

### 3. 📋 회수 주문서 확인

목록에서 회수 주문서 내역을 확인하고 **☑ 체크**로 처리할 문서를 선택합니다.

### 4. 📦 회수(반품)요청

확인이 끝나면 [회수(반품)요청]으로 넘깁니다(회수요청 탭으로 이동).

### 📌 가능한 작업

- **작업관리** : [작업관리]로 쇼핑몰 주문수집·오픈마켓 주문등록 메뉴를 엽니다.
- **수정** : [수정] 버튼으로 **회수주문서수정** 화면으로 이동합니다.
- **인쇄** : [인쇄]로 회수지시서 미리보기를 엽니다.
- **취소** : 쓰지 않을 문서면 [취소]합니다(취소 탭으로 이동).

---

## 취소

**취소**한 회수 문서를 모아 보는 탭입니다.

### 1. 📋 취소 문서 확인

취소한 회수 문서 목록에서 내용을 확인합니다.

### 2. ↩️ 회수입력으로 복구

[회수입력] 버튼으로 취소한 문서를 회수입력 상태로 되돌립니다.

- 이 탭에서는 [수정] · [취소] 버튼을 사용할 수 없습니다.

---

## 회수(반품)요청

**회수(반품)요청**한 문서가 모이는 탭입니다.

### 1. 📋 요청 문서 확인

회수(반품)요청한 문서 목록에서 내용을 확인합니다.

### 2. ✅ 회수완료 처리

요청 내용을 확인한 뒤 [회수완료] 버튼으로 회수를 확정합니다(완료 탭으로 이동).

- [인쇄]로 회수지시서를 출력하고, [수정]으로 문서를 고칩니다.
- 잘못 요청한 문서면 [취소]합니다.

---

## 회수중

회수가 **진행 중**인 문서가 모이는 탭입니다.

### 1. 🚚 회수중 문서 확인

회수가 진행 중인 문서를 모아 보며 진행 상황을 확인합니다.

- 이 탭에는 다음 단계로 보내는 **상태이동 버튼이 없고** 인쇄·수정·취소만 사용합니다.

---

## 회수(반품)완료

완료 탭으로 오면 **회수(반품)가 완료**된 것입니다.

### 1. 📋 완료 문서 확인

회수가 끝난 문서를 모아 보며 [인쇄]로 회수지시서를 출력합니다.

- 이 탭에서는 [수정] · [취소] 버튼을 사용할 수 없습니다.

---

## 반려

**반려**된 회수 문서를 모아 보는 탭입니다.

### 🗂️ 반려 문서 확인

- 반려된 회수 문서를 모아 보며 내용을 확인합니다.

---

## 수정

회수 주문서 내용을 **고치는 수정 화면**입니다. 회수 조회의 [수정] 버튼으로 들어옵니다.

### 1. ✏️ 전표 수정

전표를 수정하고 **문서수정** 버튼을 눌러주세요.

### 2. 💾 문서수정(F5)

내용을 고친 뒤 [문서수정(F5)] 버튼을 누르면 저장하고 **이전 화면**으로 돌아갑니다.

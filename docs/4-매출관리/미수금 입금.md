# 미수금 입금

매출처의 **미수금**을 조회하고 **수금(입금)**을 등록하는 화면입니다.

### 1. 🏢 매출처 선택

[···] 버튼으로 매출처 목록을 열어 대상 매출처를 지정합니다.

### 2. 📅 매출일 지정

조회할 **매출일**(시작~종료)을 지정합니다.

### 3. 🔍 검색

[검색] 버튼으로 매출처의 미수금 내역을 조회합니다.

### 4. 📋 수금 대상 선택

매출·수금·**미수금** 내역에서 수금할 건을 선택합니다.

### 5. 🧾 수금 정보 확인

우측 **수금(입금) 정보**에서 입금일·담당자를 확인합니다.

### 6. 💳 결제구분 선택

수금할 **결제구분**을 선택합니다.

### 7. 💰 수금금액 입력

**수금(입금)금액**을 입력합니다.

### 8. ✅ 수금입력

[수금입력] 버튼으로 수금 내역을 등록합니다.

- 잘못 입력했으면 [다시작성]으로 지우고 다시 입력합니다.

# 결제수단별 현황

판매 내역을 **결제수단별**로 집계해 조회하는 화면입니다.

### 1. 🔍 상세검색 열기

[상세검색] 버튼을 누르면 조건 입력 패널이 열립니다.

### 2. 📅 판매일 지정

조회할 **판매일**(시작~종료)을 지정합니다 · 판매일은 **필수**입니다.

- 분류·부서명·판매구분·결제구분 등은 필요에 따라 선택합니다.

### 3. 🔍 검색

[검색] 버튼으로 설정한 조건의 판매 내역을 조회합니다.

### 4. 📋 결과 확인

포스·판매일·**결제구분**별 반품완료·판매완료·합계 금액을 확인합니다.

# 미수금 입금조회

---

## 수금입금

등록한 **수금(입금)** 내역을 조회하는 화면입니다. 상단 「수금입금」·「수금삭제」 탭으로 나눠 봅니다.

### 1. 🔍 수금 내역 검색

두 가지 방법으로 원하는 수금 내역을 찾습니다.

**📌 통합검색**

- 통합검색 입력창에 **문서번호·매출처** 등을 입력해 찾습니다.
**📌 상세검색**

- [상세검색]을 누르면 **매출처·입금일** 조건 패널이 열립니다.
- 매출처 칸의 [···] 버튼으로 **매출처 목록**에서 골라 지정할 수 있습니다.

### 2. 📋 수금 내역 확인

**입금일·문서번호·매출처·수금구분·결제방법** 등 수금입금 내역을 확인하고 처리할 건을 선택합니다.

### 📌 가능한 작업

- **인쇄** : [인쇄]로 선택한 건의 **입금표** 미리 보기를 엽니다.
- **수금취소** : [수금취소]로 선택한 수금 건을 취소합니다.
- **수금정보삭제** : [수금정보삭제]로 선택한 건을 삭제합니다 · 삭제된 건은 **수금삭제 탭**에 모입니다.

---

## 수금삭제

**수금입금 탭**에서 **수금정보삭제**한 내역이 모이는 탭입니다.

### 1. 🔍 삭제 내역 검색

두 가지 방법으로 수금삭제 내역을 찾습니다.

**📌 통합검색**

- 통합검색 입력창에 **문서번호·매출처** 등을 입력해 찾습니다.
**📌 상세검색**

- [상세검색]을 누르면 **매출처·입금일** 조건 패널이 열립니다.
- 매출처 칸의 [···] 버튼으로 **매출처 목록**에서 골라 지정할 수 있습니다.

### 2. 📋 수금삭제 내역 확인

**입금일·문서번호·매출처·결제방법** 등 삭제된 수금 내역을 확인합니다.

### 📌 가능한 작업

- **인쇄** : [인쇄]로 선택한 건의 **입금표** 미리 보기를 엽니다.
- **수금정보삭제** : [수금정보삭제]로 내역을 완전히 삭제합니다.
- **수금취소** : 이미 삭제된 건이라 사용할 수 없습니다.

# 면과세 매출현황

월별 **면세·과세 매출 합계**를 조회하는 화면입니다 · 조회 조건을 정하고 검색하면 월별 매출이 표시됩니다.

### 1. 🔎 조회 조건 지정

조회 대상과 기간을 정합니다.

- 라디오에서 **전체 · 직영(수수료 제외) · 수수료 매입처** 중 조회 대상을 고릅니다.
- **월 선택**에서 시작월~종료월 범위를 지정합니다.

### 2. 🔍 검색

조건을 정하고 [검색] 버튼으로 조회합니다.

### 3. 📊 월별 면과세 매출 확인

검색한 결과가 그리드에 표시됩니다.

- 월별 **순매출·공급가액·부가세·면세금액·합계금액** 합계를 확인합니다.

조회한 내용은 상단 [인쇄] 버튼으로 인쇄할 수 있습니다.

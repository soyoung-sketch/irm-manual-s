# 세금계산서 일괄 작성

당월 매출을 **매출처별로 묶어** 세금계산서를 일괄 발행하는 화면입니다.

### 1. 🔍 검색

발행 대상을 조회합니다.

- **매출월**을 선택하고 [매출처선택]으로 발행할 매출처를 지정합니다.
- [검색]을 클릭하면 해당 매출이 그리드에 조회됩니다.

### 2. ✅ 발행할 전표 선택

그리드에서 발행할 **전표(행)**를 체크해 선택합니다.

### 3. 🗓️ 발행(작성)일 지정

세금계산서의 **발행(작성)일**을 지정합니다.

### 4. 🧾 작성

[계산서 및 세금계산서 작성] 버튼으로 선택 전표를 일괄 발행합니다.

발행 내역은 **세금계산서 발행 조회**에서 확인할 수 있습니다.

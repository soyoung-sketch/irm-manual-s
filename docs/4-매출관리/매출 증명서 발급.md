# 매출 증명서 발급

매출 전표를 지정해 **매출 증명서를 발급**하는 화면입니다.

### 1. 🏢 매출처 선택

증명서를 발급할 매출처를 먼저 지정합니다.

- 매출처 칸의 [···] 버튼을 클릭하면 **매출처목록** 창이 열립니다.
- 단일 선택은 **더블클릭**, 여러 개는 **멀티선택모드**를 켠 뒤 선택합니다.

### 2. 🔍 검색

매출기간과 결제구분을 지정해 전표를 조회합니다.

- **매출 시작일~종료일**과 **결제구분**을 지정한 뒤 [검색]을 클릭합니다.

### 3. 📋 전표 선택

- 조회된 목록에서 증명서를 발급할 **전표(행)**를 선택합니다.

### 4. 🧾 매출 증명서 발급

우측 발급정보를 채우고 발급합니다.

- **부서명·담당자**는 필수 항목입니다.
- 받는 방법에 따라 **방문수령·우편수신·문자수신·팩스수신·메일수신**을 선택합니다.
- [매출증명서발급] 버튼을 클릭해 증명서를 발급합니다.

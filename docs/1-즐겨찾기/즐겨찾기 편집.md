# 즐겨찾기 편집

메인 화면 상단에 표시되는 **즐겨찾기 메뉴**를 구성하는 화면입니다.

### 1. ✔️ 메뉴 선택

- 메뉴정보 트리에서 즐겨찾기에 추가할 **메뉴**를 선택합니다.
- 메뉴가 많을 때는 검색으로 빠르게 찾을 수 있습니다.

### 2. ➕ 즐겨찾기 추가

- [+ 추가] 버튼을 클릭하면 선택한 메뉴가 우측 **즐겨찾기 목록**에 추가됩니다.
- [⬆ 위로] [⬇ 아래] 버튼으로 표시 순서를 조정하고, [✕ 사용안함] 버튼으로 목록에서 삭제합니다.

### 📐 아이콘 크기 지정

- 크기 열에서 **크게 / 작게**를 선택합니다.
- 크게 : 즐겨찾기 한 칸을 온전히 사용하는 큰 아이콘
- 작게 : 한 칸에 세로 두 줄로 들어가는 작은 아이콘
  - 노란·초록 화살표는 각 크기로 지정된 메뉴가 실제 표시되는 위치를 나타냅니다.

💡 그룹 추가 · 이름변경 · 그룹 삭제 · 왼쪽/오른쪽 등 **그룹 관리 기능**은 일반적으로 사용하지 않습니다.

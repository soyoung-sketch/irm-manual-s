# HOME

프로그램 실행 시 처음 표시되는 **메인(HOME)** 화면입니다. 자주 쓰는 기능을 한 화면에서 바로 실행할 수 있습니다.

### 1. 🗂️ 메뉴 실행

- 상단 카테고리를 선택하면 해당 카테고리의 기능이 아래 리본에 표시됩니다.

- 리본에 표시된 메뉴를 클릭하면 해당 기능 화면으로 이동합니다.
- 「즐겨찾기」 탭에는 즐겨찾기로 등록한 메뉴가 표시되며, [즐겨찾기 편집] 버튼으로 직접 구성합니다.

### 2. 📊 오늘의 현황 확인

- 오늘의 **총 객수·총 매출**을 시간대별 그래프와 함께 확인합니다.
  - 내 매장의 객수·매출 데이터가 5분 간격으로 갱신됩니다.

### 3. 📋 바로가기 타일 실행

- 행사 상품 등록·판매 현황·매입 등록 등 주요 기능 타일을 클릭해 해당 화면으로 바로 이동합니다.

### 💬 고객 지원

- [FAQ] 버튼을 클릭해 자주 묻는 질문을 확인합니다.
- [1:1문의하기] 버튼을 클릭해 지원을 요청합니다.

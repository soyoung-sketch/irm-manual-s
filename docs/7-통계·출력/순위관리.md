## 판매상품순위

**판매상품순위**는 조회 조건에 따라 **상품별 판매 실적과 순위를 확인하는 화면**입니다. 판매수량뿐 아니라 **매입금액·판매금액·마진율**을 함께 확인하여 상품별 판매성과를 비교할 수 있습니다.

> 진행 순서 : **① 조회 조건 지정** → **② 검색** → **③ 판매순위 및 실적 확인**

### 1. 🔍 조회 조건 지정

- 조회할 **사업장 · 상품분류 · 기간** 등을 설정합니다.
  - 필요한 경우 **판매구분 · 배송구분 · 결제구분 · 매입처 · 매출처** 등으로 조건을 추가하여 원하는 판매내역만 조회할 수 있습니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭하면 설정한 조건에 맞는 상품별 판매순위가 표시됩니다.
  - 목록에서 원하는 상품을 빠르게 찾을 때는 **결과 내 검색**을 이용합니다.

### 3. ✅ 판매순위 및 실적 확인

- 조회 결과에서 상품별 **순위와 판매성과**를 확인합니다.
| 확인 항목 | 의미 |
| --- | --- |
| 총수량 | 판매된 상품 수량 |
| 매입금액 | 판매상품의 총 매입금액 |
| 판매금액 | 상품 판매로 발생한 총 금액 |
| 마진율 | 판매금액 대비 수익 비율 |
- **판매수량이 많은 상품뿐 아니라 판매금액과 마진율을 함께 비교하면, 많이 팔리는 상품과 수익성이 높은 상품을 구분하여 확인할 수 있습니다.**
- 또한 **전체 실적과 사업장별 실적을 함께 비교**하여 사업장에 따른 상품 판매성과 차이를 확인할 수 있습니다.

## 지역별판매순위

**지역별 판매순위**는 조회 기간 동안의 판매실적을 **시·구·동 지역별로 구분하여 비교하는 화면**입니다. 지역별 매출과 순이익을 확인하여 어느 지역에서 판매실적이 많이 발생했는지 확인할 수 있습니다.

> 진행 순서 : **① 매출처·기간 지정** → **② 검색** → **③ 지역별 실적 확인**

### 1. ✔️ 조회 조건 지정

- **매출처**와 **매출일 기간**을 설정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 지역별 실적 확인

| 항목 | 설명 |
| --- | --- |
| 시 · 구 · 동 | 판매실적이 발생한 지역 |
| 총 매출 | 해당 지역의 총 판매금액 |
| 총 순이익 | 매출에서 매입원가 등을 제외한 이익 |
| 총 매입가 | 판매상품의 총 매입금액 |
| 과세 / 비과세 | 과세 여부에 따른 매출금액 |

💡 지역별 **매출 · 매입 · 순이익**을 함께 비교하여 지역별 판매성과를 확인합니다.

## 연령별판매순위

**연령별 판매순위**는 고객의 **연령대별 매출과 결제현황을 비교하는 화면**입니다. 연령대별 매출 규모뿐 아니라 결제수단과 순이익까지 함께 확인할 수 있습니다.

> 진행 순서 : **① 매출처·기간 지정** → **② 검색** → **③ 연령대별 실적 확인**

### 1. ✔️ 조회 조건 지정

- **매출처**와 **매출일 기간**을 설정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 연령대별 실적 확인

| 구분 | 확인 내용 |
| --- | --- |
| 매출 | 연령대별 총 매출 |
| 결제수단 | 현금 · 카드 · 기타결제 |
| 결제건수 | 승인 · 취소 · 매출 건수 |
| 손익 | 총 매입가 · 총 순이익 · 할인 |
| 과세구분 | 과세 · 비과세 매출 |

💡 어떤 연령대에서 매출이 많이 발생했는지와 **주로 사용하는 결제수단**을 함께 확인할 수 있습니다.

## 성별판매순위

**성별 판매순위**는 판매실적을 **남성 · 여성 · 성별미상**으로 구분하여 비교하는 화면입니다. 조회 단위를 **일자별 · 월별 · 연도별**로 선택하여 기간에 따른 성별 매출 변화를 확인할 수 있습니다.

> 진행 순서 : **① 조회단위 선택** → **② 기간 지정** → **③ 검색** → **④ 성별 매출 확인**

### 1. ✔️ 조회단위 선택

- **일자별 · 월별 · 연도별** 중 조회 단위를 선택합니다.

### 2. ✔️ 기간 지정

- 조회할 **날짜** 범위를 지정합니다.

### 3. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 4. ✅ 성별 매출 확인

- 각 기간별로 다음 실적을 성별로 나누어 확인합니다.
| 구분 | 확인 내용 |
| --- | --- |
| 남성 | 합계 · 현금 · 카드 · 기타결제 |
| 여성 | 합계 · 현금 · 카드 · 기타결제 |
| 성별미상 | 합계 · 현금 · 카드 · 기타결제 |

💡 고객의 성별정보가 없는 매출은 **성별미상**으로 구분하여 확인합니다.

## 분류별판매순위

**분류별 판매순위**는 상품분류별 판매실적을 비교하여 **어떤 분류의 상품이 많이 팔리거나 높은 수익을 냈는지 확인하는 화면**입니다.

> 진행 순서 : **① 기간 지정** → **② 순위기준 선택** → **③ 검색** → **④ 분류별 순위 확인**

### 1. ✔️ 기간 지정

- 조회할 **날짜** 범위를 지정합니다.

### 2. 📊 순위기준 선택

| 기준 | 의미 |
| --- | --- |
| 판매수량 | 판매된 수량을 기준으로 비교 |
| 판매금액 | 총 판매금액을 기준으로 비교 |
| 수익금액 | 판매로 발생한 수익금액을 기준으로 비교 |
- 선택한 기준에 따라 분류별 순위가 표시됩니다.

### 3. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 4. ✅ 분류별 순위 확인

| 항목 | 설명 |
| --- | --- |
| 순위 | 선택한 기준에 따른 순서 |
| 분류 | 상품 분류 |
| 판매금액 | 해당 분류의 총 판매금액 |
| 매입금액 | 판매상품의 총 매입금액 |
| 수익금액 | 판매금액에서 매입금액을 제외한 금액 |
| 판매수량 | 판매된 총 수량 |

💡 **판매수량 · 매출 · 수익성 중 원하는 기준을 선택하여 분류별 성과를 비교**할 수 있습니다.

## 판매금액 구간 분석

**판매금액 구간 분석**은 판매건을 **결제금액 구간별로 나누어 금액과 건수를 확인하는 화면**입니다. 예를 들어 **1만원 미만, 1만원대, 3만원대** 등 어느 금액대의 판매가 많이 발생하는지 확인할 수 있습니다.

> 진행 순서 : **① 기간 지정** → **② 검색** → **③ 판매금액 구간 확인**

### 1. ✔️ 기간 지정

- 조회할 **날짜** 범위를 지정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 판매금액 구간 확인

- 각 날짜별로 판매금액 구간에 따른 **금액과 건수**가 표시됩니다.
| 항목 | 의미 |
| --- | --- |
| 판매금액 구간 | 판매건을 금액대별로 구분 |
| 금액 | 해당 구간에서 발생한 판매금액 |
| 건수 | 해당 구간에 포함된 판매 건수 |
  - 예시 : **30,000원 구간 → 금액 37,500원 / 건수 1건** — 해당 날짜에 30,000원 구간에 해당하는 판매가 **1건 발생**했다는 의미입니다.

💡 고객이 주로 **어느 금액대에서 결제하는지** 파악할 때 활용합니다.

## 누적회원 구간 분석

**누적회원 구간 분석**은 회원을 **누적개월 구간별로 나누어 발생한 매출금액과 건수를 확인하는 화면**입니다.

> 진행 순서 : **① 기간 지정** → **② 검색** → **③ 누적개월별 실적 확인**

### 1. ✔️ 기간 지정

- 조회할 **날짜** 범위를 지정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 누적개월별 실적 확인

| 항목 | 의미 |
| --- | --- |
| 누적개월 구간 | 회원을 누적기간별로 구분 |
| 금액 | 해당 구간에서 발생한 매출금액 |
| 건수 | 해당 구간의 판매 건수 |
- 날짜별로 **1개월 · 2개월 등 누적개월 구간에 따른 금액과 건수**를 비교할 수 있습니다.

💡 회원의 누적기간에 따라 **매출 발생 규모와 이용 건수의 차이**를 확인할 수 있습니다.

💡 **메뉴별 핵심 한눈에 보기**

| 메뉴 | 핵심 |
| --- | --- |
| **지역별 판매순위** | 어느 **지역**에서 매출이 많이 발생했는지 확인 |
| **연령별 판매순위** | 어느 **연령대**에서 매출이 많이 발생했는지 확인 |
| **성별 판매순위** | **남성 · 여성 · 성별미상** 매출 비교 |
| **분류별 판매순위** | 상품 **분류별 판매수량 · 매출 · 수익** 비교 |
| **판매금액 구간 분석** | 고객이 주로 결제하는 **판매금액대** 확인 |
| **누적회원 구간 분석** | 회원 **누적개월별 매출 · 건수** 확인 |

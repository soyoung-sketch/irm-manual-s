# 매입통계

---

## 매입처별 매출

**매입통계**는 매입처에서 공급받은 상품이 실제 판매에서 어느 정도의 **매출과 마진을 발생시켰는지** 확인하는 메뉴입니다. 그중 **매입처별 매출**은 선택한 매입처에서 공급받은 상품의 **전체 판매실적을 기간 합계로 확인하는 화면**입니다.

예) **(주)무한상사**에서 매입한 상품들이 조회기간 동안 **얼마에 매입되어 → 얼마에 판매되고 → 얼마의 마진을 남겼는지** 확인합니다.

> 진행 순서 : **① 매입처·기간 지정** → **② 검색** → **③ 매출 확인**

### 1. ✔️ 조회 조건 지정

- 조회할 **매입처**를 선택합니다.
- **매입일 기간**을 설정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 매출 확인

| 항목 | 설명 |
| --- | --- |
| 매입처코드 / 매입처명 | 상품을 공급받은 매입처 |
| 매입 합계금액 | 해당 매입처 상품의 총 매입원가 |
| 매출 공급가액 | 부가세를 제외한 판매금액 |
| 매출 부가세 | 판매금액에 포함된 부가세 |
| 매출 면세금액 | 면세상품 판매금액 |
| 매출 합계금액 | 최종 판매금액 |
| 마진 | 매출 합계금액 − 매입 합계금액 |
| 마진율(%) | 매출금액 대비 마진 비율 |

💡 **어느 매입처에서 공급받은 상품이 매출과 이익에 많이 기여했는지** 확인할 때 사용합니다.

---

## 매입처별 매출(일)

**매입처별 매출(일)**은 선택한 매입처에서 공급받은 상품의 판매실적을 **판매일자별로 나누어 확인하는 화면**입니다. **매입처별 매출**이 조회기간 전체 합계를 보여준다면, 이 화면은 **날짜별 판매 흐름**을 확인할 수 있습니다.

> 진행 순서 : **① 매입처·기간 지정** → **② 검색** → **③ 일자별 매출 확인**

### 1. ✔️ 조회 조건 지정

- 조회할 **매입처**를 선택합니다.
- **매입일 기간**을 설정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 일자별 매출 확인

| 항목 | 설명 |
| --- | --- |
| 판매일 | 매출이 발생한 날짜 |
| 매입처코드 / 매입처명 | 상품을 공급한 매입처 |
| 매입 합계금액 | 해당 날짜 판매상품의 매입원가 |
| 매출 합계금액 | 해당 날짜의 판매금액 |
| 마진 | 매출금액에서 매입금액을 제외한 금액 |
| 마진율(%) | 매출금액 대비 마진 비율 |

💡 특정 매입처 상품이 **어느 날짜에 많이 판매되었는지**, 일자별 매출과 마진 변화를 확인할 수 있습니다.

---

## 매입처별 상품매출

**매입처별 상품매출**은 선택한 매입처에서 공급받은 상품의 판매실적을 **상품별로 세분화하여 확인하는 화면**입니다. 매입처 전체 실적이 아니라 **어떤 상품이 매출과 마진을 많이 발생시켰는지** 확인할 수 있습니다.

> 진행 순서 : **① 매입처·기간 지정** → **② 검색** → **③ 상품별 매출 확인**

### 1. ✔️ 조회 조건 지정

- 조회할 **매입처**를 선택합니다.
- **매입일 기간**을 설정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 상품별 매출 확인

| 항목 | 설명 |
| --- | --- |
| 매입처코드 / 매입처명 | 상품을 공급받은 매입처 |
| 상품코드 / 상품명 | 해당 매입처에서 공급받은 상품 |
| 매입 합계금액 | 상품의 총 매입원가 |
| 매출 공급가액 | 부가세 제외 판매금액 |
| 매출 부가세 | 판매금액에 포함된 부가세 |
| 매출 면세금액 | 면세상품 판매금액 |
| 매출 합계금액 | 상품의 총 판매금액 |
| 마진 | 매출 합계금액 − 매입 합계금액 |
| 마진율(%) | 매출금액 대비 마진 비율 |

💡 특정 매입처의 상품 중 **어떤 상품이 잘 팔리고 수익성이 높은지** 비교할 때 사용합니다.

## 매입처구분별 매출(월)

**매입처구분별 매출(월)**은 판매실적을 **개인 · 사업자 · 비회원 구분별로 나누어 월 단위로 확인하는 화면**입니다. 각 구분별로 **공급가액 · 부가세 · 면세 · 합계금액**을 비교하여 어떤 고객구분에서 매출이 발생했는지 확인할 수 있습니다.

> 진행 순서 : **① 매출처·기간 지정** → **② 검색** → **③ 구분별 월 매출 확인**

### 1. ✔️ 조회 조건 지정

- 조회할 **매출처**를 선택합니다.
- **판매월 기간**을 설정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 구분별 월 매출 확인

| 구분 | 의미 |
| --- | --- |
| 개인 | 개인 고객에게 발생한 매출 |
| 사업자 | 사업자 고객에게 발생한 매출 |
| 비회원 | 회원정보 없이 발생한 매출 |
- 각 구분에서는 다음 금액을 확인합니다.
| 항목 | 설명 |
| --- | --- |
| 공급가액 | 부가세를 제외한 매출금액 |
| 부가세 | 매출에 포함된 부가세 |
| 면세 | 면세상품 판매금액 |
| 합계금액 | 해당 구분의 총 판매금액 |
  - 예시 : **사업자 → 공급가액 510,090원 + 부가세 51,010원 = 합계금액 561,100원** — 해당 월에는 **사업자 구분에서 총 561,100원의 매출이 발생**했다는 의미입니다.

💡 개인 · 사업자 · 비회원 중 **어떤 고객구분에서 매출이 많이 발생했는지 월별로 비교**할 수 있습니다.

💡 **메뉴별 차이 한눈에 보기**

| 메뉴 | 핵심 |
| --- | --- |
| **매입처별 매출** | 매입처별 **전체 매출·마진 합계** 확인 |
| **매입처별 매출(일)** | 매입처 상품의 **일자별 판매실적** 확인 |
| **매입처별 상품매출** | 매입처 상품을 **상품별로 세분화**하여 확인 |
| **매입처구분별 매출(월)** | **개인 · 사업자 · 비회원**별 월 매출 비교 |

💡 **핵심 정리**
    · **매입처별 매출** → “이 업체에서 사온 상품들이 전체적으로 얼마나 팔렸나?”
    · **매입처별 매출(일)** → “이 업체 상품들이 날짜별로 얼마나 팔렸나?”
    · **매입처별 상품매출** → “이 업체에서 사온 상품 중 무엇이 잘 팔렸나?”
    · **매입처구분별 매출(월)** → “월별 매출이 개인 · 사업자 · 비회원 중 어디에서 발생했나?”

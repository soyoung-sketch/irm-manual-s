# 매출통계

---

## 일자별 매출

**매출통계**는 판매 데이터를 여러 기준으로 집계하여 **매출·매입·마진을 비교·분석하는 메뉴**입니다. 그중 **일자별 매출**은 선택한 기간의 판매실적을 **판매일자별로 집계하여 확인하는 화면**입니다.

> 진행 순서 : **① 기간 지정** → **② 검색** → **③ 일자별 매출 확인**

### 1. ✔️ 기간 지정

- 조회할 **시작일 ~ 종료일**을 설정합니다.

### 2. 🔍 검색

- 조회날짜를 설정했다면 [검색] 버튼을 클릭합니다.

### 3. ✅ 일자별 매출 확인

- 일자별 **매출**을 확인해주세요.
| 항목 | 설명 |
| --- | --- |
| 판매일자 | 매출이 발생한 날짜 |
| 매입 합계금액 | 해당 날짜의 총 매입원가 |
| 매출 합계금액 | 해당 날짜의 총 판매금액 |
| 마진 | 매출금액에서 매입금액을 제외한 금액 |
| 마진율(%) | 매출금액 대비 마진 비율 |

💡 전체 **매출 합계**와 함께 우측의 **본사 등 사업장별 실적**을 비교할 수 있습니다.

💡 **주요 금액 항목**

| 항목 | 의미 |
| --- | --- |
| 매입 합계금액 | 판매된 상품의 총 매입원가 |
| 매출 공급가액 | 부가세를 제외한 매출금액 |
| 매출 부가세 | 매출에 포함된 부가세 |
| 매출 면세금액 | 면세상품의 판매금액 |
| 매출 합계금액 | 최종 판매금액 |
| 마진 | 매출 합계금액 − 매입 합계금액 |
| 마진율(%) | 마진 ÷ 매출 합계금액 × 100 |

## 연도별 매출

**연도별 매출**은 선택한 연도의 매출실적을 **연간 합계와 월별 실적**으로 확인하는 화면입니다.

> 진행 순서 : **① 연도 지정** → **② 검색** → **③ 연간·월별 실적 확인**

### 1. ✔️ 연도 지정

- 조회할 **시작연도 · 종료연도**를 설정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 연간·월별 실적 확인

| 구분 | 확인 내용 |
| --- | --- |
| 연간 실적 | 매입금액 · 매출금액 · 마진 · 마진율 |
| 월별 실적 | 각 월의 매입금액 · 매출금액 · 마진 |

💡 한 해의 **전체 실적과 각 월의 매출 흐름을 함께 비교**할 수 있습니다.

## 상품별 매출상세

**상품별 매출상세**는 판매된 상품의 내역을 **상품 단위로 상세 조회하는 화면**입니다. 특정 상품이 언제, 몇 개, 얼마에 판매되었는지 자세히 확인할 수 있습니다.

> 진행 순서 : **① 조회 조건 지정** → **② 검색** → **③ 상품별 상세내역 확인**

### 1. 🔍 조회 조건 지정

- **상품분류 · 부서 · 담당자 · 판매일 · 판매구분 · 배송구분 · 결제구분 · 매입처 · 매출처** 등을 설정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 상품별 상세내역 확인

| 구분 | 확인 내용 |
| --- | --- |
| 상품정보 | 상품코드 · 상품명 · 분류 · 단위 |
| 판매정보 | 판매일자 · 사업장 · 매출처 |
| 단가/수량 | 매입단가 · 판매단가 · 수량 |
| 금액 | 매입합계 · 공급가액 · 부가세 등 |

💡 여러 상품의 합계가 아닌 **개별 상품의 판매내역을 상세하게 확인할 때** 사용합니다.

- 연간 전체 실적과 각 판매구분의 **매입금액 · 매출금액 · 마진 · 마진율**을 비교합니다.

💡 연간 기준으로 **판매방식별 실적 차이**를 확인할 수 있습니다.

## 매출처별 매출

**매출처별 매출**은 선택한 매출처의 판매실적을 **기간별로 확인하는 화면**입니다.

> 진행 순서 : **① 매출처 선택** → **② 판매기간 지정** → **③ 검색** → **④ 매출실적 확인**

### 1. ✔️ 매출처 선택

- 조회할 **매출처**를 지정합니다.

### 2. ✔️ 판매기간 지정

- 조회할 **판매일 기간**을 설정합니다.

### 3. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 4. ✅ 매출실적 확인

| 항목 | 설명 |
| --- | --- |
| 판매일 | 매출 발생일 |
| 공급가액 | 부가세 제외 매출금액 |
| 부가세 | 매출에 포함된 부가세 |
| 면세 | 면세상품 매출 |
| 합계금액 | 총 판매금액 |
| 마진 | 판매로 발생한 이익 |

💡 특정 매출처에서 **언제 얼마의 매출과 마진이 발생했는지** 확인할 수 있습니다.

## 매출처별 상품 매출

**매출처별 상품 매출**은 선택한 매출처의 판매실적을 **상품별로 세분화하여 확인하는 화면**입니다.

> 진행 순서 : **① 매출처·기간 지정** → **② 검색** → **③ 상품별 매출 확인**

### 1. ✔️ 매출처·기간 지정

- **매출처**와 **판매일** 기간을 지정합니다.

### 2. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 3. ✅ 상품별 매출 확인

| 항목 | 설명 |
| --- | --- |
| 판매일 | 상품이 판매된 날짜 |
| 매출처 | 판매 대상 거래처 |
| 상품코드 · 상품명 | 판매된 상품 |
| 수량 | 판매수량 |
| 공급가액 · 부가세 · 면세 | 매출 세부금액 |
| 합계금액 | 총 판매금액 |
| 마진 | 상품 판매로 발생한 이익 |

💡 **매출처별 매출**보다 상세하게 **해당 매출처에서 어떤 상품이 판매되었는지** 확인할 수 있습니다.

## 매출처 등급별 매출

**매출처 등급별 매출**은 선택한 매출처의 판매실적을 **매출처 등급별로 구분하여 비교하는 화면**입니다.

> 진행 순서 : **① 매출처 선택** → **② 판매기간 지정** → **③ 검색** → **④ 등급별 실적 확인**

### 1. ✔️ 매출처 선택

- 조회할 **매출처**를 지정합니다.

### 2. ✔️ 판매기간 지정

- 조회할 **판매일 기간**을 설정합니다.

### 3. 🔍 검색

- [검색] 버튼을 클릭합니다.

### 4. ✅ 등급별 실적 확인

- 전체 매출과 **BASIC** 등 등록된 등급별 실적을 확인합니다.
| 확인 항목 |
| --- |
| 매입 합계금액 |
| 매출 공급가액 |
| 매출 부가세 · 면세금액 |
| 매출 합계금액 |
| 마진 · 마진율 |

💡 전체 매출과 **등급별 매출실적을 함께 비교하여 매출처 등급에 따른 성과 차이**를 확인할 수 있습니다.

💡 **매출통계 메뉴 한눈에 보기**

| 메뉴 | 핵심 |
| --- | --- |
| **일자별 매출** | 날짜별 전체 매출 흐름 |
| **연도별 매출** | 연간·월별 매출 비교 |
| **상품별 매출상세** | 개별 상품 판매내역 상세조회 |
| **상품별 매출(일/주/월/년)** | 상품별 기간 단위 매출 |
| **분류별 매출(일/주/월/년)** | 상품분류별 기간 단위 매출 |
| **구분별 매출(일/주/월/년)** | 판매구분별 기간 단위 매출 |
| **매출처별 매출** | 거래처별 전체 매출 |
| **매출처별 상품 매출** | 거래처별 상품 판매내역 |
| **매출처 등급별 매출** | 거래처 등급별 매출 비교 |

💡 **핵심 구분**
    · **상품별** → 어떤 **상품**이 팔렸는지
    · **분류별** → 어떤 **상품분류**에서 매출이 발생했는지
    · **구분별** → 어떤 **판매방식**에서 매출이 발생했는지
    · **매출처별** → 어느 **거래처**에서 매출이 발생했는지
